Preference List

Definition. Let $A = \{a_1, a_2, \ldots, a_n\}$ and $B = \{b_1, b_2, \ldots, b_n\}$ be two finite sets of agents. A preference list for agent $a_i \in A$ is a strict total order $\succ_{a_i}$ over the elements of $B$, written as an ordered tuple

$$P(a_i) = (b_{\sigma(1)},\, b_{\sigma(2)},\, \ldots,\, b_{\sigma(n)}),$$

where $\sigma$ is a permutation of $\{1, \ldots, n\}$ and $b_{\sigma(k)} \succ_{a_i} b_{\sigma(k+1)}$ for all $k$. Informally, $P(a_i)$ ranks every element of $B$ from most preferred to least preferred. A preference profile is the collection $\mathcal{P} = \{P(a_i)\}_{i=1}^n \cup \{P(b_j)\}_{j=1}^n$ of all agents' preference lists on both sides.

Worked Example. Suppose $A = \{\text{Alice}, \text{Bob}\}$ and $B = \{\text{Xavier}, \text{Yara}\}$ with the following preference lists:

| Agent | Rank 1 | Rank 2 | |-------|--------|--------| | Alice | Xavier | Yara | | Bob | Yara | Xavier | | Xavier | Alice | Bob | | Yara | Bob | Alice |

Alice's list is $P(\text{Alice}) = (\text{Xavier}, \text{Yara})$, meaning Xavier $\succ_{\text{Alice}}$ Yara. To check whether agent $a_i$ prefers $b$ over $b'$, we locate both in $P(a_i)$: whichever appears earlier is preferred. The rank function $r_{a_i}(b) \in \{1, \ldots, n\}$ assigns the position of $b$ in $P(a_i)$, so $b \succ_{a_i} b'$ if and only if $r_{a_i}(b) < r_{a_i}(b')$.

Key Theorem (Existence of a Stable Matching, Gale–Shapley 1962). Given any preference profile $\mathcal{P}$ with $|A| = |B| = n$, the deferred-acceptance algorithm terminates in at most $n^2$ rounds and outputs a stable matching $M \subseteq A \times B$ — a perfect matching in which no pair $(a, b) \notin M$ satisfies both $b \succ_a M(a)$ and $a \succ_b M^{-1}(b)$. The proof proceeds by the invariant that once $b$ holds a proposal from $a$, $b$'s held partner can only improve, guaranteeing termination and stability.

from sympy import symbols, Rational

# Encode preference lists as rank dictionaries
prefs_A = {
    'Alice':  {'Xavier': 1, 'Yara': 2},
    'Bob':    {'Yara':   1, 'Xavier': 2},
}
prefs_B = {
    'Xavier': {'Alice': 1, 'Bob': 2},
    'Yara':   {'Bob':   1, 'Alice': 2},
}

def prefers(prefs, agent, x, over_y):
    """Return True if agent prefers x over over_y."""
    return prefs[agent][x] < prefs[agent][over_y]

print(prefers(prefs_A, 'Alice', 'Xavier', 'Yara'))   # True
print(prefers(prefs_B, 'Yara',  'Bob',   'Alice'))   # True
