What the Algorithm Achieves

The National Resident Matching Program (NRMP) is the operational instantiation of the Gale–Shapley deferred-acceptance algorithm at national scale: each year it assigns roughly 40,000 medical-school graduates to hospital residency positions by solving a two-sided stable matching problem. Formally, given a set of applicants $A = \{a_1, \dots, a_m\}$ and a set of programs $P = \{p_1, \dots, p_n\}$, each equipped with a strict preference ordering over the other side, the NRMP produces a matching $\mu : A \to P \cup \{\varnothing\}$ satisfying the stability condition: there exists no pair $(a_i, p_j)$ such that $a_i$ prefers $p_j$ to $\mu(a_i)$ and $p_j$ prefers $a_i$ to some applicant it accepted. Stability is not merely an aesthetic criterion; an unstable matching would unravel in practice as blocking pairs arranged private contracts outside the system.

Worked Example

Let $A = \{a_1, a_2\}$ and $P = \{p_1, p_2\}$ with preferences

$$a_1 : p_1 \succ p_2, \quad a_2 : p_1 \succ p_2, \quad p_1 : a_1 \succ a_2, \quad p_2 : a_1 \succ a_2.$$

Running applicant-proposing deferred acceptance: round 1, both applicants propose to $p_1$; $p_1$ tentatively holds $a_1$ and rejects $a_2$. Round 2, $a_2$ proposes to $p_2$, which accepts. The stable matching is $\mu = \{(a_1, p_1),(a_2, p_2)\}$. One can verify no blocking pair exists.

Key Theorem

Theorem (Gale–Shapley, 1962). The applicant-proposing deferred-acceptance algorithm always terminates in at most $mn$ rounds and produces the applicant-optimal stable matching: every applicant receives the best partner they can obtain in any stable matching, while every program receives the worst stable partner it could receive.

This optimality–pessimality duality is not a defect; it is the precise price of placing proposal power in the applicants' hands, a policy choice with direct equity implications for who benefits most from centralized clearinghouses.

Lab Cell

from sympy import symbols, Rational

# Represent preference profiles as ranked dictionaries and run
# a deferred-acceptance simulation entirely in SymPy data structures.
applicants = {1: [1, 2], 2: [1, 2]}
programs   = {1: [1, 2], 2: [1, 2]}

def deferred_acceptance(apps, progs):
    held   = {}          # program -> applicant currently held
    next_p = {a: 0 for a in apps}   # next program each applicant proposes to
    free   = list(apps.keys())
    while free:
        a = free.pop(0)
        p = apps[a][next_p[a]]; next_p[a] += 1
        if p not in held:
            held[p] = a
        elif progs[p].index(a) < progs[p].index(held[p]):
            free.append(held[p]); held[p] = a
        else:
            free.append(a)
    return {a: p for p, a in held.items()}

print(deferred_acceptance(applicants, programs))
