Edge Relaxation

Definition. Let $G = (V, E, w)$ be a weighted directed graph with weight function $w : E \to \mathbb{R}$. For each vertex $v \in V$, maintain a tentative distance estimate $d[v]$, initialized as $d[s] = 0$ for a fixed source $s$ and $d[v] = +\infty$ for all $v \neq s$. The relaxation of an edge $(u, v) \in E$ is the conditional update

$$ \text{if } d[u] + w(u, v) < d[v] \text{ then } d[v] \leftarrow d[u] + w(u, v). $$

Geometrically, relaxation tests whether the known shortest path to $u$, extended by the single edge $(u, v)$, improves the current best-known path to $v$. The operation is called relaxation because it loosens (weakens) an upper bound: each application can only decrease $d[v]$, never increase it.

Worked example. Consider the graph with vertices $\{s, a, b\}$ and edges $s \to a$ with $w = 4$, $s \to b$ with $w = 7$, and $a \to b$ with $w = 1$. Initialize $d[s]=0$, $d[a]=d[b]=+\infty$.

  • Relax $(s, a)$: $0 + 4 < \infty$, so $d[a] \leftarrow 4$.
  • Relax $(s, b)$: $0 + 7 < \infty$, so $d[b] \leftarrow 7$.
  • Relax $(a, b)$: $4 + 1 = 5 < 7$, so $d[b] \leftarrow 5$.

    • After these three relaxations, $d[b] = 5$, correctly reflecting the shortest path $s \to a \to b$ of total weight $5$.

    Theorem (Convergence of Relaxation). Let $\delta(s, v)$ denote the true shortest-path distance from $s$ to $v$. If the edges on a shortest path $s = v_0, v_1, \ldots, v_k = v$ are relaxed in the order $(v_0, v_1), (v_1, v_2), \ldots, (v_{k-1}, v_k)$, then after those $k$ relaxations we have $d[v] = \delta(s, v)$.

    Proof sketch. By induction on path length $k$. Base case $k = 0$: $d[s] = 0 = \delta(s,s)$. Inductive step: assume $d[v_{k-1}] = \delta(s, v_{k-1})$ before relaxing $(v_{k-1}, v_k)$. Then $d[v_{k-1}] + w(v_{k-1}, v_k) = \delta(s, v_k)$ by optimality of the subpath, so the relaxation sets $d[v_k] \leq \delta(s, v_k)$. Since no estimate can undercut a true shortest-path distance, equality holds. $\blacksquare$

    Lab cell.

    import sympy as sp

# Graph as adjacency list: {u: [(v, weight), ...]}
graph = {'s': [('a', 4), ('b', 7)], 'a': [('b', 1)], 'b': []}
d = {'s': 0, 'a': sp.oo, 'b': sp.oo}

def relax(u, v, w):
    if d[u] + w < d[v]:
        d[v] = d[u] + w
        print(f"  Relaxed ({u},{v}): d[{v}] = {d[v]}")

for u, neighbors in graph.items():
    for v, w in neighbors:
        relax(u, v, w)

print("Final distances:", d)
