Concept Book: Moores Algorithm

Algorithms Ch09 · Generated by SPL

Payoff

Every preceding chapter in this text has been building toward a single question: how small can a computation be while remaining correct? Moore's algorithm answers that question with finality. Given any deterministic finite automaton $\mathcal{A} = (Q, \Sigma, \delta, q_0, F)$, the algorithm produces a provably minimal equivalent automaton $\mathcal{A}^* $ in time $O(|Q|^2 |\Sigma|)$—no smaller machine can recognize the same language. This is not merely an optimization; it is a uniqueness result.

The core idea is iterative partition refinement. Begin with the coarsest possible partition of $Q$: accepting states $F$ in one block, non-accepting states $Q \setminus F$ in another. Then repeatedly split any block $B$ for which there exists a symbol $a \in \Sigma$ such that $\delta(B, a)$ straddles two distinct blocks. States that are split apart are distinguishable; states that survive together are indistinguishable—they respond identically to every future input string. When no further splitting is possible, each equivalence class $[q]$ becomes a single state in $\mathcal{A}^*$.

Worked example. Consider the automaton over $\Sigma = \{0, 1\}$ that accepts binary strings ending in $01$. A naive construction yields six states. After one round of Moore refinement the accept state isolates immediately. A second round separates "just read $0$" from "just read $1$" in the non-accept group. The process stabilizes in three rounds, collapsing the automaton to its irreducible three-state core.

Key theorem (Myhill–Nerode). Two strings $x, y \in \Sigma^$ are Nerode-equivalent with respect to language $L$ if for every $z \in \Sigma^$, $xz \in L \iff yz \in L$. The number of Nerode equivalence classes is exactly the number of states in $\mathcal{A}^*$. Moore's algorithm constructs these classes constructively; uniqueness follows from the fact that any two minimal DFAs for the same language are isomorphic.

from sympy.combinatorics import Permutation
from sympy import FiniteSet

# Encode transition table as a dict: state -> {symbol: next_state}
delta = {0: {'0':1,'1':0}, 1: {'0':1,'1':2}, 2: {'0':1,'1':0}}
F = {2}
Q = set(delta)

# Initial partition: accepting vs. non-accepting
P = [F, Q - F]

def split(block, partition, delta, sigma):
    for a in sigma:
        groups = {}
        for q in block:
            target_class = next(i for i,b in enumerate(partition) if delta[q][a] in b)
            groups.setdefault(target_class, set()).add(q)
        if len(groups) > 1:
            return list(groups.values())
    return [block]

sigma = {'0','1'}
changed = True
while changed:
    changed = False
    new_P = []
    for block in P:
        parts = split(block, P, delta, sigma)
        new_P.extend(parts)
        if len(parts) > 1:
            changed = True
    P = new_P

print("Equivalence classes (minimal states):", P)

The output reveals exactly three classes—confirming the hand calculation above.

Because minimality is a structural property—derivable from the language alone, independent of how the original automaton was constructed—Moore's algorithm is the natural capstone of automata theory. Every compiler's lexer, every network protocol parser, every regular-expression engine is secretly running inside this theorem.

The concept unlocks a rich frontier. Regular-language compression, state-machine synthesis from specification tables, equivalence checking of hardware circuits, and randomized streaming algorithms for majority detection all descend directly from the partition-refinement insight developed here. Each of these domains rewards deeper study; the one that perhaps most rewards immediate exploration is streaming computation, where the space bound implied by Myhill–Nerode translates directly into lower bounds on memory—a bridge between the abstract algebra of this chapter and the practical engineering of data systems at scale.
