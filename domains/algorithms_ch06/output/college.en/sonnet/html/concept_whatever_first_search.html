Whatever First Search

Definition. Let $G = (V, E)$ be a directed or undirected graph and let $s \in V$ be a designated source vertex. Whatever First Search (WFS) is a family of graph-traversal algorithms parameterised by a single abstract data structure called the bag $\mathcal{B}$, which supports two operations: $\textsc{Put}(v, \mathcal{B})$ (insert a vertex) and $\textsc{Pull}(\mathcal{B})$ (remove and return one vertex according to $\mathcal{B}$'s internal policy). Concretely:

  • Mark $s$ as discovered; $\mathcal{B} \leftarrow \{s\}$.
  • While $\mathcal{B} \neq \emptyset$: pull $u \leftarrow \textsc{Pull}(\mathcal{B})$; for each neighbour $v$ of $u$, if $v$ is undiscovered, mark $v$ and $\textsc{Put}(v, \mathcal{B})$.

    • Every classical traversal is an instantiation: a LIFO stack yields depth-first search (DFS); a FIFO queue yields breadth-first search (BFS); a min-priority queue ordered by edge weight yields Dijkstra's algorithm.

    Worked example. Consider the graph $G$ with vertices $\{A, B, C, D\}$ and edges $A{-}B,\, A{-}C,\, B{-}D,\, C{-}D$, source $s = A$.

    | Step | Pull | Discover | |------|------|----------| | 1 | $A$ | $B, C$ | | 2 | $B$ (stack) or $C$ (queue) | … |

    With a stack the pull order is $A, C, D, B$, tracing a depth-first path; with a queue it is $A, B, C, D$, processing vertices layer by layer. The bag abstraction makes both orderings instances of the same three-line pseudocode.

    Key theorem. For any finite graph $G = (V, E)$ with $|V| = n$ and $|E| = m$, WFS terminates in $O(n + m)$ time regardless of the bag policy, provided each vertex is placed in $\mathcal{B}$ at most once (enforced by the discovered flag). The proof follows by a potential-function argument: define $\Phi = |\mathcal{B}|$; each vertex contributes exactly one $\textsc{Put}$ and one $\textsc{Pull}$, so the total work is $\Theta(n + m)$.

    Lab cell.

    from collections import deque
import sympy as sp

def whatever_first_search(adj, source, use_stack=False):
    discovered = {source}
    bag = [source]          # list used as stack or queue
    order = []
    while bag:
        u = bag.pop() if use_stack else bag.pop(0)
        order.append(u)
        for v in adj.get(u, []):
            if v not in discovered:
                discovered.add(v)
                bag.append(v)
    return order

adj = {'A': ['B', 'C'], 'B': ['D'], 'C': ['D'], 'D': []}
print("DFS:", whatever_first_search(adj, 'A', use_stack=True))
print("BFS:", whatever_first_search(adj, 'A', use_stack=False))

    Running this cell prints DFS: ['A', 'C', 'D', 'B'] and BFS: ['A', 'B', 'C', 'D'], confirming that the sole structural difference between the two canonical traversals is the extraction policy of $\mathcal{B}$.
