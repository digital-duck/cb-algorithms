Concept Book: Flood Fill

Algorithms Ch06 · Generated by SPL

Payoff

Definition. The flood fill of a grid $G$ from a seed cell $s$ is the maximal set $R \subseteq G$ such that (i) $s \in R$, and (ii) every cell $c \in R$ is reachable from $s$ by a path whose every step crosses a shared edge between two cells bearing the same label. Formally, if we define the adjacency relation $\sim$ on cells of identical value, then $R$ is the connected component of the equivalence class $[s]_{\sim}$ in the graph $(G, \sim)$.

Worked example. Consider the $4 \times 4$ integer grid

$$G = \begin{pmatrix} 1 & 1 & 2 & 2 \\ 1 & 1 & 2 & 3 \\ 4 & 2 & 2 & 3 \\ 4 & 4 & 3 & 3 \end{pmatrix}.$$

Seeding at position $(0,0)$ (value $1$), a breadth-first flood fill enqueues $(0,0)$, then discovers $(0,1),(1,0),(1,1)$. No further neighbor carries the value $1$, so $R = \{(0,0),(0,1),(1,0),(1,1)\}$. Replacing each cell in $R$ with the value $5$ rewrites the top-left quadrant uniformly, leaving the remaining components intact — exactly the behaviour exploited by the paint-bucket tool in raster editors.

Key theorem (complexity). On a grid of $N$ cells with bounded vertex degree $d$, the flood-fill algorithm terminates in $\Theta(N)$ time and $O(N)$ space, optimal among algorithms that must inspect every cell of the output region.

Proof sketch. Each cell enters the queue at most once (marked on first visit) and is dequeued at most once; each dequeue examines at most $d$ neighbors. The lower bound follows because any correct algorithm must write every cell in the output region, which may be all of $G$.

Lab cell.

from sympy import zeros, Matrix

def flood_fill(grid, r, c, old, new):
    if r < 0 or r >= len(grid) or c < 0 or c >= len(grid[0]):
        return
    if grid[r][c] != old:
        return
    grid[r][c] = new
    for dr, dc in [(-1,0),(1,0),(0,-1),(0,1)]:
        flood_fill(grid, r+dr, c+dc, old, new)

G = [[1,1,2,2],[1,1,2,3],[4,2,2,3],[4,4,3,3]]
flood_fill(G, 0, 0, 1, 5)

Flood fill is the natural endpoint of this textbook's journey because every concept built along the way — graph traversal, connected components, queue-based search, and recursive descent — converges here into a single, clean primitive. The algorithm is deceptively simple yet underlies image segmentation in medical imaging, region labelling in cartographic analysis, reachability queries in game-state graphs, and leak detection in finite-element meshes. Each domain reinterprets "same label" and "adjacency" differently, but the mathematical core remains the connected-component computation you have now mastered.
