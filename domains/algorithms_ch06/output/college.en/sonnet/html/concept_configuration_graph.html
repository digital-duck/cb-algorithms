Configuration Graph

Definition. Let $S$ be a finite set of configurations of some combinatorial or computational system, and let $\to$ be a binary relation on $S$ called the transition relation. The configuration graph (also called the state graph or reachability graph) of the system is the directed graph $G = (S, E)$ where the edge set is

$$E = \{(u, v) \in S \times S : u \to v\},$$

that is, there is a directed edge from $u$ to $v$ whenever configuration $v$ is reachable from $u$ in one step. A configuration $s^ \in S$ is a terminal configuration (or sink) if it has out-degree zero: no edge leaves $s^$. A configuration graph with a unique sink is said to be convergent if every directed path leads to that sink.

Worked Example. Consider a system of three tokens placed on the squares $\{1,2,3\}$ of a row. A legal move slides the leftmost misplaced token one position to the right. Label each configuration by the ordered occupancy vector. Starting from $(1, 2, 3)$ there are no legal moves, so $(1, 2, 3)$ is the terminal configuration. Starting from $(2, 1, 3)$, the leftmost misplaced token is at position $2$, moving it yields $(1, 2, 3)$; from $(2, 3, 1)$ we obtain $(2, 1, 3)$ then $(1, 2, 3)$. The resulting configuration graph is a directed path:

$$ (2,3,1) \;\longrightarrow\; (2,1,3) \;\longrightarrow\; (1,2,3). $$

Every configuration has a directed path to the unique sink, confirming convergence.

Key Theorem (Convergence via Monovariant). If there exists a function $\phi: S \to \mathbb{Z}_{\geq 0}$ such that $u \to v$ implies $\phi(v) < \phi(u)$ for all $(u,v) \in E$, then $G$ is acyclic and every maximal directed path terminates in finitely many steps.

Proof sketch. Any directed path $s_0 \to s_1 \to \cdots \to s_k$ satisfies $\phi(s_0) > \phi(s_1) > \cdots > \phi(s_k) \geq 0$, so the path length is bounded by $\phi(s_0)$. Acyclicity follows because a cycle would yield a strictly decreasing sequence returning to its start, contradicting the well-ordering of $\mathbb{Z}_{\geq 0}$. $\square$

The function $\phi$ is called a monovariant or potential function for the system.

Lab Cell.

import networkx as nx
import sympy as sp

configs = [(2,3,1), (2,1,3), (1,2,3)]
edges   = [((2,3,1),(2,1,3)), ((2,1,3),(1,2,3))]

G = nx.DiGraph()
G.add_nodes_from(configs)
G.add_edges_from(edges)

# Verify acyclicity and locate the unique sink
print("Acyclic:", nx.is_directed_acyclic_graph(G))
sinks = [n for n in G.nodes if G.out_degree(n) == 0]
print("Terminal configurations:", sinks)

# Monovariant: number of inversions
def inversions(cfg):
    return sum(1 for i in range(len(cfg))
                 for j in range(i+1, len(cfg)) if cfg[i] > cfg[j])

phi = {c: inversions(c) for c in configs}
print("Monovariant values:", phi)
