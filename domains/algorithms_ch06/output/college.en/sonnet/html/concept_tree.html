Tree

Definition. A tree is a connected, acyclic undirected graph. Formally, a graph $T = (V, E)$ is a tree if and only if it satisfies any two (and hence all three) of the following equivalent conditions:

  • $T$ is connected and contains no cycles.
  • $T$ is connected and $|E| = |V| - 1$.
  • Every pair of distinct vertices $u, v \in V$ is joined by exactly one simple path.

    • A designated vertex $r \in V$ may be chosen as the root, inducing a parent–child hierarchy on all other vertices. In a rooted tree, the depth of a vertex $v$ is the length of the unique path from $r$ to $v$, and the height of $T$ is $\max_{v \in V} \operatorname{depth}(v)$.

    Worked Example. Consider the vertex set $V = \{1, 2, 3, 4, 5\}$ with edge set

    $$E = \{\{1,2\},\, \{1,3\},\, \{3,4\},\, \{3,5\}\}.$$

    We verify the tree conditions: $|V| = 5$ and $|E| = 4 = |V| - 1$. Traversing from any vertex to any other yields exactly one path—for instance, the unique path from $2$ to $5$ is $2 \to 1 \to 3 \to 5$. Rooting at vertex $1$, the depths are $\operatorname{depth}(1)=0$, $\operatorname{depth}(2)=\operatorname{depth}(3)=1$, $\operatorname{depth}(4)=\operatorname{depth}(5)=2$, giving height $2$.

    Key Theorem (Cayley's Formula). The number of distinct labeled trees on $n$ vertices is

    $$\tau(n) = n^{n-2}, \qquad n \geq 2.$$

    Proof sketch. Associate each labeled tree with a sequence of $n-2$ vertex labels, called the Prüfer sequence, by iteratively removing the leaf with the smallest label and recording the label of its neighbor. This map is a bijection between the set of labeled trees on $n$ vertices and sequences in $\{1, \ldots, n\}^{n-2}$; since there are $n^{n-2}$ such sequences, the formula follows. $\square$

    Lab Cell (SymPy).

    import networkx as nx
import matplotlib.pyplot as plt

T = nx.Graph()
T.add_edges_from([(1,2),(1,3),(3,4),(3,5)])

print("Is tree:", nx.is_tree(T))
print("Cayley count for n=5:", 5**3)   # n^{n-2} = 125

pos = nx.spring_layout(T, seed=42)
nx.draw(T, pos, with_labels=True, node_color="lightblue")
plt.title("Example tree rooted at vertex 1")
plt.show()
