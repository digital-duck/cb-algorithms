Cycle Acyclic

Definition. Let $G = (V, E)$ be an undirected graph. A walk in $G$ is a sequence of vertices $v_0, v_1, \ldots, v_k$ such that $\{v_i, v_{i+1}\} \in E$ for each $0 \le i < k$. A walk is a path if all vertices are distinct. A cycle is a closed walk $v_0, v_1, \ldots, v_k = v_0$ of length $k \ge 3$ in which $v_0, v_1, \ldots, v_{k-1}$ are pairwise distinct. A graph is called acyclic if it contains no cycle; an undirected acyclic graph is also called a forest. A connected forest is a tree.

Worked Example. Consider the graph $G$ with vertex set $V = \{1, 2, 3, 4\}$ and edge set $E = \{\{1,2\},\{2,3\},\{3,4\},\{4,2\}\}$. The walk $2 \to 3 \to 4 \to 2$ has length 3, returns to its starting vertex, and visits $2, 3, 4$ without repetition, so it is a cycle. Adding the edge $\{1,2\}$ does not create a new cycle because vertex $1$ is a leaf. Removing any one of $\{2,3\}$, $\{3,4\}$, or $\{4,2\}$ destroys the cycle and renders the graph acyclic; what remains is a tree on four vertices with exactly three edges, illustrating the identity $|E| = |V| - 1$ for trees.

Key Theorem (Cycle Characterisation of Trees). A connected graph $G = (V, E)$ is a tree if and only if it is acyclic and $|E| = |V| - 1$.

Proof sketch. ($\Rightarrow$) By induction on $|V|$: a single vertex satisfies both conditions. For $|V| > 1$, every tree has a leaf $\ell$; removing $\ell$ gives a tree on $|V|-1$ vertices with $|V|-2$ edges by hypothesis, so restoring $\ell$ adds one vertex and one edge, preserving $|E| = |V| - 1$ and acyclicity (a leaf cannot close a cycle). ($\Leftarrow$) If $|E| = |V| - 1$ and $G$ is connected and acyclic, any edge removal disconnects $G$, which is the defining property of a tree. $\square$

import sympy.combinatorics as sc
from sympy.combinatorics.graphs import Graph  # SymPy ≥ 1.12

G = Graph([(0,1),(1,2),(2,3),(3,1)])   # contains triangle 1-2-3
print("Acyclic?", G.is_acyclic())      # False

T = Graph([(0,1),(1,2),(2,3)])         # path graph — a tree
print("Acyclic?", T.is_acyclic())      # True
print("|E| == |V|-1:", T.number_of_edges() == T.number_of_vertices() - 1)
