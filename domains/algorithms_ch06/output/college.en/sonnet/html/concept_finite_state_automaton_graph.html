Finite State Automaton Graph

Definition. A finite state automaton (FSA) is a tuple $M = (Q, \Sigma, \delta, q_0, F)$, where $Q$ is a finite nonempty set of states, $\Sigma$ is a finite input alphabet, $\delta : Q \times \Sigma \to Q$ is the transition function, $q_0 \in Q$ is the initial state, and $F \subseteq Q$ is the set of accepting states. The automaton graph of $M$ is the directed graph $G_M = (Q, E)$ with edge set

$$E = \bigl\{\,(q,\, \delta(q,a)) \mid q \in Q,\; a \in \Sigma\bigr\},$$

where each edge is labelled by the symbol $a$ that triggers the transition. Recognising a string $w = a_1 a_2 \cdots a_n \in \Sigma^$ amounts to following the unique walk $q_0, q_1, \ldots, q_n$ in $G_M$ defined by $q_i = \delta(q_{i-1}, a_i)$; the string is accepted* if and only if $q_n \in F$.

Worked Example. Let $Q = \{q_0, q_1, q_2\}$, $\Sigma = \{0, 1\}$, $F = \{q_0\}$, and define $\delta$ by the table

| | $0$ | $1$ | |---|---|---| | $q_0$ | $q_0$ | $q_1$ | | $q_1$ | $q_2$ | $q_0$ | | $q_2$ | $q_1$ | $q_2$ |

This FSA accepts all binary strings whose number of $1$s is divisible by $2$. Tracing $w = 110$: the walk is $q_0 \xrightarrow{1} q_1 \xrightarrow{1} q_0 \xrightarrow{0} q_0$, ending in $q_0 \in F$, so $w$ is accepted. Tracing $w = 10$: the walk $q_0 \xrightarrow{1} q_1 \xrightarrow{0} q_2$ ends outside $F$, so $w$ is rejected.

Key Theorem (Kleene, 1956). A language $L \subseteq \Sigma^$ is accepted by some FSA if and only if $L$ is regular*, i.e., describable by a regular expression. The proof uses the automaton graph directly: the set of strings labelling walks from $q_0$ to any $q \in F$ is shown to satisfy the algebraic closure properties (union, concatenation, Kleene star) that characterise regular languages.

Lab Cell.

import networkx as nx
import matplotlib.pyplot as plt

delta = {('q0','0'):'q0', ('q0','1'):'q1',
         ('q1','0'):'q2', ('q1','1'):'q0',
         ('q2','0'):'q1', ('q2','1'):'q2'}

G = nx.MultiDiGraph()
for (src, sym), tgt in delta.items():
    G.add_edge(src, tgt, label=sym)

pos = nx.spring_layout(G, seed=42)
nx.draw(G, pos, with_labels=True, node_color='lightblue',
        arrows=True, node_size=1500)
edge_labels = {(u, v): d['label']
               for u, v, d in G.edges(data=True)}
nx.draw_networkx_edge_labels(G, pos, edge_labels=edge_labels)
plt.title("Automaton Graph for Parity FSA")
plt.show()
