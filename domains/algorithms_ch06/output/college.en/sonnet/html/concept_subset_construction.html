Subset Construction

Definition. Let $N = (Q, \Sigma, \delta, q_0, F)$ be a nondeterministic finite automaton (NFA), where $Q$ is a finite set of states, $\Sigma$ an input alphabet, $\delta : Q \times \Sigma \to \mathcal{P}(Q)$ the nondeterministic transition function, $q_0 \in Q$ the start state, and $F \subseteq Q$ the set of accepting states. The subset construction (also called the powerset construction) produces a deterministic finite automaton (DFA) $D = (Q', \Sigma, \delta', q_0', F')$ that accepts exactly the same language as $N$. The states of $D$ are elements of the powerset $\mathcal{P}(Q)$: each DFA state represents the set of NFA states reachable under a given input history. Formally,

$$Q' \subseteq \mathcal{P}(Q), \quad q_0' = \varepsilon\text{-closure}(\{q_0\}), \quad \delta'(S, a) = \varepsilon\text{-closure}\!\Bigl(\bigcup_{q \in S} \delta(q, a)\Bigr),$$ $$F' = \{ S \in Q' \mid S \cap F \neq \emptyset \}.$$

The $\varepsilon$-closure of a set $S$ is the set of all NFA states reachable from any state in $S$ by zero or more $\varepsilon$-transitions.

Worked Example. Consider an NFA over $\Sigma = \{0, 1\}$ with states $\{A, B, C\}$, start state $A$, accepting state $C$, and transitions $\delta(A, 0) = \{A, B\}$, $\delta(A, 1) = \{A\}$, $\delta(B, 1) = \{C\}$, all others empty (no $\varepsilon$-transitions). The subset construction begins with $q_0' = \{A\}$. Reading $0$ from $\{A\}$ gives $\{A, B\}$; reading $1$ from $\{A\}$ gives $\{A\}$. From $\{A, B\}$, reading $0$ gives $\{A, B\}$ and reading $1$ gives $\{A, C\}$. Since $C \in F$, the DFA state $\{A, C\}$ is accepting. Continuing until no new subsets appear yields a DFA that recognizes strings over $\{0,1\}$ containing the substring $01$.

Key Theorem (Rabin–Scott, 1959). For every NFA $N$, the subset construction produces a DFA $D$ such that $\mathcal{L}(D) = \mathcal{L}(N)$. If $|Q| = n$, then $|Q'| \leq 2^n$, and this bound is tight in the worst case.

Proof sketch. By induction on input length, one verifies that the DFA state reached after reading $w$ is precisely the set of NFA states reachable from $q_0$ via $w$. Acceptance conditions then coincide by definition of $F'$. $\square$

from itertools import chain

def epsilon_closure(states, eps_map):
    closure = set(states)
    stack = list(states)
    while stack:
        s = stack.pop()
        for t in eps_map.get(s, []):
            if t not in closure:
                closure.add(t); stack.append(t)
    return frozenset(closure)

def subset_construction(Q, Sigma, delta, q0, F, eps_map=None):
    eps_map = eps_map or {}
    start = epsilon_closure({q0}, eps_map)
    dfa, worklist = {}, [start]
    while worklist:
        S = worklist.pop()
        dfa[S] = {}
        for a in Sigma:
            nxt = epsilon_closure(chain.from_iterable(delta.get((q, a), []) for q in S), eps_map)
            dfa[S][a] = nxt
            if nxt not in dfa:
                worklist.append(nxt)
    accepting = {S for S in dfa if S & set(F)}
    return dfa, start, accepting
