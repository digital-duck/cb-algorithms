Concept Book: Intersection Graph

Algorithms Ch06 · Generated by SPL

Payoff

An intersection graph is the natural endpoint of a journey through set families, incidence structures, and combinatorial geometry. Having built the machinery to represent sets, membership, and pairwise relations, we can now encode an entire family of sets as a single graph whose edges carry exactly the information we need: do these two sets share an element?

Definition. Let $\mathcal{F} = \{S_1, S_2, \ldots, S_n\}$ be a finite family of non-empty sets. The intersection graph of $\mathcal{F}$, denoted $\Omega(\mathcal{F})$, is the graph $G = (V, E)$ with vertex set $V = \{1, 2, \ldots, n\}$ and edge set

$$E = \{\{i, j\} : i \neq j \text{ and } S_i \cap S_j \neq \emptyset\}.$$

Every graph is an intersection graph of some family (a classical result due to Marczewski, 1945); the interest lies in restricting the type of sets allowed, which yields geometrically and algorithmically tractable subclasses.

Worked example. Let $S_1 = \{a, b\}$, $S_2 = \{b, c\}$, $S_3 = \{c, d\}$, $S_4 = \{a, d\}$. Then $S_1 \cap S_2 = \{b\} \neq \emptyset$, $S_2 \cap S_3 = \{c\} \neq \emptyset$, $S_3 \cap S_4 = \{d\} \neq \emptyset$, $S_4 \cap S_1 = \{a\} \neq \emptyset$, while $S_1 \cap S_3 = \emptyset$ and $S_2 \cap S_4 = \emptyset$. The intersection graph $\Omega(\mathcal{F})$ is therefore the 4-cycle $C_4$, illustrating how combinatorial structure in the ground set translates directly into graph structure.

Key theorem (Helly, 1923 — one-dimensional case). If $\mathcal{F}$ is a family of intervals on $\mathbb{R}$ and every two members of $\mathcal{F}$ intersect, then $\bigcap_{i=1}^{n} S_i \neq \emptyset$. Equivalently, the intersection graph of an interval family is chordal: every cycle of length four or more possesses a chord. Chordal graphs admit $O(n + m)$ recognition and yield polynomial-time algorithms for problems that are $\mathsf{NP}$-hard on general graphs, including graph coloring and maximum clique.

Lab cell.

from sympy import FiniteSet
from itertools import combinations

sets = {
    "S1": FiniteSet("a", "b"),
    "S2": FiniteSet("b", "c"),
    "S3": FiniteSet("c", "d"),
    "S4": FiniteSet("a", "d"),
}

names = list(sets.keys())
edges = [
    (u, v)
    for u, v in combinations(names, 2)
    if sets[u].intersect(sets[v]) != FiniteSet()
]
print("Vertices:", names)
print("Edges:   ", edges)

Running this cell reproduces the $C_4$ computed above, confirming that symbolic set intersection and graph construction are two faces of the same operation.

The reach of this construction is broad. In scheduling, jobs sharing a machine become adjacent vertices, and graph coloring yields a conflict-free timetable. In computational biology, overlapping DNA fragments define an interval graph whose Hamiltonian path reconstructs the original sequence. In knowledge representation, concepts with overlapping extension form a concept lattice whose covering relation is precisely the intersection graph of the associated extent sets. In network design, frequency bands that interfere share an edge, and the chromatic number of the resulting graph is the minimum number of non-interfering channels required.

Each application reduces a domain-specific conflict or overlap problem to a graph-theoretic question that centuries of combinatorics have already answered. The intersection graph is the common language.
