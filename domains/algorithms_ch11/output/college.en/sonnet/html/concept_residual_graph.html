Residual Graph

Definition. Let $G = (V, E)$ be a directed graph in which each edge $(u, v) \in E$ carries a non-negative capacity $c(u, v) \geq 0$. Given a feasible flow $f$ on $G$, the residual graph $G_f = (V, E_f)$ is a directed graph on the same vertex set whose edges encode the remaining freedom to route additional flow. For every edge $(u, v) \in E$, define the residual capacity

$$c_f(u, v) = c(u, v) - f(u, v).$$

The edge set $E_f$ contains the forward edge $(u, v)$ whenever $c_f(u, v) > 0$, and the backward edge $(v, u)$ whenever $f(u, v) > 0$. The backward edge represents the ability to cancel previously committed flow, effectively "un-routing" up to $f(u, v)$ units along the original direction.

Worked Example. Consider the network with vertices $\{s, a, t\}$ and edges $s \to a$ with capacity $4$, and $a \to t$ with capacity $3$. Suppose the current flow sends $f(s,a) = 3$ and $f(a,t) = 3$.

  • Forward edge $s \to a$: residual capacity $4 - 3 = 1$.
  • Backward edge $a \to s$: residual capacity $3$ (can cancel up to $3$ units).
  • Forward edge $a \to t$: residual capacity $3 - 3 = 0$ (omitted from $G_f$).
  • Backward edge $t \to a$: residual capacity $3$.

    • Thus $G_f$ contains $s \to a$ (capacity 1), $a \to s$ (capacity 3), and $t \to a$ (capacity 3). An augmenting path is any $s$-to-$t$ path in $G_f$; the Ford–Fulkerson algorithm iteratively finds such paths and pushes flow along them until none remains.

    Key Theorem (Max-Flow Min-Cut). The value of a maximum flow from $s$ to $t$ equals the capacity of a minimum $s$-$t$ cut. The residual graph certifies optimality: a flow $f^$ is maximum if and only if $G_{f^}$ contains no augmenting path from $s$ to $t$.

    Lab Cell.

    import sympy as sp
from sympy.combinatorics.named_groups import *

# Represent residual capacities symbolically
c, f_val = sp.symbols('c f', nonneg=True)

residual_forward  = sp.Max(c - f_val, 0)
residual_backward = sp.Max(f_val,     0)

print("Forward residual :", residual_forward)
print("Backward residual:", residual_backward)

# Concrete instance: c=4, f=3
print(residual_forward.subs([(c, 4), (f_val, 3)]))   # 1
print(residual_backward.subs([(c, 4), (f_val, 3)]))  # 3
