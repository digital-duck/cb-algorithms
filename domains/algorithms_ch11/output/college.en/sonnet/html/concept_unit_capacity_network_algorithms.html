Unit Capacity Network Algorithms

Definition. A unit capacity network is a directed graph $G = (V, E)$ equipped with a capacity function $c : E \to \{0, 1\}$, a designated source $s \in V$, and a sink $t \in V$. Because every edge carries capacity exactly one, the maximum number of edge-disjoint $s$-$t$ paths equals the maximum flow value, a correspondence made precise by Menger's theorem. The structural uniformity of unit capacities allows faster flow algorithms than the general case: whereas Edmonds–Karp runs in $O(VE^2)$ time on arbitrary networks, unit capacity networks admit an $O(E \cdot \sqrt{V})$ bound via the Hopcroft–Karp style of blocking-flow analysis.

Worked Example. Consider the network below with $V = \{s, a, b, c, t\}$ and edges

$$s \to a,\quad s \to b,\quad a \to c,\quad b \to c,\quad a \to t,\quad c \to t,$$

each with capacity 1. We seek the maximum $s$-$t$ flow.

Iteration 1. Build the level graph by BFS from $s$: levels are $\ell(s)=0$, $\ell(a)=\ell(b)=1$, $\ell(c)=2$, $\ell(t)=2$. A blocking flow saturates paths $s \to a \to t$ and $s \to b \to c \to t$, contributing flow value 2.

Iteration 2. Residual BFS finds no augmenting path of length 3 or shorter. The algorithm terminates with maximum flow $f^* = 2$.

By Menger's theorem, there exist exactly 2 edge-disjoint paths, confirming the result.

Key Theorem (Dinic on Unit Networks). Let $G$ be a unit capacity network with $|V| = n$ and $|E| = m$. Dinic's algorithm computes a maximum flow in $O(m \sqrt{n})$ time. The argument rests on two facts: (i) after each blocking-flow phase the shortest augmenting path length strictly increases, and (ii) in unit networks the blocking flow in a level graph of depth $d$ can be computed in $O(m)$ time, and the number of phases before the path length exceeds $2\sqrt{n}$ is at most $\sqrt{n}$. Phases beyond $\sqrt{n}$ contribute at most $\sqrt{n}$ additional units of flow, each found by a single DFS in $O(m)$.

from sympy import zeros

# Adjacency matrix for the worked example (rows = from, cols = to)
# Nodes: 0=s, 1=a, 2=b, 3=c, 4=t
n = 5
cap = zeros(n, n)
edges = [(0,1),(0,2),(1,3),(2,3),(1,4),(3,4)]
for u, v in edges:
    cap[u, v] = 1

def bfs_level(cap, s, t, n):
    from collections import deque
    level = [-1]*n; level[s] = 0; q = deque([s])
    while q:
        u = q.popleft()
        for v in range(n):
            if cap[u,v] > 0 and level[v] < 0:
                level[v] = level[u]+1; q.append(v)
    return level if level[t] >= 0 else None

print(bfs_level(cap, 0, 4, n))  # [0, 1, 1, 2, 2]
