Shortest Augmenting Path

Definition. Let $G = (V, E)$ be a directed network with source $s$, sink $t$, and non-negative integer capacities $c : E \to \mathbb{Z}_{\geq 0}$. Given a flow $f$, the residual graph $G_f$ contains a forward edge $(u,v)$ with residual capacity $c_f(u,v) = c(u,v) - f(u,v)$ whenever $c(u,v) - f(u,v) > 0$, and a backward edge $(v,u)$ with capacity $f(u,v)$ whenever $f(u,v) > 0$. An augmenting path is any simple $s$-$t$ path in $G_f$. Among all such paths, a shortest augmenting path is one that minimises the number of edges (hops). The Edmonds–Karp algorithm implements the Ford–Fulkerson method by selecting a shortest augmenting path at every iteration, discovered via breadth-first search (BFS) on $G_f$.

Worked Example. Consider the network below with $s = 1$, $t = 4$, and edges $(1,2,10)$, $(1,3,10)$, $(2,3,1)$, $(2,4,10)$, $(3,4,10)$ (format: $(u,v,c)$). Initially $f \equiv 0$.

  • Iteration 1. BFS finds $s \to 2 \to 4$ (length 2). Bottleneck capacity $= \min(10,10)=10$. Push 10 units.
  • Iteration 2. BFS finds $s \to 3 \to 4$ (length 2). Bottleneck $= 10$. Push 10 units.
  • Iteration 3. No $s$-$t$ path remains in $G_f$. Total flow $= 20$.

    • Key Theorem (Edmonds–Karp Complexity). In any network with $|V|$ vertices and $|E|$ edges, the Edmonds–Karp algorithm terminates after at most $O(|V||E|)$ augmenting steps, giving an overall time complexity of $O(|V||E|^2)$. The proof relies on showing that the BFS distance $d_f(s,v)$ is monotonically non-decreasing across iterations for every vertex $v$. Because distances are bounded by $|V|-1$ and each edge can become critical (i.e., saturated) at most $O(|V|)$ times before the distance bound forces it out of the shortest-path tree, the number of augmentations is finite.

    Lab Cell.

    import networkx as nx

G = nx.DiGraph()
edges = [(1,2,10),(1,3,10),(2,3,1),(2,4,10),(3,4,10)]
for u, v, cap in edges:
    G.add_edge(u, v, capacity=cap)

flow_value, flow_dict = nx.maximum_flow(G, 1, 4, flow_func=nx.algorithms.flow.edmonds_karp)
print("Max flow:", flow_value)          # Expected: 20
print("Flow on each edge:", flow_dict)
