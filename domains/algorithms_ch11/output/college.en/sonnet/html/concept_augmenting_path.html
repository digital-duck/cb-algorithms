Augmenting Path

Definition. Let $G = (V, E)$ be a directed graph with a capacity function $c : E \to \mathbb{R}_{\geq 0}$ and a flow function $f : E \to \mathbb{R}_{\geq 0}$ satisfying $0 \leq f(e) \leq c(e)$ for every edge $e$. Given a source $s \in V$ and a sink $t \in V$, the residual graph $G_f = (V, E_f)$ is constructed by including a forward edge $u \to v$ with residual capacity $c(u,v) - f(u,v) > 0$ whenever flow can be increased, and a backward edge $v \to u$ with residual capacity $f(u,v) > 0$ whenever flow can be cancelled. An augmenting path is any simple path from $s$ to $t$ in $G_f$.

The bottleneck capacity of an augmenting path $P$ is

$$\delta(P) = \min_{e \in P} r(e),$$

where $r(e)$ denotes the residual capacity of edge $e$. Sending $\delta(P)$ additional units of flow along $P$ increases the total flow value by exactly $\delta(P)$ without violating any capacity constraint.

Worked example. Consider the network with edges $s \to u$, $s \to v$, $u \to t$, $v \to t$, and $u \to v$, all with capacity $10$, and suppose the current flow assigns $f(s \to u) = 10$, $f(u \to t) = 7$, $f(u \to v) = 3$, $f(v \to t) = 3$, $f(s \to v) = 0$. The total flow is $|f| = 7 + 3 = 10$. In $G_f$, the backward edge $u \to s$ has residual capacity $10$, the forward edge $s \to v$ has residual capacity $10$, and $v \to t$ has residual capacity $7$. The path $s \to v \to t$ is an augmenting path with $\delta = \min(10, 7) = 7$, raising $|f|$ to $17$.

Theorem (Ford–Fulkerson). A flow $f$ is a maximum flow if and only if there is no augmenting path from $s$ to $t$ in $G_f$.

Proof sketch. By the max-flow min-cut theorem, $|f|$ equals the capacity of every minimum $s$-$t$ cut. If an augmenting path exists, $|f|$ can be strictly increased, so $f$ is not maximum. Conversely, if no augmenting path exists, define the cut $S = \{v \in V : v \text{ is reachable from } s \text{ in } G_f\}$; every edge crossing from $S$ to $V \setminus S$ is saturated, so $|f|$ equals the cut capacity, confirming maximality. $\square$

from sympy import symbols, Rational

# Represent a tiny residual graph as a dict of dicts: r[u][v] = residual capacity
r = {'s': {'u': 0, 'v': 10},
     'u': {'s': 10, 't': 3, 'v': 7},
     'v': {'u': 0, 't': 7},
     't': {}}

def bfs_augmenting_path(r, s, t):
    from collections import deque
    parent = {s: None}
    queue = deque([s])
    while queue:
        node = queue.popleft()
        for nbr, cap in r[node].items():
            if nbr not in parent and cap > 0:
                parent[nbr] = node
                if nbr == t:
                    path = []
                    while nbr is not None:
                        path.append(nbr)
                        nbr = parent[nbr]
                    return list(reversed(path))
                queue.append(nbr)
    return None

print(bfs_augmenting_path(r, 's', 't'))  # ['s', 'v', 't']
