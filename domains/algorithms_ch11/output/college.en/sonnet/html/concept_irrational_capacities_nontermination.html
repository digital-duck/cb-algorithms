Irrational Capacities Nontermination

Definition. A capacity on a finite set $X = \{x_1, \dots, x_n\}$ is a set function $\nu : 2^X \to [0, 1]$ satisfying $\nu(\emptyset) = 0$, $\nu(X) = 1$, and monotonicity: $A \subseteq B \Rightarrow \nu(A) \le \nu(B)$. A capacity is called irrational if there exists some $A \subseteq X$ for which $\nu(A) \notin \mathbb{Q}$. Such capacities arise naturally in cooperative game theory, Choquet integration, and multi-criteria decision analysis whenever weights are derived from geometric or transcendental quantities.

Worked Example. Let $X = \{a, b\}$ and define

$$\nu(\{a\}) = \tfrac{1}{\sqrt{2}}, \quad \nu(\{b\}) = 1 - \tfrac{1}{\sqrt{2}}, \quad \nu(\{a,b\}) = 1.$$

Consider the greedy algorithm that iteratively subtracts the largest rational approximation $p/q \le \nu(A)$ with $q \le Q$ from each coalition value and checks whether a residual of exactly zero is reached. For the rational capacity $\nu(\{a\}) = 1/2$ the algorithm terminates in one step. For $\nu(\{a\}) = 1/\sqrt{2}$, every rational $p/q$ leaves a nonzero irrational residual $1/\sqrt{2} - p/q \neq 0$, so the algorithm cycles without halt: the residuals form an infinite sequence converging to zero but never reaching it. This is the phenomenon of irrational-capacity nontermination.

Key Theorem (Nontermination of Exact-Residual Algorithms). Let $\nu$ be a capacity on $X$ with at least one irrational value. Any algorithm that terminates only upon producing an exact rational representation of $\nu$ by successive rational subtractions does not terminate.

Proof sketch. Suppose $\nu(A) \in \mathbb{R} \setminus \mathbb{Q}$ for some $A$. At each step the residual is $\nu(A) - \sum_{k=1}^{m} p_k/q_k$, which belongs to $\mathbb{R} \setminus \mathbb{Q}$ because $\mathbb{Q}$ is closed under addition. Hence the termination condition (residual $= 0$) is never satisfied. $\square$

Practical implication. Implementations must replace exact-zero halting with an $\epsilon$-tolerance check, converting exact symbolic loops into finite approximate procedures. The choice of $\epsilon$ introduces a controlled approximation error bounded by $\epsilon$.

Lab Cell (SymPy).

from sympy import sqrt, Rational, N

nu_a = 1 / sqrt(2)          # irrational capacity
residuals = []
approx = Rational(0)

for k in range(1, 8):
    best = max(Rational(p, k) for p in range(k + 1)
               if Rational(p, k) <= nu_a - approx)
    approx += best
    residuals.append(float(nu_a - approx))
    print(f"step {k}: approx = {float(approx):.6f}, residual = {residuals[-1]:.2e}")

Running this cell reveals residuals that shrink but remain strictly positive, demonstrating nontermination empirically before the tolerance threshold is reached.
