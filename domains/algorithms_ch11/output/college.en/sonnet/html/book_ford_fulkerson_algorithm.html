Concept Book: Ford Fulkerson Algorithm

Algorithms Ch11 · Generated by SPL

Payoff

The Ford-Fulkerson algorithm is the natural culmination of this concept-book because it crystallises every preceding idea into a single, executable procedure. A flow network $G = (V, E, c)$ assigns a non-negative capacity $c(u,v)$ to each directed edge; the algorithm seeks a feasible flow $f : E \to \mathbb{R}_{\geq 0}$ satisfying capacity constraints $f(u,v) \leq c(u,v)$, conservation at interior vertices, and skew symmetry $f(u,v) = -f(v,u)$, while maximising the net flow $|f|$ from a designated source $s$ to a sink $t$.

The algorithm. Starting from the zero flow, Ford-Fulkerson repeatedly locates an augmenting path — a directed path from $s$ to $t$ in the residual graph $G_f$, whose edges carry residual capacity $c_f(u,v) = c(u,v) - f(u,v)$ — and pushes flow equal to the path's bottleneck capacity $\delta = \min_{(u,v) \in P} c_f(u,v)$ along it. Iteration continues until no augmenting path exists.

Worked example. Consider the network with vertices $\{s, a, b, t\}$, edges $s \to a$ (capacity $3$), $s \to b$ (capacity $2$), $a \to t$ (capacity $2$), $b \to t$ (capacity $3$), and cross-edge $a \to b$ (capacity $2$). After augmenting along $s \to a \to t$ with $\delta = 2$, then $s \to b \to t$ with $\delta = 2$, no further augmenting path exists. The maximum flow is $|f| = 4$, confirmed by the minimum cut $\{s \to a, s \to b\}$ of capacity $3 + 2 = 5$… wait — capacity $2 + 2 = 4$. The Max-Flow Min-Cut Theorem guarantees $|f^*| = \min_{\text{cut}} c(\text{cut})$.

Key theorem (Max-Flow Min-Cut). For any flow network with integer capacities, $\max |f| = \min_{(S,T)} c(S,T)$, where the minimum ranges over all $s$-$t$ cuts $(S,T)$. When capacities are rational, termination is guaranteed; when capacities are irrational, the algorithm may cycle indefinitely through an infinite sequence of augmentations whose total gain converges to a value strictly below the true maximum.

from sympy import Rational, sqrt
# Residual capacity with irrational weight
phi = (1 + sqrt(5)) / 2          # golden ratio — irrational
cap = {('s','a'): phi, ('a','t'): Rational(1)}
bottleneck = min(cap.values())
print("bottleneck:", bottleneck)  # 1; path still chosen greedily

This boundary — rational versus irrational capacities — is not a footnote. It exposes the algorithm's deepest vulnerability: irrational capacities can cause non-termination, with successive augmentations shrinking by a geometric ratio that never reaches zero. That phenomenon, explored in full in the next chapter, reveals how a deterministic graph procedure intersects the theory of real-number computation and Diophantine approximation. If you have ever wondered why textbooks quietly assume integer weights, the answer lives there — and it is worth the detour.
