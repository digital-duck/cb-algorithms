回溯法

定义。 回溯法(backtracking)是一种递归搜索策略:每次只为解增加一个分量,在每个决策点依次尝试所有可选项,并对每个选项递归地向下探索。若当前的部分解已经违反约束(或不可能扩展为完整解),就剪枝,撤销最近一步选择(即"回溯"),换下一个选项继续。

设部分解为 $x=(x_1,\dots,x_k)$,候选集为 $C(x)$,则通用框架为:

def backtrack(x):
    if is_complete(x):
        record(x); return
    for c in candidates(x):
        if feasible(x, c):      # 剪枝检查
            x.append(c)         # 选择
            backtrack(x)        # 探索
            x.pop()             # 撤销(回溯)

"选择 → 探索 → 撤销"三步是回溯法的核心。它本质上是对解空间树的深度优先遍历,与暴力枚举的区别在于:一旦某个节点不可行,其整棵子树都被跳过。

例题:子集和。 从集合 $\{3,5,6,7\}$ 中选出若干数,使其和为 $15$。

按顺序决定每个数"取"或"不取",记当前和为 $s$:

  • 取 3($s=3$)→ 取 5($s=8$)→ 取 6($s=14$)→ 取 7 得 $21>15$,剪枝;不取 7 得 $14\ne15$,失败。回溯到 6。
  • 不取 6($s=8$)→ 取 7 得 $15$ ✓。找到解 $\{3,5,7\}$。

    • 因为所有数为正,只要 $s>15$ 就可以立即剪枝,这避免了展开大量子树。

    子集和的解空间树(局部):超过目标值的分支被剪枝,成功分支给出解 $\{3,5,7\}$。

    问题求解应用:$n$ 皇后。 在 $n\times n$ 棋盘上放置 $n$ 个皇后,使其互不攻击。逐行放置,第 $r$ 行选择列 $c$,可行条件是:与已放皇后不同列、不同对角线,即对所有 $i $$c\ne c_i,\qquad |c-c_i|\ne r-i.$$ 

    def solve(n):
    cols, res = [], 0
    def bt(r):
        nonlocal res
        if r == n: res += 1; return
        for c in range(n):
            if all(c != cols[i] and abs(c-cols[i]) != r-i for i in range(r)):
                cols.append(c); bt(r+1); cols.pop()
    bt(0)
    return res

    对 $n=8$,朴素枚举需检查 $8^8\approx1.7\times10^7$ 种放法,而回溯法因提前剪枝,只访问约两千多个节点即可找出全部 92 个解。

    复杂度与使用要点。 最坏情况下回溯仍是指数级,例如子集和为 $O(2^n)$,排列问题为 $O(n!)$;其优势依赖于剪枝的强度。设计时应注意:(1)状态必须能被完全撤销;(2)约束检查应尽早进行;(3)合理排序候选项,可更快发现解或更早剪枝。
