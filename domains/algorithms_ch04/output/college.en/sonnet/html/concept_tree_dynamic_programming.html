Tree Dynamic Programming

Definition. Let $T = (V, E)$ be a rooted tree with root $r$, where each vertex $v \in V$ may carry a weight $w(v)$. Tree dynamic programming (Tree DP) is a technique for solving optimization or counting problems on $T$ by defining a state function $f(v, \cdot)$ at each vertex and computing it bottom-up: leaves are base cases, and an internal vertex $v$ with children $c_1, c_2, \ldots, c_k$ aggregates results from all subtrees $T_{c_i}$ before passing a summary value to $v$'s parent. The crucial structural property is that, once all children of $v$ have been processed, their subtrees are independent of each other — a direct consequence of the tree's acyclicity.

Worked Example: Maximum Independent Set on a Tree. An independent set is a subset $S \subseteq V$ such that no two vertices in $S$ are adjacent. We wish to maximize $\sum_{v \in S} w(v)$.

Define two states for each vertex $v$:

$$ f(v, 1) = \text{maximum weight of an independent set in } T_v \text{ that includes } v, $$ $$ f(v, 0) = \text{maximum weight of an independent set in } T_v \text{ that excludes } v. $$

Recurrences.

$$ f(v, 1) = w(v) + \sum_{c \in \text{children}(v)} f(c, 0), $$ $$ f(v, 0) = \sum_{c \in \text{children}(v)} \max\bigl(f(c, 0),\, f(c, 1)\bigr). $$

The answer is $\max(f(r, 0),\, f(r, 1))$.

Key Theorem. Tree DP runs in $O(n)$ time and space on a tree with $n$ vertices. Each vertex is visited exactly once (in a post-order traversal), and each edge is examined exactly once when aggregating a child's result into its parent. Hence both time and space are linear, regardless of the tree's shape.

Lab Cell (SymPy / Python).

from sympy import symbols, Max

def tree_dp(children, weight, root):
    f = {}
    def dfs(v):
        if not children[v]:           # leaf base case
            f[v] = (weight[v], 0)
            return
        for c in children[v]:
            dfs(c)
        f[v] = (
            weight[v] + sum(f[c][1] for c in children[v]),   # include v
            sum(max(f[c]) for c in children[v])              # exclude v
        )
    dfs(root)
    return max(f[root])

# Example: star graph, root=0 connected to leaves 1,2,3
children = {0:[1,2,3], 1:[], 2:[], 3:[]}
weight   = {0:10, 1:5, 2:7, 3:3}
print(tree_dp(children, weight, 0))   # → 15  (pick leaves 1,2,3)

Running this cell confirms the recurrence: selecting all three leaves (total weight 15) beats selecting the root alone (weight 10).
