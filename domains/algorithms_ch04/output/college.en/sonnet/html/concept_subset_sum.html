Subset Sum

Definition. Given a finite set $S = \{a_1, a_2, \ldots, a_n\}$ of integers and a target value $T \in \mathbb{Z}$, the subset sum problem asks whether there exists a subset $A \subseteq S$ such that

$$\sum_{a \in A} a = T.$$

The decision version — does such an $A$ exist? — is one of the canonical NP-complete problems. The optimization variant seeks the subset whose sum is as close to $T$ as possible without exceeding it, and appears in scheduling, cryptography, and resource allocation.

Worked Example. Let $S = \{3, 1, 4, 1, 5\}$ and $T = 9$. We ask: can we select elements that sum exactly to $9$? Observe $\{3, 1, 5\} \subset S$ and $3 + 1 + 5 = 9$. Hence the answer is yes, witnessed by this subset. Note that the element $1$ appears twice in $S$; elements are taken by position, not by value, so both copies are available independently.

Key Theorem (DP Recurrence). Define the Boolean table $\text{dp}[i][s]$, where $0 \le i \le n$ and $0 \le s \le T$, by

$$\text{dp}[i][s] = \begin{cases} \text{True} & \text{if } s = 0, \\ \text{False} & \text{if } i = 0 \text{ and } s > 0, \\ \text{dp}[i-1][s] \lor \text{dp}[i-1][s - a_i] & \text{if } s \ge a_i, \\ \text{dp}[i-1][s] & \text{otherwise.} \end{cases}$$

The answer is $\text{dp}[n][T]$. This recurrence embodies the inclusion–exclusion principle: either $a_i$ is excluded (first branch) or included, reducing the remaining target by $a_i$ (second branch). The time complexity is $O(nT)$ and space complexity $O(nT)$, or $O(T)$ with a rolling array. Because $T$ may be exponential in the input bit-length, this is a pseudo-polynomial algorithm, not a polynomial one.

Lab Cell.

from sympy import symbols, Rational

def subset_sum_dp(S, T):
    dp = [False] * (T + 1)
    dp[0] = True
    for a in S:
        for s in range(T, a - 1, -1):   # traverse right-to-left to avoid reuse
            dp[s] = dp[s] or dp[s - a]
    return dp[T]

S = [3, 1, 4, 1, 5]
T = 9
print(subset_sum_dp(S, T))   # True
print(subset_sum_dp(S, 11))  # False
