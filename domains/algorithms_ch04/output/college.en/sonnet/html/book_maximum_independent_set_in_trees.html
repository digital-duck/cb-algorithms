Payoff

What the Algorithm Achieves

An independent set of a graph $G = (V, E)$ is a subset $S \subseteq V$ such that no two vertices in $S$ are adjacent: for all $u, v \in S$, the edge $\{u, v\} \notin E$. A maximum independent set is one of largest possible cardinality, denoted $\alpha(G)$. On general graphs, finding $\alpha(G)$ is NP-hard; on trees, the dynamic-programming recurrence introduced in this chapter delivers an exact solution in $O(n)$ time. This tractability is the payoff: the tree structure imposes a parent–child ordering that eliminates the combinatorial explosion present in cyclic graphs, allowing each subproblem to be solved exactly once and combined without revisitation.

Worked Example

Consider the path graph $P_5$ with vertices $\{1, 2, 3, 4, 5\}$ and edges $\{12, 23, 34, 45\}$. Root the tree at vertex $1$. Define $\text{dp}[v][0]$ as the size of the maximum independent set in the subtree rooted at $v$ when $v$ is excluded, and $\text{dp}[v][1]$ when $v$ is included. Propagating leaves upward:

$$\text{dp}[v][1] = 1 + \sum_{c \in \text{children}(v)} \text{dp}[c][0], \qquad \text{dp}[v][0] = \sum_{c \in \text{children}(v)} \max\bigl(\text{dp}[c][0],\, \text{dp}[c][1]\bigr).$$

For $P_5$ this yields $\alpha(P_5) = 3$, realized by the set $\{1, 3, 5\}$, which is easily verified by inspection.

Key Theorem

Theorem (Optimal Substructure on Trees). Let $T$ be a tree rooted at $r$, and let $T_v$ denote the subtree rooted at $v$. Then $\alpha(T) = \max\!\bigl(\text{dp}[r][0],\, \text{dp}[r][1]\bigr)$, and the recurrence above computes this value correctly in $\Theta(n)$ time and $\Theta(n)$ space.

Proof sketch. Because $T$ is acyclic, removing the root disconnects its children's subtrees entirely. An optimal solution either includes $r$ — forcing all children to be excluded — or excludes $r$ — allowing each child subtree to be solved independently. These two cases are exhaustive and mutually exclusive, establishing the recurrence's correctness by strong induction on subtree size. $\blacksquare$

Lab Cell

from sympy import symbols
from sympy.combinatorics import PermutationGroup

def max_independent_set_tree(adj, root=0):
    n = len(adj)
    dp = [[0, 0] for _ in range(n)]
    visited = [False] * n

    def dfs(v):
        visited[v] = True
        dp[v][1] = 1
        for c in adj[v]:
            if not visited[c]:
                dfs(c)
                dp[v][1] += dp[c][0]
                dp[v][0] += max(dp[c][0], dp[c][1])

    dfs(root)
    return max(dp[root][0], dp[root][1])

# Path P_5
adj = {0:[1], 1:[0,2], 2:[1,3], 3:[2,4], 4:[3]}
print(max_independent_set_tree(adj))   # Expected: 3
