Edit Distance

Definition. Given two strings $s = s_1 s_2 \cdots s_m$ and $t = t_1 t_2 \cdots t_n$ over an alphabet $\Sigma$, the edit distance (Levenshtein distance) $d(s, t)$ is the minimum number of single-character operations required to transform $s$ into $t$, where the permitted operations are:

  • Insertion: insert a character at any position,
  • Deletion: remove a character at any position,
  • Substitution: replace one character with another.

    • Each operation carries unit cost. More precisely, $d(s, t)$ is defined recursively. Let $D[i][j]$ denote the edit distance between the prefix $s[1{:}i]$ and the prefix $t[1{:}j]$. The recurrence is:

    $$D[i][j] = \begin{cases} i & j = 0 \\ j & i = 0 \\ D[i-1][j-1] & s_i = t_j \\ 1 + \min\!\bigl(D[i-1][j],\; D[i][j-1],\; D[i-1][j-1]\bigr) & s_i \neq t_j \end{cases}$$

    The three terms in the minimum correspond, respectively, to deletion from $s$, insertion into $s$, and substitution.

    Worked example. Compute $d(\texttt{kitten}, \texttt{sitting})$.

    Filling the $7 \times 8$ dynamic-programming table row by row yields $D[6][7] = 3$. The three operations are: substitute $\texttt{k} \to \texttt{s}$, substitute $\texttt{e} \to \texttt{i}$, insert $\texttt{g}$ at the end.

    Key theorem (metric axioms). The function $d$ is a metric on $\Sigma^*$: it satisfies non-negativity ($d(s,t) \ge 0$), identity ($d(s,t)=0 \Leftrightarrow s=t$), symmetry ($d(s,t)=d(t,s)$), and the triangle inequality $d(s,u) \le d(s,t)+d(t,u)$.

    Proof sketch. Non-negativity and identity are immediate from the recurrence. Symmetry follows because every edit sequence from $s$ to $t$ can be reversed (each insertion becomes a deletion and vice versa). The triangle inequality holds because concatenating an optimal sequence from $s$ to $t$ with one from $t$ to $u$ yields a (not necessarily optimal) sequence from $s$ to $u$.

    The algorithm runs in $O(mn)$ time and $O(\min(m,n))$ space (keeping only two rows).

    Lab cell.

    from sympy import symbols, Function

def edit_distance(s, t):
    m, n = len(s), len(t)
    prev = list(range(n + 1))
    for i, cs in enumerate(s, 1):
        curr = [i] + [0] * n
        for j, ct in enumerate(t, 1):
            if cs == ct:
                curr[j] = prev[j - 1]
            else:
                curr[j] = 1 + min(prev[j], curr[j - 1], prev[j - 1])
        prev = curr
    return prev[n]

print(edit_distance("kitten", "sitting"))   # 3
print(edit_distance("sunday", "saturday"))  # 3
