Payoff

Every concept introduced in this book — from the axioms of a metric space to dynamic-programming recurrences — has been a stepping stone toward a single, remarkably practical object: the edit distance between two sequences.

Definition (Edit Distance). Let $\Sigma$ be a finite alphabet and let $s, t \in \Sigma^$. The Levenshtein edit distance $d(s, t)$ is the minimum number of single-character insertions, deletions, and substitutions* required to transform $s$ into $t$. Formally,

$$d(s, t) = \min_{\text{operation sequences } O} |O| \quad \text{such that } O(s) = t.$$

The function $d : \Sigma^ \times \Sigma^ \to \mathbb{Z}_{\geq 0}$ satisfies non-negativity, symmetry, and the triangle inequality, making $(\Sigma^*, d)$ a metric space.

Worked Example. Take $s = \texttt{kitten}$ and $t = \texttt{sitting}$. The classical dynamic-programming table fills an $(m+1)\times(n+1)$ integer matrix $D$ where $D[i][j]$ holds the cost of aligning the first $i$ characters of $s$ with the first $j$ characters of $t$:

$$D[i][j] = \begin{cases} i & j = 0 \\ j & i = 0 \\ D[i-1][j-1] & s[i] = t[j] \\ 1 + \min\!\bigl(D[i-1][j],\; D[i][j-1],\; D[i-1][j-1]\bigr) & \text{otherwise.} \end{cases}$$

Tracing the table yields $d(\texttt{kitten}, \texttt{sitting}) = 3$ (substitute $k \to s$, substitute $e \to i$, insert $g$).

Key Theorem (Optimality of the DP Recurrence). The recurrence above computes $d(s,t)$ exactly, running in $O(mn)$ time and $O(\min(m,n))$ space after row compression. No comparison-based algorithm can do better in the worst case without structural assumptions on $\Sigma$.

Lab Cell.

from sympy import symbols, Matrix

def edit_distance(s, t):
    m, n = len(s), len(t)
    D = [[0]*(n+1) for _ in range(m+1)]
    for i in range(m+1): D[i][0] = i
    for j in range(n+1): D[0][j] = j
    for i in range(1, m+1):
        for j in range(1, n+1):
            cost = 0 if s[i-1] == t[j-1] else 1
            D[i][j] = min(D[i-1][j]+1, D[i][j-1]+1, D[i-1][j-1]+cost)
    return D[m][n], Matrix(D)

dist, table = edit_distance("kitten", "sitting")
print(f"d = {dist}")
print(table)

Edit distance is the natural endpoint of this book because it unifies everything: it is simultaneously an algebraic metric, a combinatorial optimisation problem, and a probabilistic model of noise. With this single number in hand, a practitioner can quantify how far one string is from another and act on that information — correcting a misspelled query, aligning two DNA strands to detect a mutation, computing the diff between two versions of a source file, or measuring translation quality between languages. Each application is, at its core, a question of how much must change for one sequence to become another, and edit distance answers that question with mathematical precision.
