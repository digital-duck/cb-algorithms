Subproblem Evaluation Order

Definition. Given a computational problem $P$ that decomposes into subproblems $P_1, P_2, \ldots, P_n$, the subproblem evaluation order is a total (or partial) ordering $\prec$ on the index set $\{1, \ldots, n\}$ such that whenever the solution to $P_j$ depends on the solution to $P_i$, we require $i \prec j$. Formally, define a directed dependency graph $G = (V, E)$ where $V = \{P_1, \ldots, P_n\}$ and $(P_i, P_j) \in E$ if computing $P_j$ requires the value of $P_i$. A valid evaluation order is any topological ordering of $G$.

If $G$ contains a directed cycle, no valid order exists and the problem formulation is ill-posed. In dynamic programming, correctness depends entirely on guaranteeing that each subproblem is solved before it is referenced.

Worked Example. Consider the Fibonacci recurrence $F(n) = F(n-1) + F(n-2)$, with $F(0) = 0$ and $F(1) = 1$. The dependency graph has edges $(F(k-2), F(k))$ and $(F(k-1), F(k))$ for each $k \geq 2$. A valid evaluation order is simply the natural order $F(0), F(1), F(2), \ldots, F(n)$, since each value depends only on strictly smaller indices. Evaluating in this order ensures every right-hand side is already computed when needed, yielding an $O(n)$ time algorithm with $O(n)$ space (reducible to $O(1)$ by noting only two prior values are required).

Key Theorem (Correctness of Bottom-Up DP). Let $G$ be the dependency graph of a dynamic programming formulation, and let $\sigma = (P_{\sigma(1)}, P_{\sigma(2)}, \ldots, P_{\sigma(n)})$ be a topological ordering of $G$. Then evaluating subproblems in the order $\sigma$ guarantees that every subproblem value is available before it is required. Consequently, the bottom-up algorithm produces the correct solution to $P$ in time proportional to the total work across all subproblems.

Proof sketch. By definition of topological ordering, if $(P_i, P_j) \in E$ then $\sigma^{-1}(i) < \sigma^{-1}(j)$. Hence $P_i$ is evaluated strictly before $P_j$, satisfying every dependency. $\blacksquare$

Lab Cell.

from sympy import symbols, Function, rsolve

n = symbols('n', integer=True, nonneg=True)
F = Function('F')

# Symbolic solution confirms bottom-up order recovers closed form
sol = rsolve(F(n) - F(n-1) - F(n-2), F(n), {F(0): 0, F(1): 1})
print(sol)  # (sqrt(5)/5)*(((1+sqrt(5))/2)**n - ((1-sqrt(5))/2)**n)

Running this cell verifies that the recurrence, solved in the correct evaluation order, recovers Binet's closed-form formula $F(n) = \frac{\phi^n - \psi^n}{\sqrt{5}}$ where $\phi = \frac{1+\sqrt{5}}{2}$.
