What the Algorithm Achieves

The Longest Increasing Subsequence (LIS) problem asks: given a sequence $a_1, a_2, \ldots, a_n$ of real numbers, find the length $L$ of the longest subsequence $a_{i_1} < a_{i_2} < \cdots < a_{i_L}$ where $i_1 < i_2 < \cdots < i_L$. This is not merely an exercise in dynamic programming—it is the canonical example of extracting monotone structure from an arbitrary finite sequence, and it appears wherever order, time, or rank must be respected simultaneously.

The algorithm's power lies in its patience-sorting formulation. Assign each element $a_k$ to the leftmost pile whose top exceeds $a_k$, opening a new pile when none qualifies. At termination, the number of piles equals $L$. The correctness proof rests on a clean invariant: pile tops form a strictly increasing sequence at every step, so the pile count is simultaneously a lower bound (any increasing subsequence requires at least that many piles) and an upper bound (the piles themselves construct a witness). Combined with binary search for pile placement, the runtime is $\Theta(n \log n)$—optimal in the comparison model.

Theorem (Dilworth, 1950). Every finite partially ordered set satisfies

$$\text{(minimum number of chains covering the set)} = \text{(maximum antichain size)},$$

and the LIS length equals the minimum number of non-increasing subsequences needed to partition $a_1, \ldots, a_n$. The patience-sorting argument is a constructive proof of this duality for total orders on sequences.

A Worked Example

Let $\mathbf{a} = (3, 1, 4, 1, 5, 9, 2, 6)$. Processing each element with binary search yields pile tops evolving as $[3] \to [1] \to [1,4] \to [1,4] \to [1,4,5] \to [1,4,5,9] \to [1,2,5,9] \to [1,2,5,6]$, giving $L = 4$. One certificate is the subsequence $(1, 4, 5, 9)$.

from sympy import symbols
# Lab: verify LIS length via patience sorting
import bisect

def lis_length(seq):
    piles = []
    for x in seq:
        pos = bisect.bisect_left(piles, x)
        if pos == len(piles):
            piles.append(x)
        else:
            piles[pos] = x
    return len(piles)

a = [3, 1, 4, 1, 5, 9, 2, 6]
print(lis_length(a))  # 4

The Natural Endpoint

Every concept developed in this book—recurrence relations, memoisation, order-theoretic duality—converges here. LIS is where these threads become load-bearing: it is the primitive behind RNA folding alignment (replace "increasing" with a compatibility predicate), edit-distance algorithms (LCS and LIS are dual under complementary encodings), financial time-series trend detection, and compiler register-allocation via interval scheduling.
