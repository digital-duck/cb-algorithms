Concept Book: Optimal Binary Search Trees

Algorithms Ch04 · Generated by SPL

Payoff

An optimal binary search tree (OBST) is the endpoint of a journey that begins with sorting and ends with dynamic programming. Given a sorted sequence of keys $k_1 < k_2 < \cdots < k_n$ with associated search probabilities $p_i$ and miss probabilities $q_i$ for the gaps between keys, the OBST minimises the expected number of comparisons over all possible binary search trees on those keys. Formally, if $d(v)$ denotes the depth of node $v$ in a tree $T$, the cost functional is

$$E[T] = \sum_{i=1}^{n} p_i \bigl(d(k_i) + 1\bigr) + \sum_{i=0}^{n} q_i \bigl(d(d_i) + 1\bigr),$$

where $d_i$ are the $n+1$ dummy nodes representing unsuccessful searches. The Knuth–Yao algorithm computes the globally minimising tree in $\Theta(n^2)$ time and space via a recurrence on subproblems $e[i,j]$, the expected cost of an optimal tree over keys $k_i,\ldots,k_j$.

Worked example. Consider three keys with $p_1 = 0.5,\, p_2 = 0.1,\, p_3 = 0.05$ and uniform miss probabilities $q_0 = q_1 = q_2 = q_3 = 0.1$. A naive balanced tree places $k_2$ at the root; but because $k_1$ is far more probable, the OBST instead places $k_1$ at the root with $k_2$ and $k_3$ in the right subtree, yielding $E \approx 1.70$ compared with $E \approx 2.05$ for the balanced tree—a 17 % reduction in expected comparisons with no change in worst-case height.

Theorem (Knuth's monotonicity). Let $r[i,j]$ be the index of the root of an optimal tree on $k_i,\ldots,k_j$. Then $r[i,j-1] \le r[i,j] \le r[i+1,j]$ for all valid $i,j$. This monotonicity reduces the naïve $\Theta(n^3)$ recurrence to $\Theta(n^2)$.

from sympy import symbols, Rational, pprint

p = [Rational(1,2), Rational(1,10), Rational(1,20)]
q = [Rational(1,10)] * 4
n = len(p)

e = [[Rational(0)] * (n + 2) for _ in range(n + 2)]
w = [[Rational(0)] * (n + 2) for _ in range(n + 2)]

for i in range(n + 1):
    e[i+1][i] = q[i]
    w[i+1][i] = q[i]

for length in range(1, n + 1):
    for i in range(1, n - length + 2):
        j = i + length - 1
        e[i][j] = None
        w[i][j] = w[i][j-1] + p[j-1] + q[j]
        for r in range(i, j + 1):
            t = e[i][r-1] + e[r+1][j] + w[i][j]
            if e[i][j] is None or t < e[i][j]:
                e[i][j] = t

pprint(e[1][n])   # expected cost of the OBST

Because the OBST framework is domain-agnostic—it requires only keys, a total order, and access probabilities—it is the natural culmination of this text. Wherever a retrieval structure must be tuned to a known or estimated frequency distribution, the OBST is the principled choice, not a heuristic one.

To see this power in practice, choose one application that interests you most and work through how its frequency distribution is estimated, how the Knuth–Yao recurrence is instantiated, and what performance guarantee the resulting tree carries. That investigation will transform the abstract recurrence into a living engineering tool.
