What Text Segmentation Achieves

Text segmentation is the process of partitioning a continuous character sequence $S = s_1 s_2 \cdots s_n$ into a sequence of meaningful units $W = (w_1, w_2, \ldots, w_k)$ such that the concatenation $w_1 \cdot w_2 \cdots w_k = S$ and each $w_i$ belongs to a linguistically or statistically coherent class. Formally, a segmentation defines a monotone index sequence $0 = i_0 < i_1 < \cdots < i_k = n$ where $w_j = s_{i_{j-1}+1} \cdots s_{i_j}$. The problem is non-trivial because natural language contains no universal delimiter: word boundaries in English are whitespace-demarcated, yet sentence boundaries require syntactic inference, and languages such as Chinese, Japanese, and Thai carry no whitespace at all.

The achievement of text segmentation is precisely this: it transforms an unstructured byte stream into a discrete symbolic sequence over which every subsequent layer of linguistic and mathematical analysis can operate. Without it, operations as elementary as frequency counting are ill-defined.

Worked Example

Consider the Thai string "แมวกินปลา" (meaning "the cat eats fish"). A naïve whitespace splitter returns one token. A maximum-matching segmenter operating over a lexicon $\mathcal{L}$ applies a greedy scan: at each position $i$, it selects the longest prefix $s_i \cdots s_j$ such that $s_i \cdots s_j \in \mathcal{L}$, yielding the partition $\langle$แมว, กิน, ปลา$\rangle$. The cost of this segmentation can be measured as the negative log-likelihood under a unigram language model:

$$\mathcal{C}(W) = -\sum_{j=1}^{k} \log P(w_j).$$

Optimal segmentation minimises $\mathcal{C}(W)$ over all valid partitions, a task solved exactly by dynamic programming in $O(n \cdot L_{\max})$ time, where $L_{\max}$ is the maximum lexicon entry length.

Key Theorem

Optimal substructure of segmentation. Let $\text{OPT}(i)$ denote the minimum cost segmentation of $s_1 \cdots s_i$. Then:

$$\text{OPT}(i) = \min_{\substack{j < i \\ s_{j+1}\cdots s_i \in \mathcal{L}}} \bigl[\text{OPT}(j) + \log P(s_{j+1}\cdots s_i)^{-1}\bigr].$$

This recurrence guarantees that a globally optimal segmentation is assembled from locally optimal sub-problems, justifying the dynamic-programming approach and bounding its complexity.

Lab Cell (SymPy)

from sympy import symbols, Min, oo

# Encode a toy cost table for demonstration
costs = {'cat': 1.2, 'cats': 1.8, 'at': 2.1, 's': 3.0}
s = "cats"
n = len(s)
OPT = [oo] * (n + 1)
OPT[0] = 0

for i in range(1, n + 1):
    for token, c in costs.items():
        L = len(token)
        if i >= L and s[i-L:i] == token:
            OPT[i] = min(OPT[i], OPT[i-L] + c)

print(f"Minimum segmentation cost: {OPT[n]}")  # → 1.2  (["cat","s"] vs ["cats"])

Invitation

Text segmentation is not a terminal destination but a foundation. Every application that processes language at scale — information retrieval, machine translation, sentiment analysis, knowledge-graph construction — begins with a segmented token stream. Among these, information retrieval offers perhaps the most immediate and measurable payoff: the quality of an inverted index, and therefore the relevance of every search result a user ever sees, is determined directly by the segmentation decisions examined in this chapter. The next chapter invites you to build a working retrieval engine from first principles, tracing how each segmentation choice propagates through indexing, query parsing, and ranked retrieval.
