Optimal Binary Search Trees

Definition. Given a sorted sequence of keys $k_1 < k_2 < \cdots < k_n$ with associated search probabilities $p_i = P(\text{search hits } k_i)$ and miss probabilities $q_j = P(\text{search falls in gap } (k_j, k_{j+1}))$, an optimal binary search tree (OBST) is a BST that minimises the expected number of comparisons:

$$E[\text{cost}] = \sum_{i=1}^{n} (d_i + 1)\,p_i + \sum_{j=0}^{n} (d_j' + 1)\,q_j,$$

where $d_i$ is the depth of key node $i$ and $d_j'$ is the depth of dummy leaf $j$. Equivalently, placing a node at depth $d$ contributes $d+1$ to the expected cost because the root itself requires one comparison.

Worked Example. Consider $n = 3$ keys with $p_1 = 0.3,\; p_2 = 0.1,\; p_3 = 0.1$ and miss probabilities $q_0 = q_1 = q_2 = q_3 = 0.1$. The total probability sums to $1$. Among all five structurally distinct BSTs on three keys, placing $k_1$ at the root (with $k_2, k_3$ in the right subtree and $k_2$ as the right child of $k_1$) yields expected cost $2.0$, whereas the alphabetically balanced tree rooted at $k_2$ yields $1.9$. Even though $k_1$ has the highest individual probability, the balanced placement wins because it reduces costs for the two high-probability miss regions.

Key Theorem (Knuth, 1971). Let $e[i,j]$ denote the expected cost of an OBST over keys $k_{i+1}, \ldots, k_j$ and let $w[i,j] = \sum_{l=i}^{j} p_l + \sum_{l=i}^{j} q_l$ be the total probability mass. The recurrence

$$e[i,j] = \min_{i < r \leq j}\bigl\{e[i,r-1] + e[r,j]\bigr\} + w[i,j]$$

with base cases $e[i,i] = q_i$ solves the problem in $\Theta(n^2)$ time (improving the naïve $\Theta(n^3)$ by exploiting the monotone root property: if $r^[i,j]$ is the optimal root, then $r^[i,j-1] \leq r^[i,j] \leq r^[i+1,j]$).

from sympy import symbols, Rational, Min

def obst(p, q):
    n = len(p)
    e = [[Rational(0)] * (n + 1) for _ in range(n + 2)]
    w = [[Rational(0)] * (n + 1) for _ in range(n + 2)]
    for i in range(n + 1):
        e[i + 1][i] = q[i];  w[i + 1][i] = q[i]
    for length in range(1, n + 1):
        for i in range(1, n - length + 2):
            j = i + length - 1
            w[i][j] = w[i][j - 1] + p[j - 1] + q[j]
            e[i][j] = min(e[i][r - 1] + e[r + 1][j] for r in range(i, j + 1)) + w[i][j]
    return e[1][n]

p = [Rational(3,10), Rational(1,10), Rational(1,10)]
q = [Rational(1,10)] * 4
print("Minimum expected cost:", obst(p, q))
