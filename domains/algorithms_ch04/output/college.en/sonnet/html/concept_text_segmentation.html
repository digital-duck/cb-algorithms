Text Segmentation

Definition. Text segmentation is the process of partitioning a character sequence $S = c_1 c_2 \cdots c_n$ into a sequence of non-overlapping, contiguous subsequences (segments) $S = w_1 \cdot w_2 \cdots w_k$, where each $w_i$ satisfies membership in a target unit class (characters, tokens, sentences, or paragraphs). Formally, given a vocabulary $\mathcal{V}$ and a string $S$, segmentation finds a sequence of indices $0 = i_0 < i_1 < \cdots < i_k = n$ such that each substring $w_j = c_{i_{j-1}+1} \cdots c_{i_j}$ is a valid unit. The segmentation is ambiguous when multiple valid partitions exist; resolving ambiguity requires a scoring function, typically a language model probability $P(w_1, w_2, \ldots, w_k)$.

Worked Example. Consider the string $S = \texttt{"unbelievable"}$. A greedy maximum-match algorithm scans left-to-right, always selecting the longest prefix that belongs to $\mathcal{V}$. Suppose $\mathcal{V}$ contains $\{\texttt{un}, \texttt{believe}, \texttt{able}, \texttt{unbelievable}\}$. The algorithm first checks $\texttt{unbelievable} \in \mathcal{V}$: match found, so the segmentation is the single token $[\texttt{unbelievable}]$. If $\texttt{unbelievable} \notin \mathcal{V}$, it backtracks to $\texttt{un}$, then continues from position 3, yielding $[\texttt{un}, \texttt{believe}, \texttt{able}]$. The two segmentations encode different semantic granularities, illustrating why vocabulary design critically determines downstream meaning.

Key Theorem (Viterbi Optimality). Let $P(w_1, \ldots, w_k) = \prod_{j=1}^{k} P(w_j \mid w_{j-1})$ be a bigram model. The segmentation maximizing this probability can be found in $O(n \cdot L)$ time via dynamic programming, where $L = \max_j |w_j|$. Define $\delta(i) = \max_{1 \le \ell \le L} \bigl[\delta(i - \ell) + \log P(c_{i-\ell+1}\cdots c_i)\bigr]$. The optimal segmentation is recovered by backtracking through the argmax pointers. This is the Viterbi segmentation, guaranteeing global optimality under the model.

import sympy as sp
from sympy import Function, Symbol

# Demonstrate dynamic-programming segmentation symbolically
def viterbi_segment(s, vocab, log_prob):
    n = len(s)
    dp = [-sp.oo] * (n + 1)
    back = [None] * (n + 1)
    dp[0] = 0
    for i in range(1, n + 1):
        for w in vocab:
            l = len(w)
            if i >= l and s[i-l:i] == w:
                score = dp[i - l] + log_prob.get(w, -sp.oo)
                if score > dp[i]:
                    dp[i], back[i] = score, i - l
    # Reconstruct
    tokens, pos = [], n
    while pos > 0:
        tokens.append(s[back[pos]:pos])
        pos = back[pos]
    return list(reversed(tokens))

vocab     = {"un", "believe", "able", "unbelievable"}
log_p     = {"un": -1.2, "believe": -0.8, "able": -1.0, "unbelievable": -0.5}
result    = viterbi_segment("unbelievable", vocab, log_p)
print(result)   # ['unbelievable']
