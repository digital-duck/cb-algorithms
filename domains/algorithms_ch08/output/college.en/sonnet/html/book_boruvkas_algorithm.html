Concept Book: Boruvkas Algorithm

Algorithms Ch08 · Generated by SPL

Payoff

Borůvka's algorithm solves the minimum spanning tree (MST) problem: given a weighted connected graph $G = (V, E, w)$ with $w : E \to \mathbb{R}$, find a spanning tree $T \subseteq E$ such that $\sum_{e \in T} w(e)$ is minimized. What distinguishes Borůvka's approach from those of Kruskal and Prim is its simultaneous selection of cheapest edges across all components — a structural property that makes it the natural endpoint of a chapter built on component merging, graph connectivity, and greedy invariants.

The algorithm. Initialize each vertex as its own component. In each phase, every component independently selects the minimum-weight edge crossing its boundary to a distinct component. All such edges are added to the forest, merging components. Because each phase at least halves the number of components, the total number of phases is $O(\log |V|)$, yielding an overall complexity of $O(|E| \log |V|)$.

Worked example. Consider $G$ with vertices $\{a, b, c, d\}$ and edges $ab = 1,\ ac = 4,\ bc = 2,\ bd = 5,\ cd = 3$. In Phase 1, component $\{a\}$ picks $ab$ (weight 1), $\{b\}$ picks $ab$ (weight 1), $\{c\}$ picks $bc$ (weight 2), $\{d\}$ picks $cd$ (weight 3). After deduplication, edges $ab$ and $bc$ merge $\{a,b,c\}$; edge $cd$ joins $d$ to $c$, yielding the single tree $\{ab, bc, cd\}$ with total weight $1 + 2 + 3 = 6$.

Key theorem (Cut Property). For any partition of $V$ into two non-empty sets $S$ and $V \setminus S$, the minimum-weight edge crossing the cut belongs to every MST (assuming distinct edge weights). Each component boundary in Borůvka's algorithm is precisely such a cut, so every selected edge is MST-safe — the greedy choice is globally optimal.

import sympy as sp
from sympy.combinatorics.prufer import Prufer

# Encode the example MST via its Prüfer sequence
# Vertices 0=a,1=b,2=c,3=d; MST edges: (0,1),(1,2),(2,3)
prufer_seq = [1, 2]          # encodes a path graph on 4 nodes
T = Prufer(prufer_seq)
print("MST edge list:", T.tree_repr)   # [(0,1),(1,2),(2,3)]
print("Tree edges:", len(T.tree_repr), "== n-1:", 4-1)

Borůvka's algorithm is more than an efficient MST routine; it is the archetype of parallel greedy design. Every phase can be executed in $O(|E|)$ work with processors operating concurrently on disjoint components — a property that makes it foundational in distributed network provisioning, VLSI layout, and approximation schemes for NP-hard clustering problems. The simultaneous-selection structure also underpins modern randomized MST algorithms that achieve near-linear expected time.
