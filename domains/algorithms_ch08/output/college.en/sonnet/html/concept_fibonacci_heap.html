Fibonacci Heap

Definition. A Fibonacci heap is a collection of heap-ordered trees satisfying the min-heap property: every node's key is no less than its parent's key. Unlike a binary heap, the trees need not be complete or even binary; their shapes are left unconstrained until a consolidation step is triggered. The heap maintains a pointer to the minimum-key node and a doubly-linked circular list of tree roots. Each node $x$ stores a key $x.\mathit{key}$, a degree $x.\mathit{degree}$ (number of children), a Boolean $x.\mathit{mark}$ (whether it has lost a child since it last became someone's child), and pointers to parent, one child, and two siblings.

The heap supports the following operations with the amortised costs shown, proved via the potential method with $\Phi = t + 2m$, where $t$ is the number of trees and $m$ is the number of marked nodes:

| Operation | Amortised cost | |---|---| | Insert | $O(1)$ | | Find-min | $O(1)$ | | Union | $O(1)$ | | Extract-min | $O(\log n)$ | | Decrease-key | $O(1)$ | | Delete | $O(\log n)$ |

Worked Example. Start with an empty Fibonacci heap and insert keys $3, 7, 2, 5$. Each insertion places a singleton tree into the root list in $O(1)$ time; the minimum pointer tracks key $2$. Now call Extract-min: node $2$ is removed, its children are spliced into the root list, and consolidation runs. During consolidation, trees are linked so that no two roots share the same degree, repeatedly making the larger-key root a child of the smaller. After consolidation the root list contains trees of distinct degrees, and the new minimum pointer finds key $3$.

Key Theorem (Degree Bound). In a Fibonacci heap on $n$ nodes, every node's degree satisfies $\deg(x) \le \lfloor \log_\phi n \rfloor$, where $\phi = \tfrac{1+\sqrt{5}}{2}$ is the golden ratio. The proof exploits the fact that the $k$-th child of any node was linked when it had degree $\ge k-1$, so the subtree size satisfies $s_k \ge F_{k+2}$, the $(k+2)$-th Fibonacci number, giving $n \ge \phi^k$ and hence $k \le \log_\phi n$.

import heapq          # stdlib min-heap for comparison
from sympy import fibonacci, log, sqrt, Rational, simplify

phi = (1 + sqrt(5)) / 2

# Verify degree bound: for n nodes, max degree <= floor(log_phi(n))
for n in [10, 100, 1000]:
    max_deg = int(log(n, phi))
    print(f"n={n:4d}  max degree <= {max_deg}  "
          f"F({max_deg+2}) = {fibonacci(max_deg+2)}")

Running this cell confirms that $F_{k+2} \le n$ at the boundary degree, grounding the abstract bound in explicit Fibonacci numbers.
