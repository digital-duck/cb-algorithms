Jarník's Algorithm

Definition. Let $G = (V, E, w)$ be a connected, weighted, undirected graph where $w : E \to \mathbb{R}$. A minimum spanning tree (MST) of $G$ is a spanning subgraph $T \subseteq E$ that is acyclic, connects all vertices, and minimizes $w(T) = \sum_{e \in T} w(e)$. Jarník's algorithm (independently rediscovered by Prim and Dijkstra) grows an MST greedily from a single source vertex by repeatedly annexing the cheapest edge that crosses the cut between the current tree and the remaining vertices.

Formally, maintain a set $S \subseteq V$ of tree vertices (initially $S = \{s\}$ for an arbitrary source $s$) and a priority queue $\mathcal{Q}$ keyed on the minimum-weight edge connecting each vertex in $V \setminus S$ to $S$. At each step, extract the vertex $u^ = \arg\min_{u \in V \setminus S} \text{key}(u)$, add $u^$ to $S$, and relax the keys of its neighbors still in $V \setminus S$.

Worked Example. Consider the graph with vertices $\{A, B, C, D\}$ and edges $AB = 4,\; AC = 1,\; BC = 2,\; BD = 5,\; CD = 3$. Starting from $A$:

| Step | $S$ | Edge added | Cost | |------|-----|-----------|------| | 1 | $\{A, C\}$ | $AC$ | 1 | | 2 | $\{A, C, B\}$ | $BC$ | 2 | | 3 | $\{A, C, B, D\}$ | $CD$ | 3 |

The MST has total weight $1 + 2 + 3 = 6$.

Key Theorem (Correctness). Jarník's algorithm produces a minimum spanning tree.

Proof sketch. The correctness follows from the Cut Property: for any cut $(S, V \setminus S)$ of $G$, the minimum-weight crossing edge belongs to some MST. At each iteration, Jarník's algorithm selects exactly such an edge. By induction on $|S|$, the partial tree maintained at every step is a subset of some MST, and upon termination $S = V$, so the result is an MST. $\square$

Complexity. With a binary heap, the algorithm runs in $O((|V| + |E|)\log |V|)$; a Fibonacci heap achieves $O(|E| + |V| \log |V|)$.

Lab Cell (SymPy/NetworkX).

import networkx as nx
G = nx.Graph()
G.add_weighted_edges_from([
    ('A','B',4), ('A','C',1), ('B','C',2), ('B','D',5), ('C','D',3)
])
T = nx.minimum_spanning_tree(G, algorithm='prim')
print(T.edges(data='weight'))   # [('A','C',1), ('B','C',2), ('C','D',3)]
print(sum(d for _,_,d in T.edges(data='weight')))  # 6
