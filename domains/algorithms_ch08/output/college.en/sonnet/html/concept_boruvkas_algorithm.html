Borůvka's Algorithm

Definition. Let $G = (V, E, w)$ be a connected, weighted, undirected graph with $n$ vertices, $m$ edges, and distinct edge weights. A minimum spanning tree (MST) of $G$ is a spanning tree $T \subseteq E$ such that $\sum_{e \in T} w(e)$ is minimized. Borůvka's algorithm constructs an MST by maintaining a forest $F$ that is grown in phases. At the start of each phase, $F$ consists of several connected components. For every component $C$, the algorithm selects the minimum-weight edge crossing from $C$ to any other component and adds it to $F$. Phases repeat until only one component remains.

Formally, let $\mathcal{C}^{(k)}$ denote the partition of $V$ into components after $k$ phases, with $\mathcal{C}^{(0)} = \{\{v\} : v \in V\}$. In phase $k+1$, for each $C \in \mathcal{C}^{(k)}$ define

$$e^*(C) = \arg\min\{w(u,v) : u \in C,\; v \notin C,\; (u,v) \in E\}.$$

All edges $\{e^*(C) : C \in \mathcal{C}^{(k)}\}$ are added to $F$. Because edge weights are distinct, no cycle is introduced.

Worked Example. Consider the graph with vertices $\{A, B, C, D\}$ and weighted edges: $AB = 3$, $AC = 1$, $BC = 4$, $BD = 2$, $CD = 5$.

Phase 1. Each vertex is its own component. Minimum outgoing edges: $A \to AC(1)$, $B \to BD(2)$, $C \to AC(1)$, $D \to BD(2)$. Adding $\{AC, BD\}$ yields two components $\{A,C\}$ and $\{B,D\}$.

Phase 2. Component $\{A,C\}$: cheapest crossing edge is $AB = 3$ or $BC = 4$; minimum is $AB = 3$. Adding $AB$ merges all four vertices into one component. The MST is $\{AC, BD, AB\}$ with total weight $1 + 2 + 3 = 6$.

Theorem (Correctness and Complexity). Borůvka's algorithm produces a minimum spanning tree of $G$ in $O(m \log n)$ time.

Proof sketch. Each selected edge $e^*(C)$ is the lightest edge in the cut $(C, V \setminus C)$; by the Cut Property of MSTs, every such edge belongs to some MST. Since distinct weights guarantee a unique MST, all selected edges lie in it. Each phase at least halves the number of components, so the algorithm terminates in at most $\lceil \log_2 n \rceil$ phases. Scanning all edges per phase costs $O(m)$, giving $O(m \log n)$ total.

import sympy as sp
from sympy.combinatorics import graph_utils  # illustrative

# Represent the example graph as an edge list
edges = [('A','B',3), ('A','C',1), ('B','C',4), ('B','D',2), ('C','D',5)]

def boruvka(vertices, edges):
    parent = {v: v for v in vertices}
    def find(x):
        while parent[x] != x:
            parent[x] = parent[parent[x]]
            x = parent[x]
        return x
    mst, total = [], 0
    num_components = len(vertices)
    while num_components > 1:
        cheapest = {}
        for u, v, w in edges:
            ru, rv = find(u), find(v)
            if ru != rv:
                if ru not in cheapest or cheapest[ru][2] > w:
                    cheapest[ru] = (u, v, w)
                if rv not in cheapest or cheapest[rv][2] > w:
                    cheapest[rv] = (u, v, w)
        for edge in set(map(tuple, cheapest.values())):
            ru, rv = find(edge[0]), find(edge[1])
            if ru != rv:
                parent[ru] = rv
                mst.append(edge)
                total += edge[2]
                num_components -= 1
    return mst, total

vertices = ['A', 'B', 'C', 'D']
mst, cost = boruvka(vertices, edges)
print("MST edges:", mst)
print("Total weight:", cost)  # Expected: 6
