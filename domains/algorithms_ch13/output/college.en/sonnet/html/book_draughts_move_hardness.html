Concept Book: Draughts Move Hardness

What the concept achieves. Throughout this text we have built the machinery to assign a precise numerical measure to the difficulty of a single legal move in the game of draughts (checkers): the quantity $\mathcal{H}(m, P)$, the draughts move hardness of move $m$ from position $P$. Informally, $\mathcal{H}(m, P)$ quantifies how much the optimal value of the game tree changes—and how deep a search must reach—before a rational agent can confidently prefer $m$ over all alternatives. Formally, we define it as

$$\mathcal{H}(m, P) = \min\!\left\{ d \in \mathbb{N} \;\middle|\; V_d(P, m) = V^*(P) \right\},$$

where $V_d(P, m)$ is the $d$-ply minimax value anchored at move $m$ and $V^*(P)$ is the true game-theoretic value of $P$. A hardness of $d = 1$ means the move is immediately dominant; large $d$ signals a tactically murky position demanding exhaustive look-ahead.

Worked example. Consider a four-piece endgame with a forced capture sequence. From position $P_0$ let $m_1$ be the capturing move and $m_2$ be a passive advance. One verifies $V_1(P_0, m_1) = +1$ (an immediate win), so $\mathcal{H}(m_1, P_0) = 1$. For $m_2$, the evaluation oscillates until depth $d = 4$, at which point the opponent's reply tree is fully resolved and $V_4(P_0, m_2) = -1$. Hence $\mathcal{H}(m_2, P_0) = 4$, confirming quantitatively what intuition suggests: capturing is easy, the passive move is hard.

Key theorem (Hardness Ceiling). For any $n$-piece draughts position $P$, $\mathcal{H}(m, P) \leq 2^{O(n)}$. The bound follows from the PSPACE-completeness of generalised draughts: every position is resolved within exponentially many plies, yet the hardness function is computable for fixed board sizes.

Lab cell.

from sympy import symbols, Piecewise, oo

d = symbols('d', positive=True, integer=True)
V_star = 1          # known optimal value for our example
V_d = Piecewise((-1, d < 4), (1, True))   # schematic evaluation function

hardness = min(k for k in range(1, 20) if V_d.subs(d, k) == V_star)
print(f"draughts_move_hardness = {hardness}")   # prints 4

Invitation. The framework developed here is not confined to draughts. Hardness measures of this form reappear in curriculum design (ordering exercises by their resolution depth), in proof-complexity theory (measuring the minimum derivation length needed to certify a tautology), and in neural-network interpretability (quantifying how many transformer layers a model must "unroll" before a decision stabilises).
