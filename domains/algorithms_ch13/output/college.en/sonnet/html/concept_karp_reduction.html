Karp Reduction

Definition. Let $A$ and $B$ be decision problems (languages over $\{0,1\}^$). A Karp reduction (also called a polynomial-time many-one reduction) from $A$ to $B$, written $A \leq_p B$, is a function $f : \{0,1\}^ \to \{0,1\}^*$ satisfying two conditions:

  • $f$ is computable in polynomial time.
  • For every input $x$: $x \in A \iff f(x) \in B$.

    • Intuitively, $f$ translates any instance of $A$ into an instance of $B$ such that "yes" maps to "yes" and "no" maps to "no." If $A \leq_p B$ and $B$ is solvable in polynomial time, then so is $A$—simply compute $f(x)$ and feed it to $B$'s algorithm. Karp reductions are the formal backbone of $\mathbf{NP}$-hardness: a problem $B$ is $\mathbf{NP}$-hard if every problem $A \in \mathbf{NP}$ satisfies $A \leq_p B$.

    Worked Example: 3-SAT $\leq_p$ Independent Set. Given a 3-CNF formula $\varphi$ with $k$ clauses $C_1, \ldots, C_k$, construct a graph $G = (V, E)$ as follows. For each clause $C_i = (\ell_{i,1} \vee \ell_{i,2} \vee \ell_{i,3})$, introduce three vertices $v_{i,1}, v_{i,2}, v_{i,3}$ (one per literal) and connect them in a triangle. Then add an edge between $v_{i,a}$ and $v_{j,b}$ whenever $i \neq j$ and $\ell_{i,a} = \neg \ell_{j,b}$ (conflicting literals). Set the target size $t = k$. The claim is: $\varphi$ is satisfiable $\iff$ $G$ has an independent set of size $k$.

    Proof sketch. ($\Rightarrow$) A satisfying assignment picks at least one true literal per clause; choosing the corresponding vertex yields $k$ vertices with no edges between them—triangle edges are avoided by selecting one vertex per triangle, and conflict edges are avoided because a variable cannot be simultaneously true and false. ($\Leftarrow$) An independent set of size $k$ must contain exactly one vertex per triangle; the literals these represent are mutually consistent and satisfy every clause. The construction runs in $O(k^2)$ time, confirming polynomiality.

    Key Theorem (Cook–Levin, Karp 1972). If $A \leq_p B$ and $B \in \mathbf{P}$, then $A \in \mathbf{P}$. Equivalently, if $A$ is $\mathbf{NP}$-hard and $A \leq_p B$, then $B$ is $\mathbf{NP}$-hard. This transitivity property makes Karp reductions the primary tool for proving new problems hard.

    Lab Cell.

    from sympy import symbols, And, Or, Not, satisfiable

# 3-CNF: (x1 ∨ x2 ∨ ¬x3) ∧ (¬x1 ∨ x3 ∨ x2) ∧ (¬x2 ∨ ¬x3 ∨ x1)
x1, x2, x3 = symbols('x1 x2 x3')
phi = And(Or(x1, x2, ~x3), Or(~x1, x3, x2), Or(~x2, ~x3, x1))
model = satisfiable(phi)
print(model)  # {x1: True, x2: False, x3: False} or similar
