Reduction General Pattern

Definition. A reduction is a systematic transformation that maps an instance of one problem to an instance of a simpler — or already-solved — problem, preserving the essential structure needed to recover the original answer. Formally, given a family of objects $\{P_n\}$ indexed by $n \in \mathbb{N}$, a reduction formula is a relation of the form

$$P_n = f(n) \cdot P_{n-k} + g(n), \quad k \geq 1,$$

where $f$ and $g$ are known functions of $n$. Iterated application drives $n$ toward a base case $P_{n_0}$ that can be evaluated directly, after which the full answer is reconstructed by unwinding the chain.

Worked Example. Consider the integral $I_n = \int_0^{\pi/2} \sin^n x\, dx$. Integration by parts with $u = \sin^{n-1} x$ and $dv = \sin x\, dx$ yields

$$I_n = \frac{n-1}{n}\, I_{n-2}, \quad n \geq 2,$$

with base cases $I_0 = \tfrac{\pi}{2}$ and $I_1 = 1$. To compute $I_6$:

$$I_6 = \frac{5}{6} I_4 = \frac{5}{6} \cdot \frac{3}{4} I_2 = \frac{5}{6} \cdot \frac{3}{4} \cdot \frac{1}{2} I_0 = \frac{15}{48} \cdot \frac{\pi}{2} = \frac{5\pi}{32}.$$

Each step reduces the exponent by $2$ until a base case is reached; the answer is assembled on the way back up.

Key Theorem (Well-Founded Reduction). Let $\{P_n\}$ satisfy a reduction $P_n = f(n) \cdot P_{n-k} + g(n)$ for all $n > n_0$, and suppose $P_{n_0}$ is finite. Then every $P_n$ is well-defined and can be expressed as a closed-form product-sum:

$$P_n = \left(\prod_{j=1}^{m} f(n - (j-1)k)\right) P_{n_0} + \sum_{i=0}^{m-1} g(n - ik) \prod_{j=0}^{i-1} f(n - jk),$$

where $m = \lfloor (n - n_0)/k \rfloor$. The proof follows by induction on $m$: the base case is trivial, and the inductive step substitutes the hypothesis into the recurrence and simplifies.

Lab Cell.

from sympy import symbols, factorial, pi, simplify, Rational

def I(n):
    if n == 0:
        return pi / 2
    if n == 1:
        return 1
    return Rational(n - 1, n) * I(n - 2)

for n in range(0, 9):
    print(f"I_{n} =", simplify(I(n)))

Running this cell verifies the Wallis-type pattern and illustrates how the reduction formula collapses an infinite family of integrals to two base evaluations.
