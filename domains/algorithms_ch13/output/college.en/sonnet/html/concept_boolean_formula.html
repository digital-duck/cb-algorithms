Boolean Formula

Definition. A Boolean formula is a well-formed expression built from a finite set of propositional variables $\{x_1, x_2, \ldots, x_n\}$, the logical constants $\top$ (true) and $\bot$ (false), and the connectives negation $(\lnot)$, conjunction $(\land)$, and disjunction $(\lor)$. Formally, the set $\mathcal{F}$ of Boolean formulas over variables $X$ is the smallest set satisfying: (i) every constant and every variable is in $\mathcal{F}$; (ii) if $\varphi, \psi \in \mathcal{F}$, then $\lnot\varphi$, $(\varphi \land \psi)$, and $(\varphi \lor \psi)$ are in $\mathcal{F}$. Each variable ranges over the domain $\mathbb{B} = \{0, 1\}$, and an interpretation is a function $v : X \to \mathbb{B}$ that assigns a truth value to every variable. The truth value of a formula $\varphi$ under $v$, written $\llbracket \varphi \rrbracket_v$, is computed inductively on the structure of $\varphi$.

Worked Example. Consider $\varphi = (x_1 \land \lnot x_2) \lor x_3$ over variables $\{x_1, x_2, x_3\}$. Under the interpretation $v(x_1) = 1$, $v(x_2) = 0$, $v(x_3) = 0$:

$$\llbracket \lnot x_2 \rrbracket_v = 1, \quad \llbracket x_1 \land \lnot x_2 \rrbracket_v = 1 \land 1 = 1, \quad \llbracket \varphi \rrbracket_v = 1 \lor 0 = 1.$$

A formula is satisfiable if some interpretation makes it true, valid (a tautology) if every interpretation does, and unsatisfiable if none does.

Key Theorem (Completeness of $\{\lnot, \land, \lor\}$). Every Boolean function $f : \mathbb{B}^n \to \mathbb{B}$ is expressible as a Boolean formula. In particular, the disjunctive normal form (DNF) of $f$ is

$$\varphi_f = \bigvee_{\substack{v \in \mathbb{B}^n \\ f(v)=1}} \bigwedge_{i=1}^{n} x_i^{v_i},$$

where $x_i^1 = x_i$ and $x_i^0 = \lnot x_i$. The DNF is obtained by taking one conjunctive clause per satisfying row of the truth table and disjoining them.

Lab Cell.

from sympy.logic.boolalg import Or, And, Not, to_dnf
from sympy.abc import x1, x2, x3

phi = Or(And(x1, Not(x2)), x3)
print("DNF:", to_dnf(phi, simplify=True))

# Evaluate under v: x1=True, x2=False, x3=False
v = {x1: True, x2: False, x3: False}
print("Truth value:", phi.subs(v))

Running this cell confirms that the DNF simplifies to the original formula and that $\llbracket \varphi \rrbracket_v = \texttt{True}$, matching the hand calculation above.
