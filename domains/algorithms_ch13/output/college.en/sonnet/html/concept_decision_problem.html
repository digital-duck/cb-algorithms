Decision Problem

Definition. A decision problem is a computational problem whose answer is restricted to one of two values: yes or no. Formally, a decision problem is a pair $(L, \Sigma)$ where $\Sigma$ is a finite alphabet and $L \subseteq \Sigma^$ is a language. Given an input string $w \in \Sigma^$, the problem asks whether $w \in L$. An algorithm decides $L$ if it halts on every input and returns the correct yes/no answer. This binary framing is not a restriction in practice: most quantitative problems (e.g., "is the shortest path shorter than $k$?") are reducible to decision form by introducing a threshold parameter.

Worked Example. Consider the primality decision problem: given a positive integer $n$, decide whether $n$ is prime. The input is the binary encoding of $n$, so the alphabet is $\Sigma = \{0, 1\}$ and the language is $L_{\text{PRIME}} = \{\langle n \rangle : n \text{ is prime}\}$. For $n = 17$, a trial-division algorithm checks divisibility by each integer $d$ with $2 \leq d \leq \lfloor\sqrt{17}\rfloor = 4$. Since $17$ is not divisible by $2$, $3$, or $4$, the algorithm halts and returns yes. For $n = 15$, the check $15 = 3 \times 5$ yields no. The algorithm terminates for every $n$, so it decides $L_{\text{PRIME}}$ in $O(\sqrt{n})$ arithmetic steps — equivalently, $O(2^{k/2})$ steps where $k = \lfloor\log_2 n\rfloor + 1$ is the bit-length of the input. The landmark result that $L_{\text{PRIME}} \in \mathbf{P}$ was established by the AKS algorithm (Agrawal, Kayal, Saxena, 2002), which runs in $O(k^{12})$ time.

Key Theorem (Church–Turing). Every effectively computable function can be computed by a Turing machine. As a corollary, a decision problem is decidable if and only if there exists a Turing machine that halts on all inputs and accepts precisely the strings in $L$. Problems for which no such machine exists — such as the Halting Problem $L_{\text{HALT}}$ — are called undecidable.

Lab Cell.

from sympy import isprime

def decide_prime(n: int) -> str:
    return "yes" if isprime(n) else "no"

test_cases = [2, 15, 17, 100, 101]
for n in test_cases:
    print(f"n = {n:>3}  →  {decide_prime(n)}")

Running this cell prints yes for $n \in \{2, 17, 101\}$ and no for $n \in \{15, 100\}$, confirming the decision oracle on five representative inputs. SymPy's isprime implements a deterministic Miller–Rabin test for small $n$ and a combination of probabilistic checks for large $n$, illustrating that efficient decision procedures often exploit number-theoretic structure rather than exhaustive search.
