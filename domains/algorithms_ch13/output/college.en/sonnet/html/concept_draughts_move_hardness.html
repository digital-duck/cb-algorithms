Draughts Move Hardness

Definition. Let $G = (P, M, T)$ denote a finite two-player zero-sum game, where $P$ is the set of board positions, $M : P \to 2^P$ the legal-move function, and $T \subseteq P$ the set of terminal positions carrying payoff $v : T \to \{-1, +1\}$. The move-hardness problem for draughts is the decision problem

$$\textsc{DraughtsWin} = \{ \langle p, k \rangle \mid \text{the first player has a forced win from position } p \text{ in at most } k \text{ plies} \},$$

where a ply is a single half-move. Hardness is quantified by the worst-case depth of the game tree $\mathcal{T}(p)$ rooted at $p$: a position is hard when every winning strategy requires exploring a sub-tree of exponential size in the board dimension $n$.

Worked example. Consider a $4 \times 4$ draughts micro-board. From a position $p$ with two pieces per side, the branching factor is at most $b = 4$ and the horizon is at most $d = 8$ plies. The minimax algorithm evaluates at most $b^d = 4^8 = 65{,}536$ leaf nodes. On the standard $8 \times 8$ board with $b \approx 8$ and $d \approx 60$, the naive bound becomes $8^{60} \approx 10^{54}$—intractable without pruning. The $\alpha$-$\beta$ procedure reduces this to $O(b^{d/2})$ under ideal move ordering, yet the worst-case remains $O(b^d)$, confirming exponential hardness in the horizon depth.

Key theorem (Robson 1984; Fraenkel et al. 1978). Generalized draughts on an $n \times n$ board is EXPTIME-complete under polynomial-time reductions. Formally,

$$\textsc{DraughtsWin} \in \mathbf{EXPTIME} \quad \text{and} \quad \textsc{DraughtsWin} \text{ is } \mathbf{EXPTIME}\text{-hard}.$$

The upper bound follows by explicit game-tree search in time $O(b^{2^{O(n)}})$. Hardness is shown by reduction from the acceptance problem of an alternating polynomial-space Turing machine, whose computation graph is encoded as a draughts position; each machine configuration corresponds to a forced-move sequence on the board.

Lab cell.

from sympy import symbols, Rational
from sympy.combinatorics.prufer import PruferSequence  # for tree enumeration

def minimax(tree, depth, maximising):
    """tree: dict mapping node -> list[child_value | subtree]"""
    if depth == 0 or not isinstance(tree, dict):
        return Rational(tree)          # leaf: exact rational payoff
    children = [minimax(c, depth - 1, not maximising) for c in tree.values()]
    return max(children) if maximising else min(children)

# Small example: depth-2 tree, branching factor 2
game_tree = {
    'L': {0: Rational(3), 1: Rational(5)},
    'R': {0: Rational(2), 1: Rational(9)},
}
print(minimax(game_tree, depth=2, maximising=True))   # → 5
