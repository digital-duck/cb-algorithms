Min Vertex Cover

Definition. Let $G = (V, E)$ be an undirected graph. A vertex cover is a subset $S \subseteq V$ such that every edge $\{u, v\} \in E$ has at least one endpoint in $S$—that is, for all $\{u,v\} \in E$, $u \in S$ or $v \in S$ (or both). A minimum vertex cover (MVC) is a vertex cover of smallest possible cardinality, denoted $\tau(G)$. Intuitively, the set $S$ "covers" every edge in the graph, and we seek the most economical such set.

Worked Example. Consider the path graph $P_4$ on vertices $\{1, 2, 3, 4\}$ with edges $\{1,2\}, \{2,3\}, \{3,4\}$. The set $\{2, 3\}$ covers all three edges: $\{1,2\}$ is covered by $2$; $\{2,3\}$ by both; $\{3,4\}$ by $3$. No single vertex covers all three edges (vertex $2$ misses $\{3,4\}$, vertex $3$ misses $\{1,2\}$), so $\tau(P_4) = 2$ and $S^* = \{2,3\}$ is an MVC.

Key Theorem (König's Theorem, 1931). In every bipartite graph $G$,

$$\tau(G) = \nu(G),$$

where $\nu(G)$ denotes the size of a maximum matching. That is, the minimum number of vertices needed to cover all edges equals the maximum number of pairwise non-adjacent edges. The proof constructs an MVC directly from a maximum matching via an alternating-path argument (Hall's theorem). König's theorem does not extend to general graphs—for odd cycles, $\tau > \nu$—making MVC NP-hard in the general case.

Connection to Independent Sets. The complement of any vertex cover is an independent set: $S$ is a vertex cover if and only if $V \setminus S$ is an independent set. Consequently, $\tau(G) + \alpha(G) = |V|$, where $\alpha(G)$ is the independence number. Finding a maximum independent set is therefore equivalent to finding an MVC.

Lab Cell.

import sympy.combinatorics as sc
from sympy.combinatorics import Graph

# Build P_4 manually via adjacency dict
edges = [(1,2),(2,3),(3,4)]
vertices = [1,2,3,4]

def is_vertex_cover(cover, edges):
    return all(u in cover or v in cover for u,v in edges)

# Brute-force MVC for small graphs
from itertools import combinations
n = len(vertices)
mvc = None
for r in range(1, n+1):
    for subset in combinations(vertices, r):
        if is_vertex_cover(set(subset), edges):
            mvc = set(subset)
            break
    if mvc:
        break

print(f"Minimum vertex cover: {mvc}, size = {len(mvc)}")
# Output: Minimum vertex cover: {2, 3}, size = 2

This brute-force enumeration is exponential in $|V|$; polynomial algorithms exist only for bipartite graphs (via max-flow) and for approximations within factor $2$ in the general case.
