NP-Hard Games and Puzzles

Definition. A decision problem $\Pi$ is NP-hard if every problem in the class NP can be reduced to $\Pi$ in polynomial time. Informally, NP-hard problems are at least as hard as the hardest problems in NP; they need not themselves be in NP. A problem that is both NP-hard and in NP is called NP-complete. Many classical combinatorial games and puzzles fall into this category: solving them optimally is believed to require exponential time in the worst case, though no proof of this belief exists without resolving the open question $\text{P} \neq \text{NP}$.

Worked Example: Minesweeper Consistency. Consider an arbitrary rectangular Minesweeper board where some cells are revealed with their neighbor-mine counts and some remain hidden. The Minesweeper Consistency Problem asks: does there exist a valid placement of exactly $k$ mines in the hidden cells consistent with all revealed numbers? This problem is NP-complete. The reduction proceeds from 3-SAT: given a boolean formula $\phi$ in conjunctive normal form with clauses $C_1, \dots, C_m$ over variables $x_1, \dots, x_n$, one constructs a Minesweeper board in polynomial time such that $\phi$ is satisfiable if and only if a consistent mine placement exists. Variable gadgets encode truth assignments; clause gadgets enforce that at least one literal per clause is satisfied. Because 3-SAT is NP-complete and the reduction is polynomial, Minesweeper Consistency is NP-hard; membership in NP is immediate since a mine placement serves as a polynomial certificate.

Key Theorem (Kaye, 2000). Minesweeper is NP-complete. More broadly, many single-player puzzles—including Sudoku on an $n \times n$ board, the Fifteen Puzzle generalized to $n \times n$, and Tetris survival—are NP-complete or NP-hard under standard generalizations. The unifying proof technique is gadget-based reduction: local tile or cell configurations simulate logical gates, wires, and crossovers, allowing arbitrary boolean circuits to be embedded in the puzzle.

Lab Cell.

from sympy.logic.boolalg import And, Or, Not
from sympy import symbols
from sympy.logic.inference import satisfiable

# Encode a small 2-clause 3-SAT instance
x1, x2, x3 = symbols('x1 x2 x3')
formula = And(Or(x1, Not(x2), x3), Or(Not(x1), x2, Not(x3)))

model = satisfiable(formula)
print(model)  # e.g. {x1: True, x2: True, x3: False}

The new primitive here is satisfiable, which applies a DPLL-based search to return a satisfying assignment or False if none exists. Running this cell shows SymPy resolving the two-clause formula in milliseconds; the same algorithm scales exponentially in the worst case, illustrating concretely why NP-hardness matters in practice.
