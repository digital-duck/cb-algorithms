State Summary Minimization

Definition

A state summary is a function $\sigma : S \to \Sigma$ that maps each state $s$ in a state space $S$ to a compact descriptor in a summary space $\Sigma$. Given a transition system $(S, \mathcal{A}, \delta)$ — where $\mathcal{A}$ is an alphabet of actions and $\delta : S \times \mathcal{A} \to S$ is the transition function — two states $s, s'$ are said to be summary-equivalent, written $s \sim s'$, if and only if they are indistinguishable by all future observations:

$$s \sim s' \iff \forall w \in \mathcal{A}^{*},\; \delta^{*}(s,w) \in F \Leftrightarrow \delta^{*}(s',w) \in F,$$

where $F \subseteq S$ is the set of accepting states and $\delta^{}$ denotes the extension of $\delta$ to strings. State summary minimization is the problem of finding the coarsest partition $\Pi^{} = \{[s]_{\sim}\}$ of $S$ consistent with $\sim$, thereby yielding the smallest system that preserves all observable behavior.

Worked Example

Consider a deterministic finite automaton with states $\{q_0, q_1, q_2, q_3\}$, alphabet $\{0,1\}$, start state $q_0$, and accepting set $F = \{q_1, q_3\}$. Suppose the transition table is:

| State | 0 | 1 | |-------|---|---| | $q_0$ | $q_1$ | $q_2$ | | $q_1$ | $q_3$ | $q_0$ | | $q_2$ | $q_1$ | $q_2$ | | $q_3$ | $q_3$ | $q_0$ |

Step 1. Partition by acceptance: $P_0 = \{\{q_1,q_3\},\{q_0,q_2\}\}$.

Step 2. Refine. Under input $0$, both $q_0$ and $q_2$ transition to $q_1 \in F$; under input $1$, both transition to $q_2 \notin F$. Hence $q_0 \sim q_2$. Similarly $q_1 \sim q_3$.

The minimal automaton has two states: $[\![q_0]\!]$ and $[\![q_1]\!]$.

Key Theorem (Myhill–Nerode)

Theorem. A language $L \subseteq \mathcal{A}^{*}$ is recognized by a finite automaton if and only if the relation $\sim_L$, defined by

$$x \sim_L y \iff \forall z \in \mathcal{A}^{*},\; xz \in L \Leftrightarrow yz \in L,$$

has finite index. Moreover, the number of equivalence classes equals the number of states in the unique minimal automaton for $L$.

Proof sketch. Each class $[x]_{\sim_L}$ corresponds to exactly one reachable state; distinguishability of any two classes by some suffix forces them to be separate states. Merging any two classes would cause an accepting and a rejecting state to coincide, contradicting correctness. $\square$

from sympy import symbols, FiniteSet, Eq

# Represent transition as a dictionary and apply Table-filling algorithm
def minimize(states, alphabet, delta, accept):
    distinguishable = set()
    pairs = [(p,q) for i,p in enumerate(states)
                   for q in states[i+1:]]
    # Mark pairs where exactly one is accepting
    for p, q in pairs:
        if (p in accept) != (q in accept):
            distinguishable.add(frozenset({p,q}))
    changed = True
    while changed:
        changed = False
        for p, q in pairs:
            pair = frozenset({p,q})
            if pair not in distinguishable:
                for a in alphabet:
                    if frozenset({delta[p][a], delta[q][a]}) in distinguishable:
                        distinguishable.add(pair); changed = True; break
    return [pair for pair in pairs if frozenset(pair) not in distinguishable]

states  = ['q0','q1','q2','q3']
alpha   = [0, 1]
delta   = {'q0':{0:'q1',1:'q2'}, 'q1':{0:'q3',1:'q0'},
           'q2':{0:'q1',1:'q2'}, 'q3':{0:'q3',1:'q0'}}
accept  = {'q1','q3'}
print("Equivalent pairs:", minimize(states, alpha, delta, accept))
# Output: Equivalent pairs: [('q0','q2'), ('q1','q3')]
