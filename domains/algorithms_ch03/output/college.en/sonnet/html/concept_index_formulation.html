Index Formulation

Definition. Let $S$ be a finite or countably infinite set of symbolic objects. An index formulation is a triple $\mathcal{I} = (I, \phi, \preceq)$, where $I$ is an index set (typically $I \subseteq \mathbb{Z}_{\geq 0}^k$ for some dimension $k \geq 1$), $\phi: I \to S$ is a surjective labelling map assigning each index tuple to a unique element of $S$, and $\preceq$ is a partial order on $I$ that encodes the traversal or dependency structure of the collection. When $k = 1$ and $I = \{0, 1, \dots, n-1\}$, $\mathcal{I}$ reduces to the familiar one-dimensional indexing of a sequence; higher-dimensional cases arise naturally in tensor algebra and multi-variable series.

Worked Example. Consider the double sum

$$ T = \sum_{i=1}^{m} \sum_{j=1}^{n} a_{ij}, $$

where $(a_{ij})$ is an $m \times n$ real matrix. Here $I = \{(i,j) : 1 \leq i \leq m,\; 1 \leq j \leq n\}$, the map $\phi(i,j) = a_{ij}$ labels each index pair with a matrix entry, and $\preceq$ is the lexicographic order $(i,j) \preceq (i',j')$ iff $i < i'$, or $i = i'$ and $j \leq j'$. Reindexing via the bijection $\psi(i,j) = n(i-1)+j$ collapses this to a one-dimensional sum $T = \sum_{k=1}^{mn} b_k$ without altering the value, demonstrating that the choice of index set is a representational convenience, not an intrinsic property of $T$.

Key Theorem (Fubini–Tonelli for finite sums). Let $\mathcal{I} = (I_1 \times I_2, \phi, \preceq_{\mathrm{lex}})$ be a product index formulation and let $f: I_1 \times I_2 \to \mathbb{R}$. Then

$$ \sum_{(i,j)\in I_1\times I_2} f(i,j) = \sum_{i \in I_1}\sum_{j \in I_2} f(i,j) = \sum_{j \in I_2}\sum_{i \in I_1} f(i,j). $$

The proof follows from associativity and commutativity of finite addition; no absolute-convergence hypothesis is needed in the finite case, unlike the continuous analogue.

Lab Cell.

from sympy import symbols, summation, IndexedBase, Idx, simplify

i, j, m, n = symbols('i j m n', positive=True, integer=True)
a = IndexedBase('a')

# Define double sum over product index set
inner = summation(a[i, j], (j, 1, n))
T = summation(inner, (i, 1, m))

# Verify commutativity of summation order
T_swapped = summation(summation(a[i, j], (i, 1, m)), (j, 1, n))
print(simplify(T - T_swapped))   # Expected: 0

Running this cell confirms the finite Fubini–Tonelli theorem symbolically: swapping the summation indices leaves the total unchanged.
