Concept Book: Subset Sum

Algorithms Ch03 · Generated by SPL

Payoff

What the concept achieves. Throughout this text, we have built a precise vocabulary for sequences, sets, and combinatorial selection. The concept of the subset sum draws every thread together. Given a finite set $S = \{a_1, a_2, \dots, a_n\} \subset \mathbb{Z}$ and a target $T \in \mathbb{Z}$, the subset-sum problem asks: does there exist a subset $A \subseteq S$ such that

$$\sum_{a \in A} a = T?$$

This deceptively simple question sits at the intersection of combinatorics, complexity theory, cryptography, and optimization. It is the natural endpoint of our study because it forces us to reason simultaneously about existence (is such a subset present?), enumeration (how many such subsets are there?), and construction (how do we find one efficiently?). Answering these three questions in tandem requires every tool we have developed.

A worked example. Let $S = \{3, 7, 1, 8, 5\}$ and $T = 15$. We construct the dynamic-programming table $\text{dp}[i][t] = 1$ if target $t$ is achievable using elements drawn from $\{a_1, \dots, a_i\}$, and $0$ otherwise. Initialising $\text{dp}[i][0] = 1$ for all $i$ (the empty subset sums to zero), and applying the recurrence

$$\text{dp}[i][t] = \text{dp}[i-1][t] \;\vee\; \text{dp}[i-1][t - a_i] \quad (t \geq a_i),$$

we trace that $T = 15$ is first achieved at row $i = 4$ via the subset $\{7, 8\}$, confirming a solution exists in $O(nT)$ time.

The key theorem. The subset-sum decision problem is $\mathbf{NP}$-complete (Karp, 1972). Every problem whose solution can be verified in polynomial time can be reduced to subset sum in polynomial time, making it a canonical hard problem and a cornerstone of computational complexity.

Lab cell.

from sympy.utilities.iterables import subsets

S, T = [3, 7, 1, 8, 5], 15
solutions = [sub for sub in subsets(S) if sum(sub) == T]
print(solutions)   # [(7, 8), (1, 7, 5, ...), ...]

An invitation. The depth behind this single question is remarkable: cryptographic schemes such as the Merkle–Hellman knapsack cipher are built directly on the presumed hardness of subset sum. If you have been drawn to the idea that a simple arithmetic question can anchor an entire security system, the chapter that follows traces exactly that connection — from this table to a working encryption protocol.
