What Text Segmentation Achieves

Every analytical method developed in the preceding chapters — from tokenization and entropy estimation to dynamic programming over string grammars — converges on a single computational act: the principled partition of a character sequence into meaningful units. Text segmentation is the problem of finding a segmentation $S = (s_1, s_2, \ldots, s_k)$ of a string $w = w_1 w_2 \cdots w_n$ such that each segment $s_i$ is a linguistically or statistically coherent span, and the sequence of segments jointly covers $w$ without overlap or gap. Formally, a segmentation is optimal with respect to a scoring function $\phi$ when

$$S^* = \arg\max_{S \in \mathcal{S}(w)} \sum_{i=1}^{k} \phi(s_i),$$

where $\mathcal{S}(w)$ denotes the set of all admissible partitions of $w$. Because this objective decomposes additively over segments, the Bellman recurrence

$$V[j] = \max_{0 \le i < j} \bigl( V[i] + \phi(w_{i+1} \cdots w_j) \bigr)$$

yields the global optimum in $O(n^2)$ time — a fact that makes the dynamic-programming approach both theoretically elegant and practically indispensable.

Worked Example

Consider the string "studyingalgorithms" and a unigram log-probability scorer $\phi(s) = \log P(s)$ estimated from an English word list. Evaluating the recurrence produces $V[18] = \log P(\text{"studying"}) + \log P(\text{"algorithms"})$, the unique maximum-scoring partition. Every competing cut — such as "study" + "ing" + "algorithms" — yields a strictly lower total score, demonstrating that the optimal boundary arises automatically from the corpus statistics rather than from hand-crafted rules.

Key Theorem

Optimal Substructure of Segmentation. If $S^ = (s_1^, \ldots, s_k^)$ is an optimal segmentation of $w$, then the suffix $(s_2^, \ldots, s_k^)$ is an optimal segmentation of $w$ with $s_1^$ removed. This substructure property is what licenses the Bellman recurrence and guarantees that no globally optimal boundary is missed by the dynamic program.

from sympy import symbols, Sum, oo
import math, re

def segment(word, vocab_prob):
    n = len(word)
    V = [-math.inf] * (n + 1)
    back = [0] * (n + 1)
    V[0] = 0.0
    for j in range(1, n + 1):
        for i in range(j):
            tok = word[i:j]
            if tok in vocab_prob:
                score = V[i] + math.log(vocab_prob[tok])
                if score > V[j]:
                    V[j], back[j] = score, i
    # Trace back
    segs, pos = [], n
    while pos > 0:
        segs.append(word[back[pos]:pos])
        pos = back[pos]
    return list(reversed(segs))

vocab = {"studying": 1e-4, "algorithms": 1e-5, "study": 5e-4,
         "ing": 3e-3, "algorithm": 2e-5, "s": 1e-2}
print(segment("studyingalgorithms", vocab))  # ['studying', 'algorithms']

An Invitation

Text segmentation is not an end in itself; it is the key that unlocks every downstream task that requires structured input. With a reliable segmentation layer in place, one may turn immediately to information extraction — the identification of named entities, relations, and events within a document — where segment boundaries determine the atomic units over which pattern-matching and sequence models operate. The reader who wishes to pursue this path will find that every concept encountered here reappears: the scoring function becomes a sequence model, the dynamic program becomes a Viterbi decoder, and the vocabulary becomes a gazetteer. The machinery is the same; only the interpretation changes.
