Divide And Conquer Root Choice

Definition. Given a continuous function $f : [a, b] \to \mathbb{R}$ with $f(a)$ and $f(b)$ of opposite sign, the divide-and-conquer root choice (commonly called the bisection method) is the iterative procedure that locates a root $c \in [a, b]$ satisfying $f(c) = 0$ by repeatedly halving the search interval. At each step $k$, a midpoint $m_k = \tfrac{a_k + b_k}{2}$ is evaluated, and the subinterval $[a_k, m_k]$ or $[m_k, b_k]$ is retained according to which endpoint pair preserves opposite signs. The method exploits the Intermediate Value Theorem: if $f$ is continuous and $f(a_k) \cdot f(b_k) < 0$, then a root exists inside the interval.

Worked Example. Let $f(x) = x^3 - x - 2$. Note $f(1) = -2 < 0$ and $f(2) = 4 > 0$, so a root lies in $[1, 2]$.

| Step | $a_k$ | $b_k$ | $m_k$ | $f(m_k)$ | New interval | |------|--------|--------|--------|-----------|--------------| | 1 | 1.000 | 2.000 | 1.500 | $-0.125$ | $[1.5, 2.0]$ | | 2 | 1.500 | 2.000 | 1.750 | $+1.609$ | $[1.5, 1.75]$ | | 3 | 1.500 | 1.750 | 1.625 | $+0.666$ | $[1.5, 1.625]$ |

After step 3 the root is bracketed within an interval of width $0.125$, already half the original in each iteration. The true root is $x^* \approx 1.5214$.

Key Theorem (Linear Convergence). After $n$ bisection steps, the absolute error satisfies

$$|m_n - x^*| \leq \frac{b - a}{2^n}.$$

Proof sketch. Each iteration discards exactly half the current interval; by induction, the interval width after $n$ steps is $(b-a)/2^n$, and $x^$ remains inside every retained interval, so the midpoint deviates from $x^$ by at most half that width. $\square$

To achieve tolerance $\varepsilon$, one requires at least $n \geq \lceil \log_2((b-a)/\varepsilon) \rceil$ steps — a predictable, guaranteed cost regardless of $f$'s shape.

Lab Cell (SymPy).

from sympy import symbols, Rational

def bisect(f, a, b, tol=1e-6, maxiter=50):
    a, b = Rational(a), Rational(b)
    for _ in range(maxiter):
        m = (a + b) / 2
        if f(m) == 0 or (b - a) / 2 < tol:
            return float(m)
        if f(a) * f(m) < 0:
            b = m
        else:
            a = m
    return float((a + b) / 2)

x = symbols('x')
f = lambda t: t**3 - t - 2
print(bisect(f, 1, 2))   # → 1.521379...
