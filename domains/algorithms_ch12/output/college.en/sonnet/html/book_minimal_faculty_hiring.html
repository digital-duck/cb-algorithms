Concept Book: Minimal Faculty Hiring

Payoff

Throughout this text, we have built a hierarchy of combinatorial structures: set systems, hypergraphs, covering relations, and integer linear programs. The concept of minimal faculty hiring is the natural endpoint of that hierarchy because it forces every earlier tool to work in concert. Formally, let $U = \{c_1, c_2, \ldots, c_m\}$ be the universe of courses that a department must offer each semester, and let $F = \{f_1, f_2, \ldots, f_n\}$ be a pool of candidate faculty members, where each $f_i$ is qualified to teach a non-empty subset $S_i \subseteq U$. The minimal faculty hiring problem asks for the smallest index set $I \subseteq \{1, \ldots, n\}$ such that

$$\bigcup_{i \in I} S_i = U.$$

This is precisely the weighted set cover problem (unit weights), one of the canonical NP-hard problems in combinatorial optimization. Its hardness certificate — that no polynomial-time algorithm achieves an approximation ratio better than $(1 - o(1))\ln m$ unless $\mathrm{P} = \mathrm{NP}$ — makes it the sharpest lens through which to view approximation theory.

Worked example. Suppose $U = \{A, B, C, D\}$ and three candidates have teaching portfolios $S_1 = \{A, B\}$, $S_2 = \{B, C, D\}$, $S_3 = \{A, C\}$. The greedy algorithm selects $f_2$ first (largest uncovered set, size 3), then $f_1$ (covers the remaining $A$), yielding $|I| = 2$. One verifies directly that no single faculty member covers $U$, so this solution is optimal.

Theorem (Greedy Approximation). Let $\text{OPT}$ denote the size of a minimum cover. The greedy algorithm, which iteratively selects the candidate covering the most uncovered courses, returns a solution of size at most $\text{OPT} \cdot H(m)$, where $H(m) = \sum_{k=1}^{m} \frac{1}{k} \approx \ln m$ is the $m$-th harmonic number.

Proof sketch. At each greedy step, the remaining uncovered courses can be covered by $\text{OPT}$ faculty, so at least one faculty member covers at least $1/\text{OPT}$ of the remainder. A telescoping argument then bounds the total steps by $\text{OPT} \cdot H(m)$. $\square$

The integer linear programming relaxation of this problem — minimize $\mathbf{1}^\top \mathbf{x}$ subject to $Ax \geq \mathbf{1}$, $x \geq 0$, where $A_{ji} = \mathbf{1}[c_j \in S_i]$ — connects minimal faculty hiring to the entire LP duality theory developed in earlier chapters and to fractional relaxations studied in Chapter 9.

from sympy import symbols, Rational
from sympy.matrices import Matrix

# Encode the worked example as a covering matrix
A = Matrix([
    [1, 0, 1],  # course A covered by f1, f3
    [1, 1, 0],  # course B covered by f1, f2
    [0, 1, 1],  # course C covered by f2, f3
    [0, 1, 0],  # course D covered by f2 only
])
x1, x2, x3 = symbols('x1 x2 x3', nonneg=True)
x = Matrix([x1, x2, x3])
constraints = A * x  # each entry must be >= 1 for a valid cover
print("Coverage vector (must be >= 1 elementwise):")
print(constraints)

Minimal faculty hiring is not merely an administrative convenience; it is the formal skeleton beneath every resource-constrained coverage problem. The reader who has reached this point is now equipped to pursue any of the deep extensions this model unlocks. We invite you to begin with the weighted variant, where hiring costs differ across candidates, and to re-examine how LP duality reveals the economic interpretation of each dual variable as the marginal value of guaranteeing one additional course — a dialogue between algebra and institutional design that rewards careful study.
