Disjoint Path Cover

Definition. Let $G = (V, E)$ be a directed acyclic graph (DAG). A disjoint path cover (DPC) of $G$ is a collection of directed paths $\mathcal{P} = \{P_1, P_2, \ldots, P_k\}$ such that every vertex $v \in V$ belongs to exactly one path in $\mathcal{P}$. The paths are vertex-disjoint: for $i \neq j$, $V(P_i) \cap V(P_j) = \emptyset$. A minimum disjoint path cover minimizes $|\mathcal{P}|$, i.e., finds the fewest paths that together visit every vertex exactly once.

Worked Example. Consider the DAG with vertices $V = \{1, 2, 3, 4, 5\}$ and edges $E = \{(1,3),(2,3),(3,4),(3,5)\}$. One valid DPC uses three paths: $P_1 = (1, 3, 4)$, $P_2 = (2)$, $P_3 = (5)$. Can we do better? Testing two paths: any single path through vertex 3 can incorporate at most one predecessor (1 or 2) and one successor (4 or 5), leaving the remaining predecessor and successor as isolated singleton paths. Thus the minimum number of paths is $k = 3$, achieved by $\{(1,3,4),(2),(5)\}$ or $\{(2,3,5),(1),(4)\}$.

Key Theorem. (Dilworth–Reduction) The size of a minimum disjoint path cover of a DAG $G$ with $n$ vertices equals

$$k = n - \mu(G'),$$

where $\mu(G')$ is the size of a maximum matching in the bipartite graph $G'$ constructed as follows: replace each vertex $v \in V$ with a source copy $v^+$ and a sink copy $v^-$, and add edge $(u^+, v^-)$ to $G'$ whenever $(u, v) \in E$. Each matched edge in $G'$ "chains" two vertices into a single path, reducing the path count by one. A maximum matching therefore maximally chains vertices, yielding the minimum number of paths. Computing $\mu(G')$ via the Hopcroft–Karp algorithm runs in $O(\sqrt{n}\, |E|)$ time.

Lab Cell.

from sympy.combinatorics.named_groups import *
import networkx as nx

G = nx.DiGraph([(1,3),(2,3),(3,4),(3,5)])

# Build bipartite reduction
B = nx.DiGraph()
for u, v in G.edges():
    B.add_edge(f"{u}+", f"{v}-")

top = {n for n in B.nodes() if "+" in n}
matching = nx.bipartite.maximum_matching(B.to_undirected(), top_nodes=top)
mu = len(matching) // 2

min_paths = G.number_of_nodes() - mu
print(f"Maximum matching: {mu}")
print(f"Minimum path cover size: {min_paths}")
