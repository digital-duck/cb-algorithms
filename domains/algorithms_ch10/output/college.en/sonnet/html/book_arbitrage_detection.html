Concept Book: Arbitrage Detection

Algorithms Ch10 · Generated by SPL

Payoff

What arbitrage detection achieves. An arbitrage is a sequence of transactions that begins and ends in the same state yet yields a strictly positive gain—profit without risk or net investment. Detecting such opportunities is not merely a financial curiosity; it is the natural endpoint of a long chain of algebraic reasoning. Every concept developed in this book—directed graphs, weight functions, cycle enumeration, logarithmic transformations—converges here into a single, decidable question: does this system contain a negative-weight cycle?

Formally, let $G = (V, E, w)$ be a weighted directed graph where each edge $(u, v)$ carries weight $w(u,v) = -\ln r(u,v)$, with $r(u,v)$ the exchange rate (or analogous ratio) from state $u$ to state $v$. An arbitrage exists if and only if $G$ contains a directed cycle $C = (v_0, v_1, \ldots, v_k, v_0)$ satisfying

$$\sum_{i=0}^{k} w(v_i, v_{i+1}) < 0,$$

equivalently, $\prod_{i=0}^{k} r(v_i, v_{i+1}) > 1$.

Worked example. Consider three currencies with rates $r(\text{USD} \to \text{EUR}) = 0.9$, $r(\text{EUR} \to \text{GBP}) = 0.8$, $r(\text{GBP} \to \text{USD}) = 1.45$. The transformed weights are $w_1 = -\ln 0.9 \approx 0.105$, $w_2 = -\ln 0.8 \approx 0.223$, $w_3 = -\ln 1.45 \approx -0.372$. The cycle weight is $0.105 + 0.223 - 0.372 = -0.044 < 0$, confirming an arbitrage: converting \$1 through EUR and GBP returns approximately \$1.044.

Key theorem (Bellman–Ford termination). If $G$ has $|V|$ vertices, the Bellman–Ford algorithm, run for $|V| - 1$ relaxation passes, correctly computes shortest-path distances from a fixed source. A negative-weight cycle is present if and only if a further relaxation pass still decreases some distance estimate. The algorithm therefore decides the arbitrage question in $O(|V| \cdot |E|)$ time.

Lab cell.

import sympy as sp

rates = {('USD','EUR'): sp.Rational(9,10),
         ('EUR','GBP'): sp.Rational(4,5),
         ('GBP','USD'): sp.Rational(29,20)}

cycle_product = sp.prod(list(rates.values()))
print("Cycle product:", cycle_product)          # > 1 ⟹ arbitrage
print("Arbitrage:", sp.simplify(cycle_product - 1) > 0)
