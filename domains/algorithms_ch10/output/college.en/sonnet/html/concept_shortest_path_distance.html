Shortest Path Distance

Definition. Let $G = (V, E, w)$ be a weighted graph where $V$ is the set of vertices, $E \subseteq V \times V$ the set of edges, and $w : E \to \mathbb{R}_{\geq 0}$ a non-negative weight function. A path from vertex $u$ to vertex $v$ is a finite sequence of vertices $\pi = (v_0, v_1, \ldots, v_k)$ with $v_0 = u$, $v_k = v$, and $(v_{i-1}, v_i) \in E$ for each $i$. The length of path $\pi$ is

$$\ell(\pi) = \sum_{i=1}^{k} w(v_{i-1},\, v_i).$$

The shortest path distance (or geodesic distance) between $u$ and $v$ is

$$d(u, v) = \min_{\pi \in \mathcal{P}(u,v)} \ell(\pi),$$

where $\mathcal{P}(u,v)$ denotes the set of all paths from $u$ to $v$. If no path exists, one writes $d(u,v) = \infty$ by convention.

Worked Example. Consider the graph $G$ with vertices $\{A, B, C, D\}$ and weighted edges $w(A,B)=1$, $w(A,C)=4$, $w(B,C)=2$, $w(B,D)=5$, $w(C,D)=1$. To compute $d(A,D)$, enumerate candidate paths:

| Path | Length | |---|---| | $A \to B \to D$ | $1 + 5 = 6$ | | $A \to B \to C \to D$ | $1 + 2 + 1 = 4$ | | $A \to C \to D$ | $4 + 1 = 5$ |

The minimum is $4$, achieved by $A \to B \to C \to D$, so $d(A,D) = 4$.

Key Theorem (Triangle Inequality). For any three vertices $u$, $v$, $x$ in a connected weighted graph with non-negative weights,

$$d(u, v) \leq d(u, x) + d(x, v).$$

Proof sketch. Any path from $u$ to $v$ passing through $x$ has length $d(u,x) + d(x,v)$; since $d(u,v)$ is the minimum over all paths, it cannot exceed this concatenated length. $\square$

This inequality guarantees that $d$ is a proper metric on the vertex set, enabling classical metric-space arguments in graph-theoretic contexts.

Lab Cell.

import sympy as sp
import networkx as nx

G = nx.Graph()
G.add_weighted_edges_from([
    ('A','B',1), ('A','C',4),
    ('B','C',2), ('B','D',5), ('C','D',1)
])

dist = nx.shortest_path_length(G, source='A', weight='weight')
for target, d in dist.items():
    print(f"d(A, {target}) = {d}")

# Verify triangle inequality for u=A, x=B, v=D
print(dist['D'] <= dist['B'] + nx.shortest_path_length(G,'B','D',weight='weight'))
