Fast Exponentiation

Definition. Let $b$ be a real number and $n$ a non-negative integer. Fast exponentiation (also called exponentiation by squaring) is a recursive algorithm that computes $b^n$ using $O(\log n)$ multiplications, rather than the $O(n)$ multiplications required by naive repeated multiplication. It exploits the identity

$$ b^n = \begin{cases} 1 & \text{if } n = 0, \\ \left(b^{n/2}\right)^2 & \text{if } n \text{ is even}, \\ b \cdot b^{n-1} & \text{if } n \text{ is odd}. \end{cases} $$

Each recursive call halves the exponent (when $n$ is even), so the recursion depth is $\lfloor \log_2 n \rfloor + 1$, yielding the logarithmic complexity claim.

Worked Example. Compute $3^{13}$.

Write $13$ in binary: $13 = (1101)_2 = 8 + 4 + 1$. Trace the recursive calls:

| Call | $n$ | Action | |------|-----|--------| | $3^{13}$ | odd | $3 \cdot 3^{12}$ | | $3^{12}$ | even | $(3^{6})^2$ | | $3^{6}$ | even | $(3^{3})^2$ | | $3^{3}$ | odd | $3 \cdot 3^{2}$ | | $3^{2}$ | even | $(3^{1})^2 = 9$ |

Unwinding: $3^3 = 3 \cdot 9 = 27$, $3^6 = 27^2 = 729$, $3^{12} = 729^2 = 531441$, $3^{13} = 3 \cdot 531441 = 1594323$. Only 6 multiplications were needed; naive multiplication would require 12.

Key Theorem. Let $n \geq 1$. The exponentiation-by-squaring algorithm computes $b^n$ using at most $2\lfloor \log_2 n \rfloor$ multiplications.

Proof sketch. Each bit of the binary representation of $n$ contributes at most two multiplications (one squaring, one conditional multiply). Since $n$ has $\lfloor \log_2 n \rfloor + 1$ bits, the bound follows. $\square$

This theorem is especially significant in modular arithmetic: computing $b^n \pmod{m}$ for cryptographically large $n$ (e.g., $n \approx 2^{2048}$) is feasible only because of this logarithmic reduction.

Lab Cell.

from sympy import Symbol, Rational

def fast_exp(b, n):
    """Compute b**n by squaring (works over any SymPy expression)."""
    if n == 0:
        return 1
    if n % 2 == 0:
        half = fast_exp(b, n // 2)
        return half * half
    return b * fast_exp(b, n - 1)

x = Symbol('x')
print(fast_exp(3, 13))           # 1594323
print(fast_exp(Rational(1, 2), 10))  # 1/1024
print(fast_exp(x + 1, 4))       # (x+1)**4, unexpanded
