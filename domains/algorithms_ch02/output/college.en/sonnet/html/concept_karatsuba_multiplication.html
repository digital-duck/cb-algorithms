Karatsuba Multiplication

Definition. Let $x$ and $y$ be two $n$-digit integers (in base $B$). Write each number in split form by choosing $m = \lfloor n/2 \rfloor$:

$$x = x_1 B^m + x_0, \qquad y = y_1 B^m + y_0,$$

where $0 \le x_0, y_0 < B^m$. The naïve expansion of their product requires four sub-multiplications: $x_1 y_1$, $x_1 y_0$, $x_0 y_1$, and $x_0 y_0$. Karatsuba's algorithm (Karatsuba & Ofman, 1962) reduces this to three by observing that the cross terms can be recovered from

$$x_1 y_0 + x_0 y_1 = (x_1 + x_0)(y_1 + y_0) - x_1 y_1 - x_0 y_0.$$

Formally, compute $A = x_1 y_1$, $C = x_0 y_0$, $B_{\text{mid}} = (x_1+x_0)(y_1+y_0) - A - C$, then

$$x \cdot y = A \cdot B^{2m} + B_{\text{mid}} \cdot B^m + C.$$

Worked Example. Multiply $x = 1234$ and $y = 5678$ in base 10 with $m = 2$. Split: $x_1 = 12$, $x_0 = 34$, $y_1 = 56$, $y_0 = 78$. Compute:

$$A = 12 \times 56 = 672, \quad C = 34 \times 78 = 2652,$$ $$B_{\text{mid}} = (12+34)(56+78) - 672 - 2652 = 46 \times 134 - 3324 = 6164 - 3324 = 2840.$$

Reconstruct: $672 \times 10^4 + 2840 \times 10^2 + 2652 = 6{,}720{,}000 + 284{,}000 + 2{,}652 = 7{,}006{,}652$. Indeed $1234 \times 5678 = 7{,}006{,}652$. $\checkmark$

Key Theorem (Complexity). Applied recursively, Karatsuba multiplication runs in time

$$T(n) = 3\,T\!\left(\tfrac{n}{2}\right) + O(n).$$

By the Master Theorem with $a=3$, $b=2$, $f(n)=O(n)$: since $\log_2 3 \approx 1.585 > 1$, the solution is $T(n) = O(n^{\log_2 3}) \approx O(n^{1.585})$, strictly better than the $O(n^2)$ schoolbook algorithm.

Lab Cell.

from sympy import symbols, expand

x1, x0, y1, y0, B, m = symbols('x1 x0 y1 y0 B m')

A      = x1 * y1
C      = x0 * y0
B_mid  = (x1 + x0)*(y1 + y0) - A - C
product = expand(A*B**(2*m) + B_mid*B**m + C)

# Verify symbolically against direct expansion
direct = expand((x1*B**m + x0)*(y1*B**m + y0))
print(product - direct)   # should print 0

Running this cell confirms the identity algebraically, illustrating that Karatsuba's key insight is purely an algebraic rearrangement that eliminates one recursive call at each level of the recursion tree.
