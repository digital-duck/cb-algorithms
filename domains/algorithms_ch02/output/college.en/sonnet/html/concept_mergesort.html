Mergesort

Definition. Mergesort is a comparison-based sorting algorithm that follows the divide-and-conquer paradigm. Given a sequence $A$ of $n$ elements drawn from a totally ordered set, mergesort partitions $A$ into two halves, recursively sorts each half, and then merges the two sorted subsequences into a single sorted output. Formally, let $A[l \ldots r]$ denote a subarray indexed from $l$ to $r$. The algorithm computes $m = \lfloor (l+r)/2 \rfloor$, recurses on $A[l \ldots m]$ and $A[m{+}1 \ldots r]$, and applies a linear-time merge procedure to produce a sorted $A[l \ldots r]$.

Worked Example. Consider $A = [5, 2, 8, 3]$.

  • Split into $[5, 2]$ and $[8, 3]$.
  • Recursively sort each half: $[2, 5]$ and $[3, 8]$.
  • Merge by repeatedly extracting the smaller front element: compare $2$ and $3$ → take $2$; compare $5$ and $3$ → take $3$; compare $5$ and $8$ → take $5$; take $8$.
  • Result: $[2, 3, 5, 8]$.

    • The merge step performs at most $n - 1$ comparisons for two halves whose combined length is $n$.

    Key Theorem (Mergesort Complexity). Mergesort sorts $n$ elements in $\Theta(n \log n)$ time and requires $\Theta(n)$ auxiliary space.

    Proof sketch. Let $T(n)$ denote the worst-case comparison count. The recurrence is

    $$T(n) = 2\,T\!\left(\frac{n}{2}\right) + \Theta(n), \quad T(1) = 0.$$

    Applying the Master Theorem (case 2, with $a = 2$, $b = 2$, $f(n) = \Theta(n)$, and $n^{\log_b a} = n^1$), we obtain $T(n) = \Theta(n \log n)$. This bound is optimal for comparison-based sorting, since any comparison tree sorting $n$ elements must have depth at least $\log_2(n!) = \Theta(n \log n)$ by Stirling's approximation. $\blacksquare$

    Unlike quicksort, mergesort's worst-case guarantee holds unconditionally, making it the algorithm of choice when worst-case performance is critical.

    Lab Cell.

    from sympy import symbols, Function, rsolve

n = symbols('n', positive=True)
T = Function('T')

# Verify the recurrence T(n) = 2*T(n/2) + n symbolically
# Closed-form via direct expansion (Master Theorem illustration)
def merge_sort(arr):
    if len(arr) <= 1:
        return arr
    mid = len(arr) // 2
    left  = merge_sort(arr[:mid])
    right = merge_sort(arr[mid:])
    result, i, j = [], 0, 0
    while i < len(left) and j < len(right):
        if left[i] <= right[j]:
            result.append(left[i]); i += 1
        else:
            result.append(right[j]); j += 1
    return result + left[i:] + right[j:]

data = [5, 2, 8, 3, 9, 1]
print(merge_sort(data))  # [1, 2, 3, 5, 8, 9]
