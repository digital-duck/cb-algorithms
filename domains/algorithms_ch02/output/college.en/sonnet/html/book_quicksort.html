Concept Book: Quicksort

Algorithms Ch02 · Generated by SPL

Payoff

What quicksort achieves. Every concept developed in this book — recursion, divide-and-conquer, pivot selection, partition invariants — converges here. Quicksort is a comparison-based, in-place sorting algorithm that, on a sequence $A = (a_1, a_2, \ldots, a_n)$, selects a pivot element $p$, partitions $A$ into a left subarray $L = \{a_i : a_i < p\}$ and a right subarray $R = \{a_i : a_i > p\}$, and recurses on $L$ and $R$ independently. The recurrence governing its expected cost is

$$T(n) = T(k) + T(n - k - 1) + \Theta(n), \quad k \sim \text{Uniform}\{0, \ldots, n-1\},$$

whose solution yields $\mathbb{E}[T(n)] = \Theta(n \log n)$. This bound is optimal among comparison sorts by the decision-tree lower bound, making quicksort not merely fast in practice but provably efficient in expectation.

Worked example. Consider $A = (3, 6, 8, 10, 1, 2, 1)$. Choosing $p = 3$ as pivot, one pass of Lomuto's partition scheme scans left to right, swapping elements smaller than $p$ to the front, yielding $L = (1, 2, 1)$, pivot in place, $R = (6, 8, 10)$. Recursion on $L$ and $R$ each sort three elements independently. The total work at this level is $\Theta(7)$ comparisons, matching the $\Theta(n)$ partition cost.

Key theorem. With a randomly chosen pivot at each level, the expected number of comparisons performed by quicksort on $n$ distinct elements is exactly $2n H_n - 2(n-1)$, where $H_n = \sum_{k=1}^{n} \frac{1}{k}$ is the $n$-th harmonic number. Since $H_n = \ln n + O(1)$, this gives $\approx 2n \ln n \approx 1.386\, n \log_2 n$ comparisons — fewer than mergesort's $2n \log_2 n$ in the leading constant.

Lab cell.

from sympy import symbols, Sum, Rational, harmonic, simplify, log

n = symbols('n', positive=True, integer=True)
Hn = harmonic(n)
expected_comparisons = 2*n*Hn - 2*(n - 1)
print(expected_comparisons)          # exact closed form
print(simplify(expected_comparisons.rewrite(log)))  # asymptotic form

Quicksort is the natural endpoint of this book because every prior concept — loop invariants, recursion trees, probabilistic analysis — is necessary to state and prove it rigorously. No single ingredient suffices alone; all are required simultaneously. From here, the ideas generalise immediately: randomised pivot selection reappears in treaps and skip lists; the partition subroutine underlies order-statistics (finding the $k$-th smallest element in $\Theta(n)$ expected time); and the divide-and-conquer skeleton drives closest-pair geometry and FFT-based polynomial multiplication.
