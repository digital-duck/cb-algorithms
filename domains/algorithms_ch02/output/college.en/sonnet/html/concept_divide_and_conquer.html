Divide And Conquer

Definition. The divide-and-conquer paradigm is an algorithmic design strategy in which a problem of size $n$ is recursively decomposed into $a \geq 1$ subproblems, each of size $n/b$ (for some integer $b > 1$), solved independently, and then combined. The total work $T(n)$ satisfies the recurrence

$$T(n) = a\,T\!\left(\frac{n}{b}\right) + f(n), \qquad T(1) = \Theta(1),$$

where $f(n)$ denotes the cost of the divide and combine steps.

Worked Example: Merge Sort. Consider sorting an array of $n$ elements. Merge sort divides the array into two halves ($a = 2$, $b = 2$), sorts each half recursively, then merges the two sorted halves in $\Theta(n)$ time. Its recurrence is

$$T(n) = 2\,T\!\left(\frac{n}{2}\right) + \Theta(n).$$

To build intuition, trace $n = 8$: the array splits into two groups of 4, then four groups of 2, then eight singletons — three levels of recursion. At each level the total merge work is $\Theta(n) = \Theta(8)$, and there are $\log_2 8 = 3$ levels, giving $T(8) = \Theta(8 \log 8)$.

Theorem (Master Theorem). Let $T(n) = a\,T(n/b) + f(n)$ with $a \geq 1$, $b > 1$. Define the critical exponent $c^* = \log_b a$. Then:

  • If $f(n) = O(n^{c^ - \varepsilon})$ for some $\varepsilon > 0$, then $T(n) = \Theta(n^{c^})$.
  • If $f(n) = \Theta(n^{c^})$, then $T(n) = \Theta(n^{c^} \log n)$.
  • If $f(n) = \Omega(n^{c^* + \varepsilon})$ and $a\,f(n/b) \leq c\,f(n)$ for some $c < 1$, then $T(n) = \Theta(f(n))$.

    • For merge sort, $c^* = \log_2 2 = 1$ and $f(n) = \Theta(n^1)$, so Case 2 applies, confirming $T(n) = \Theta(n \log n)$.

    Lab Cell.

    from sympy import symbols, Function, rsolve, log, O

n = symbols('n', positive=True)

# Verify Master Theorem Case 2 numerically
import math

def merge_sort_ops(n):
    """Count approximate operations via recurrence T(n) = 2T(n/2) + n."""
    if n <= 1:
        return 0
    return 2 * merge_sort_ops(n // 2) + n

sizes = [8, 16, 32, 64, 128]
for s in sizes:
    ratio = merge_sort_ops(s) / (s * math.log2(s))
    print(f"n={s:4d}  T(n)/(n log n) ≈ {ratio:.4f}")

    Running this cell reveals that $T(n)/(n \log_2 n)$ converges to a constant near $1$, confirming the $\Theta(n \log n)$ bound empirically. Divide-and-conquer thus transforms an $O(n^2)$ sorting problem into one solvable in nearly linear-logarithmic time — a pattern that recurs throughout algorithm design.
