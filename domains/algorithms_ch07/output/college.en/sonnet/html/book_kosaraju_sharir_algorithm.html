Concept Book: Kosaraju Sharir Algorithm

Payoff

The journey through directed graphs culminates here: Kosaraju–Sharir's algorithm for computing strongly connected components (SCCs) is not merely a clever trick but a structural theorem made executable. A strongly connected component of a directed graph $G = (V, E)$ is a maximal set $C \subseteq V$ such that for every pair $u, v \in C$ there exist directed paths $u \rightsquigarrow v$ and $v \rightsquigarrow u$. The algorithm identifies every such component in $\Theta(V + E)$ time — optimal, since reading the edge list already costs that much.

The algorithm proceeds in two passes of depth-first search. In the first pass, run DFS on $G$ and record vertices in order of decreasing finish time. In the second pass, run DFS on the reverse graph $G^R$ (all edges flipped), visiting vertices in the order just recorded. Each DFS tree in the second pass is exactly one SCC. The correctness rests on a single key fact: if $C_1$ and $C_2$ are distinct SCCs and there is an edge from $C_1$ to $C_2$ in $G$, then the maximum finish time in $C_1$ exceeds that in $C_2$. Consequently, the second-pass DFS explores $C_1$ before $C_2$, and reversed edges prevent it from escaping into $C_2$.

Worked example. Let $G$ have vertices $\{1,2,3,4\}$ and edges $1\to 2,\, 2\to 3,\, 3\to 1,\, 3\to 4$. A first-pass DFS starting at 1 yields finish order $(4, 3, 2, 1)$. On $G^R$ — with edges $2\to 1, 3\to 2, 1\to 3, 4\to 3$ — starting from vertex 1 (highest finish time) reaches $\{1,2,3\}$ before stalling; vertex 4 forms its own tree. The SCCs are $\{1,2,3\}$ and $\{4\}$.

Key theorem (Kosaraju–Sharir, 1978/1981). The described two-pass DFS correctly partitions $V$ into strongly connected components in $O(V + E)$ time and $O(V + E)$ space.

# Lab cell — verify with SymPy / NetworkX
import networkx as nx

G = nx.DiGraph([(1,2),(2,3),(3,1),(3,4)])
sccs = list(nx.kosaraju_strongly_connected_components(G))
print(sccs)   # [{1, 2, 3}, {4}]

The condensation $G^{\text{SCC}}$ — the DAG whose nodes are SCCs — is the skeleton that downstream algorithms walk. Compiler dataflow analysis, web-scale hyperlink ranking, deadlock detection in concurrent systems, and reachability in model checkers all reduce, at their core, to asking: what are the irreducible feedback loops? Kosaraju–Sharir answers that question once, cleanly, and for free in linear time, handing every subsequent method a loop-free foundation to build on.

If one application deserves a deeper dive, it is compiler liveness analysis: the way SCCs expose exactly which variables must remain live across a loop back-edge turns this graph algorithm into the engine of every optimizing compiler you have ever used. The next chapter invites you there.
