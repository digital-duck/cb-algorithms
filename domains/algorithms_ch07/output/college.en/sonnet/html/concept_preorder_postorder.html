Preorder Postorder

Definition. Let $T$ be a rooted tree with root $r$, and let $\text{children}(v)$ denote the ordered list of children of a node $v$. A preorder traversal of $T$ visits $r$ first, then recursively traverses each subtree in left-to-right order. A postorder traversal visits each subtree recursively before visiting the root. Formally, if we write $\pi_{\text{pre}}(T)$ and $\pi_{\text{post}}(T)$ for the resulting node sequences:

$$\pi_{\text{pre}}(T) = r,\; \pi_{\text{pre}}(T_1),\; \pi_{\text{pre}}(T_2),\; \ldots,\; \pi_{\text{pre}}(T_k)$$ $$\pi_{\text{post}}(T) = \pi_{\text{post}}(T_1),\; \pi_{\text{post}}(T_2),\; \ldots,\; \pi_{\text{post}}(T_k),\; r$$

where $T_1, T_2, \ldots, T_k$ are the subtrees rooted at the children of $r$.

Worked Example. Consider the binary tree with root $A$, left child $B$ (with leaves $D$, $E$), and right child $C$ (with leaf $F$).

        A
       / \
      B   C
     / \   \
    D   E   F

Preorder visits the root before descending: $A, B, D, E, C, F$. Postorder processes all descendants before the root: $D, E, B, F, C, A$. Notice that in preorder, every node appears before all of its descendants, while in postorder every node appears after all of its descendants. This structural guarantee is the key property exploited in algorithms.

Key Theorem. (Ancestor ordering) Let $u$ and $v$ be nodes in a rooted tree $T$. Then $u$ is a proper ancestor of $v$ if and only if $u$ appears before $v$ in $\pi_{\text{pre}}(T)$ and after $v$ in $\pi_{\text{post}}(T)$. Equivalently, assigning each node $v$ the pair $(\text{pre}(v), \text{post}(v))$ of its positions in the two traversals, the ancestor relation satisfies:

$$u \text{ is an ancestor of } v \iff \text{pre}(u) < \text{pre}(v) \text{ and } \text{post}(u) > \text{post}(v).$$

This allows $O(1)$ ancestor queries after $O(n)$ preprocessing — a foundational technique in XML indexing, compiler symbol tables, and dependency resolution.

from sympy import symbols
from sympy.combinatorics import Permutation

# Build tree as adjacency dict and run both traversals
tree = {'A': ['B','C'], 'B': ['D','E'], 'C': ['F'],
        'D': [], 'E': [], 'F': []}

def preorder(node):
    yield node
    for child in tree[node]:
        yield from preorder(child)

def postorder(node):
    for child in tree[node]:
        yield from postorder(child)
    yield node

pre  = list(preorder('A'))
post = list(postorder('A'))
print("Preorder: ", pre)
print("Postorder:", post)

# Verify ancestor theorem for pair (A, E)
pre_idx  = {n: i for i, n in enumerate(pre)}
post_idx = {n: i for i, n in enumerate(post)}
u, v = 'A', 'E'
print(f"{u} ancestor of {v}:",
      pre_idx[u] < pre_idx[v] and post_idx[u] > post_idx[v])
