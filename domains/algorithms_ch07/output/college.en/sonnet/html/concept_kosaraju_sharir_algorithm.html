Kosaraju Sharir Algorithm

Definition. A strongly connected component (SCC) of a directed graph $G = (V, E)$ is a maximal set $S \subseteq V$ such that for every pair $u, v \in S$ there exist directed paths $u \rightsquigarrow v$ and $v \rightsquigarrow u$. The Kosaraju–Sharir algorithm computes all SCCs of $G$ in $\Theta(V + E)$ time using two passes of depth-first search (DFS).

Algorithm sketch. Let $G^T = (V, E^T)$ denote the transpose of $G$, obtained by reversing every edge. The procedure is:

  • Run DFS on $G$; record each vertex's finish time $f(v)$.
  • Process vertices in decreasing order of $f(v)$; run DFS on $G^T$.
  • Each DFS tree produced in step 2 is exactly one SCC.

    • The correctness rests on the following observation: if $C$ and $C'$ are two distinct SCCs and there is an edge from some $u \in C$ to some $v \in C'$, then the vertex in $C$ with the largest finish time satisfies $\max_{w \in C} f(w) > \max_{w \in C'} f(w)$. Processing in reverse finish-time order therefore guarantees that DFS on $G^T$ never "crosses" from a later-finished SCC into an earlier-finished one.

    Worked example. Consider $G$ with vertices $\{1,2,3,4\}$ and edges $1\to2, 2\to3, 3\to1, 2\to4$. A DFS starting at 1 might yield finish order $3, 1, 4, 2$ (so $f(2)$ is largest). Reversing edges gives $G^T$: $2\to1, 3\to2, 1\to3, 4\to2$. Processing vertices by decreasing finish time — $2, 4, 1, 3$ — DFS on $G^T$ from vertex 2 reaches $\{1,2,3\}$ (one SCC), then from 4 reaches only $\{4\}$. The two SCCs are $\{1,2,3\}$ and $\{4\}$, consistent with the fact that 4 has no path back to any other vertex.

    Theorem (Kosaraju–Sharir, 1978). For a directed graph $G$ with $|V| = n$ and $|E| = m$, the algorithm correctly identifies all SCCs in $O(n + m)$ time and $O(n + m)$ space.

    # Lab cell — verify SCCs with NetworkX
import networkx as nx

G = nx.DiGraph([(1,2),(2,3),(3,1),(2,4)])
sccs = list(nx.kosaraju_strongly_connected_components(G))
print(sccs)   # [{1,2,3}, {4}]

# Confirm transpose
GT = G.reverse()
print(list(GT.edges()))
