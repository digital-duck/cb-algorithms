Cycle Detection

Definition. Let $G = (V, E)$ be a directed or undirected graph. A cycle is a closed walk $v_0, v_1, \ldots, v_k = v_0$ with $k \geq 1$ in which no edge is repeated (and, for simple cycles, no internal vertex is repeated). Cycle detection is the problem of determining whether $G$ contains at least one such cycle, and, when it does, identifying the vertices and edges that compose it.

For undirected graphs a cycle exists if and only if a depth-first search (DFS) encounters a back edge—an edge $(u, v)$ where $v$ is an ancestor of $u$ in the DFS tree. For directed graphs the same criterion applies, but back edges must be distinguished from cross edges and forward edges by tracking vertex colours: white (unvisited), grey (in the current DFS stack), and black (fully processed). An edge $(u, v)$ is a back edge precisely when $v$ is grey at the moment $u$ is visited.

Worked Example. Consider the directed graph $G$ with $V = \{1, 2, 3, 4\}$ and $E = \{(1,2),(2,3),(3,4),(4,2)\}$. Begin DFS from vertex 1. The colour sequence evolves as follows:

$$1 \xrightarrow{\text{grey}} 2 \xrightarrow{\text{grey}} 3 \xrightarrow{\text{grey}} 4 \xrightarrow{\text{grey}} 2$$

When the algorithm attempts to follow edge $(4, 2)$, vertex 2 is still grey. A back edge is detected, confirming the cycle $2 \to 3 \to 4 \to 2$.

Theorem (DFS Cycle Criterion). A directed graph $G$ is a directed acyclic graph (DAG) if and only if a DFS of $G$ produces no back edge.

Proof sketch. ($\Rightarrow$) If a back edge $(u,v)$ exists, the path from $v$ to $u$ in the DFS tree together with $(u,v)$ forms a directed cycle, contradicting the DAG assumption. ($\Leftarrow$) If $G$ contains a cycle $v_0 \to v_1 \to \cdots \to v_k \to v_0$, then whichever vertex in the cycle is discovered first by DFS will still be grey when the last edge of the cycle is traversed, producing a back edge. $\square$

Both directions establish that back-edge detection runs in $O(|V| + |E|)$ time.

# Lab cell — detect a cycle in a directed graph using DFS
import sympy  # not needed for logic, but available for graph display

def has_cycle(adj):
    color = {v: 'white' for v in adj}

    def dfs(u):
        color[u] = 'grey'
        for v in adj.get(u, []):
            if color[v] == 'grey':
                return True          # back edge found
            if color[v] == 'white' and dfs(v):
                return True
        color[u] = 'black'
        return False

    return any(dfs(v) for v in adj if color[v] == 'white')

adj = {1: [2], 2: [3], 3: [4], 4: [2]}   # graph from worked example
print(has_cycle(adj))   # True
