Tarjan Low Function

Definition. Let $G = (V, E)$ be a connected undirected graph, and let $T$ be a depth-first search (DFS) tree rooted at some vertex $r$. For each vertex $v \in V$, define the discovery time $\mathrm{disc}(v)$ as the integer timestamp at which $v$ is first visited during DFS. The Tarjan low function assigns to each vertex $v$ the value

$$\mathrm{low}(v) = \min\bigl\{\mathrm{disc}(v),\;\min_{(v,w)\in E,\,w\neq \mathrm{parent}(v)}\mathrm{disc}(w),\;\min_{u\in\mathrm{desc}(v)}\mathrm{low}(u)\bigr\}$$

where $\mathrm{desc}(v)$ denotes the set of descendants of $v$ in $T$. Intuitively, $\mathrm{low}(v)$ is the earliest discovery time reachable from the subtree rooted at $v$ using at most one back edge—an edge connecting a descendant to an ancestor.

Worked Example. Consider the graph with vertices $\{1,2,3,4\}$ and edges $\{(1,2),(2,3),(3,4),(4,2)\}$. Starting DFS at vertex 1, the timestamps are $\mathrm{disc}(1)=0,\;\mathrm{disc}(2)=1,\;\mathrm{disc}(3)=2,\;\mathrm{disc}(4)=3$. The edge $(4,2)$ is a back edge since $\mathrm{disc}(2)=1 < \mathrm{disc}(4)=3$. Propagating upward: $\mathrm{low}(4)=\min(3,1)=1$; $\mathrm{low}(3)=\min(2,\mathrm{low}(4))=1$; $\mathrm{low}(2)=\min(1,\mathrm{low}(3))=1$; $\mathrm{low}(1)=0$. The edge $(1,2)$ is a bridge because $\mathrm{low}(2)=1>\mathrm{disc}(1)=0$ is false—so here no bridge exists between 2 and 3 either, confirming the cycle $2\to3\to4\to2$ keeps the subgraph 2-edge-connected.

Key Theorem (Bridge and Articulation Characterisation). Let $T$ be a DFS tree of $G$. A tree edge $(u,v)$ (with $u = \mathrm{parent}(v)$) is a bridge if and only if $\mathrm{low}(v) > \mathrm{disc}(u)$. A non-root vertex $u$ is an articulation point if and only if there exists a child $v$ of $u$ in $T$ such that $\mathrm{low}(v) \geq \mathrm{disc}(u)$.

Proof sketch. If $\mathrm{low}(v) > \mathrm{disc}(u)$, no vertex in the subtree of $v$ can reach $u$ or any ancestor of $u$ via a back edge, so removing $(u,v)$ disconnects the graph. The articulation point condition follows analogously: the subtree of $v$ would be isolated from $u$'s ancestors upon removing $u$.

from sympy import symbols

def tarjan_low(graph, root=0):
    n, disc, low, visited = len(graph), [-1]*n, [0]*n, [False]*n
    timer = [0]
    def dfs(u, parent):
        visited[u] = True
        disc[u] = low[u] = timer[0]; timer[0] += 1
        for v in graph[u]:
            if not visited[v]:
                dfs(v, u)
                low[u] = min(low[u], low[v])
            elif v != parent:
                low[u] = min(low[u], disc[v])
    dfs(root, -1)
    return low

graph = {0:[1], 1:[0,2,3], 2:[1,3], 3:[1,2]}
print(tarjan_low(graph))   # Expected: [0, 1, 1, 1]
