Tarjan Algorithm

Definition. Let $G = (V, E)$ be a directed graph. A strongly connected component (SCC) of $G$ is a maximal set $S \subseteq V$ such that for every pair $u, v \in S$ there exists a directed path from $u$ to $v$ and from $v$ to $u$. Tarjan's algorithm, published by Robert Tarjan in 1972, computes all SCCs of $G$ in a single depth-first search (DFS) traversal, running in $O(|V| + |E|)$ time.

The algorithm maintains two integers per vertex $v$: a discovery timestamp $\text{disc}[v]$ assigned in DFS order, and a low-link value $\text{low}[v]$ defined as

$$\text{low}[v] = \min\bigl(\text{disc}[v],\; \min_{(v,w) \in E,\, w \in \text{stack}} \text{low}[w]\bigr).$$

A vertex $v$ is the root of an SCC precisely when $\text{low}[v] = \text{disc}[v]$; at that moment the algorithm pops the stack down to $v$, yielding one complete SCC.

Worked Example. Consider $G$ with vertices $\{1, 2, 3, 4\}$ and edges $1 \to 2,\; 2 \to 3,\; 3 \to 1,\; 2 \to 4$. Starting DFS at vertex 1:

| Step | Visit | disc | low | Stack | |------|-------|------|-----|-------| | 1 | 1 | 0 | 0 | [1] | | 2 | 2 | 1 | 1 | [1,2] | | 3 | 3 | 2 | 2 | [1,2,3] | | 4 | back-edge $3\to1$ | — | $\text{low}[3]=0$ | [1,2,3] | | 5 | return to 2 | — | $\text{low}[2]=0$ | [1,2,3] | | 6 | 4 | 3 | 3 | [1,2,3,4] | | 7 | $\text{low}[4]=\text{disc}[4]=3$; pop SCC $\{4\}$ | | | [1,2,3] | | 8 | $\text{low}[1]=\text{disc}[1]=0$; pop SCC $\{1,2,3\}$ | | | [] |

The algorithm correctly identifies $\{1,2,3\}$ and $\{4\}$ as the two SCCs.

Key Theorem. (Tarjan, 1972) Tarjan's algorithm visits each vertex and each edge exactly once, so its time complexity is $\Theta(|V|+|E|)$ and its space complexity is $O(|V|)$ for the stack and auxiliary arrays.

Lab Cell (SymPy / NetworkX).

import networkx as nx

G = nx.DiGraph([(1,2),(2,3),(3,1),(2,4)])
sccs = list(nx.strongly_connected_components(G))
print(sccs)   # [{1, 2, 3}, {4}]

# Inspect the condensation DAG
C = nx.condensation(G, scc=sccs)
print(list(C.edges()))  # edges between SCC super-nodes

Running this cell confirms the two SCCs and reveals that the condensation of $G$ is always a directed acyclic graph — a fact that underpins many downstream graph algorithms such as topological sort and reachability queries.
