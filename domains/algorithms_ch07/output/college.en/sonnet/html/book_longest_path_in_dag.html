Payoff

What the Algorithm Achieves

Throughout this text we have built, layer by layer, the machinery of directed acyclic graphs: topological ordering, reachability, and edge relaxation. The algorithm longest_path_in_dag is the point at which all of that machinery converges into a single, definitive answer. Given a weighted DAG $G = (V, E, w)$, it computes, for every vertex $v \in V$, the weight of a heaviest path ending at $v$:

$$d[v] = \max_{(u,v) \in E} \bigl(d[u] + w(u,v)\bigr), \qquad d[s] = 0 \text{ for each source } s.$$

Because a DAG contains no cycles, processing vertices in topological order guarantees that $d[u]$ is already finalised before we process any successor of $u$. The entire computation therefore runs in $\Theta(|V| + |E|)$ time — linear in the size of the graph — with no priority queue and no iteration to convergence. This is the sharpest possible complexity for any algorithm that must read every edge at least once, and it is achievable precisely because the acyclicity of the graph eliminates the risk of an indefinitely long relaxation chain.

Worked Example

Consider the DAG with vertices $\{A, B, C, D\}$ and weighted edges

$$A \xrightarrow{3} B, \quad A \xrightarrow{1} C, \quad B \xrightarrow{4} D, \quad C \xrightarrow{6} D.$$

A valid topological order is $A, B, C, D$. Initialising $d[A] = 0$ and $d[B] = d[C] = d[D] = -\infty$, the relaxation proceeds as follows.

| Step | Edge relaxed | Update | |------|-------------|--------| | 1 | $A \to B$ | $d[B] = 0 + 3 = 3$ | | 2 | $A \to C$ | $d[C] = 0 + 1 = 1$ | | 3 | $B \to D$ | $d[D] = 3 + 4 = 7$ | | 4 | $C \to D$ | $d[D] = \max(7,\; 1 + 6) = 7$ |

The longest path from $A$ to $D$ has weight $7$, achieved by the route $A \to B \to D$.

Key Theorem

Theorem (Optimal Substructure of Longest DAG Paths). Let $P^$ be a longest path from $s$ to $t$ in a weighted DAG. For every intermediate vertex $v$ on $P^$, the sub-path from $s$ to $v$ is itself a longest path from $s$ to $v$.

Proof sketch. Suppose, for contradiction, that a longer path from $s$ to $v$ exists. Substituting it into $P^$ yields a path from $s$ to $t$ with strictly greater weight, contradicting the maximality of $P^$. $\square$

This optimal-substructure property is precisely what licenses the recurrence above: each entry $d[v]$ depends only on previously computed entries, and the dynamic-programming argument is sound.

Lab Cell

import sympy as sp
from sympy.combinatorics.named_groups import SymmetricGroup  # not used here
from collections import defaultdict, deque

def longest_path_in_dag(edges):
    """edges: list of (u, v, weight); returns dict of longest distances from sources."""
    graph   = defaultdict(list)
    indeg   = defaultdict(int)
    nodes   = set()
    for u, v, w in edges:
        graph[u].append((v, w))
        indeg[v] += 1
        nodes |= {u, v}
    for n in nodes:
        indeg.setdefault(n, 0)

    queue = deque(n for n in nodes if indeg[n] == 0)
    dist  = {n: (0 if indeg[n] == 0 else -sp.oo) for n in nodes}

    while queue:
        u = queue.popleft()
        for v, w in graph[u]:
            dist[v] = max(dist[v], dist[u] + w)
            indeg[v] -= 1
            if indeg[v] == 0:
                queue.append(v)
    return dist

edges = [('A','B',3), ('A','C',1), ('B','D',4), ('C','D',6)]
print(longest_path_in_dag(edges))
# → {'A': 0, 'B': 3, 'C': 1, 'D': 7}

Run this cell and verify that $d[D] = 7$, confirming the hand-traced result above.

The Natural Endpoint

longest_path_in_dag earns its place as the capstone of this text because it is simultaneously a general algorithm and a universal modelling primitive. Wherever work flows in one direction — tasks that must precede other tasks, computations that feed later computations, events that can only follow earlier events — the structure is a DAG, and the quantity of central interest is a longest path. Project-scheduling theory names this the critical path: the sequence of dependent tasks whose total duration determines the earliest possible completion time of the entire project, making it the first target for any manager who wishes to accelerate a deadline. The same recurrence, with weights reinterpreted as log-probabilities, underlies the Viterbi decoding of hidden Markov models in speech and language processing. In compiler theory, instruction scheduling on a pipeline reduces to finding the longest path in a dependency DAG, since the critical path length equals the minimum number of clock cycles required. Even in deep learning, automatic differentiation traverses a computational graph in topological order, accumulating gradient contributions along paths — the longest path governs the depth of the backpropagation chain.

Each of these domains takes the same mathematical skeleton and clothes it in domain-specific weights and semantics, yet the algorithm is identical in every case. This universality is the hallmark of a genuinely foundational result.
