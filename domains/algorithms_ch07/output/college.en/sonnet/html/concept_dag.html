Dag

Definition. A directed acyclic graph (DAG) is an ordered pair $G = (V, E)$ where $V$ is a finite set of vertices and $E \subseteq V \times V$ is a set of directed edges $(u, v)$ with $u \neq v$, subject to the constraint that $G$ contains no directed cycle. Formally, there is no sequence of vertices $v_0, v_1, \ldots, v_k$ with $k \geq 1$ such that $(v_i, v_{i+1}) \in E$ for all $0 \leq i < k$ and $v_0 = v_k$. A vertex $u$ is called an ancestor of $v$ if there exists a directed path from $u$ to $v$; the topological order of $G$ is any linear ordering $\prec$ of $V$ such that $(u, v) \in E$ implies $u \prec v$.

Worked Example. Consider the DAG $G$ with vertex set $V = \{A, B, C, D\}$ and edge set $E = \{(A, B),\,(A, C),\,(B, D),\,(C, D)\}$. This models a simple build dependency: task $D$ requires both $B$ and $C$, each of which requires $A$. Two valid topological orderings are $A, B, C, D$ and $A, C, B, D$. To verify acyclicity, note that every edge points from a vertex earlier in the ordering to one later; no edge can therefore close a cycle. The in-degree of $D$ is $2$ (edges from $B$ and $C$), while $A$ has in-degree $0$ and is called a source.

Key Theorem (Topological Sorting). A directed graph $G$ admits a topological ordering if and only if it is a DAG. Proof sketch. If $G$ contains a directed cycle $v_0 \to v_1 \to \cdots \to v_0$, no linear ordering can satisfy $v_i \prec v_{i+1}$ for every $i$ and simultaneously $v_k \prec v_0$, so no topological order exists. Conversely, if $G$ is acyclic, Kahn's algorithm iteratively removes source vertices (those with in-degree $0$), appending each to the ordering. Because removing a vertex cannot create a cycle, a source always exists at each step until $V$ is exhausted, yielding a valid ordering in $O(|V| + |E|)$ time. $\blacksquare$

Lab Cell.

import sympy
from sympy.combinatorics import Permutation
from sympy.utilities.iterables import topological_sort

# Define edges as (predecessor, successor) pairs
vertices = [0, 1, 2, 3]          # A=0, B=1, C=2, D=3
edges    = [(0,1),(0,2),(1,3),(2,3)]

order = topological_sort([vertices, edges])
labels = {0:'A', 1:'B', 2:'C', 3:'D'}
print("Topological order:", [labels[v] for v in order])

Running this cell prints Topological order: ['A', 'B', 'C', 'D'], confirming the analytic result. Experimenting by adding the edge (3, 0) will raise a ValueError, illustrating that SymPy detects the induced cycle.
