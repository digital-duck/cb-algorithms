Longest Path In Dag

Definition. Let $G = (V, E)$ be a directed acyclic graph (DAG), where $V$ is a finite set of vertices and $E \subseteq V \times V$ is a set of directed edges containing no directed cycle. Assign a weight function $w : E \to \mathbb{R}$. The longest path from a source $s \in V$ to a target $t \in V$ is a simple path $s = v_0 \to v_1 \to \cdots \to v_k = t$ maximizing the total weight $\sum_{i=0}^{k-1} w(v_i, v_{i+1})$. Unlike general graphs, the acyclicity of $G$ guarantees that this problem is solvable in linear time via dynamic programming on a topological ordering.

Worked Example. Consider the DAG with vertices $\{A, B, C, D\}$ and weighted edges:

$$A \xrightarrow{3} B, \quad A \xrightarrow{1} C, \quad B \xrightarrow{4} D, \quad C \xrightarrow{6} D.$$

A topological order is $A, B, C, D$. Initialize $d[A] = 0$ and $d[v] = -\infty$ for all other vertices. Processing in order:

  • A: relax $B$ and $C$: $d[B] = 3$, $d[C] = 1$.
  • B: relax $D$: $d[D] = \max(-\infty,\ 3 + 4) = 7$.
  • C: relax $D$: $d[D] = \max(7,\ 1 + 6) = 7$.

    • The longest path $A \to B \to D$ has total weight $7$.

    Theorem (Correctness and Complexity). Let $G$ be a DAG with $n$ vertices and $m$ edges. The dynamic programming recurrence

    $$d[v] = \max_{(u,v) \in E}\bigl(d[u] + w(u,v)\bigr)$$

    evaluated in topological order correctly computes the longest-path distance from a fixed source to every reachable vertex. The algorithm runs in $\Theta(n + m)$ time and $\Theta(n)$ space.

    Proof sketch. Because $G$ is acyclic, every predecessor $u$ of $v$ appears before $v$ in any topological order, so $d[u]$ is finalized before $d[v]$ is computed. An inductive argument on the topological index then establishes that $d[v]$ equals the true longest-path weight after each relaxation step. $\square$

    Lab Cell.

    import sympy as sp
from sympy.combinatorics.named_groups import *

edges = {'A': [('B', 3), ('C', 1)], 'B': [('D', 4)], 'C': [('D', 6)], 'D': []}
order = ['A', 'B', 'C', 'D']          # precomputed topological order
dist  = {v: -sp.oo for v in order}
dist['A'] = 0

for u in order:
    for v, w in edges[u]:
        if dist[u] + w > dist[v]:
            dist[v] = dist[u] + w

print(dist)   # {'A': 0, 'B': 3, 'C': 1, 'D': 7}

    Modify the weight of edge $C \to D$ and observe how dist['D'] changes — this directly illustrates the sensitivity of the longest path to individual edge weights.
