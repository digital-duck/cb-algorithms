Edge Classification

Definition. Let $G = (V, E)$ be a directed graph and let $T$ be the depth-first search (DFS) forest produced by running DFS on $G$. Every edge $(u, v) \in E$ falls into exactly one of four classes, determined by the discovery time $d[v]$ and finish time $f[v]$ assigned to each vertex during DFS:

  • Tree edge: $(u, v)$ is traversed by DFS and $v$ is discovered for the first time through $u$. These edges constitute the DFS forest $T$.
  • Back edge: $v$ is an ancestor of $u$ in $T$, i.e., $d[v] < d[u] < f[u] < f[v]$.
  • Forward edge: $v$ is a proper descendant of $u$ in $T$ but $(u, v) \notin T$, i.e., $d[u] < d[v] < f[v] < f[u]$.
  • Cross edge: $v$ and $u$ are in different branches of $T$, so $d[v] < f[v] < d[u]$.

    • In an undirected graph, DFS produces only tree edges and back edges; forward and cross edges cannot arise because the discovery of any edge $(u,v)$ with $v$ already visited implies $v$ is an ancestor of $u$.

    Worked Example. Consider the directed graph with vertices $\{1,2,3,4\}$ and edges $\{(1,2),(1,3),(2,4),(4,3),(3,2)\}$. Running DFS from vertex $1$ yields timestamps:

    | Vertex | $d$ | $f$ | |--------|-----|-----| | 1 | 1 | 8 | | 2 | 2 | 7 | | 4 | 3 | 6 | | 3 | 4 | 5 |

    Inspecting each edge: $(1,2)$ and $(2,4)$ and $(4,3)$ are tree edges; $(3,2)$ satisfies $d[2] < d[3] < f[3] < f[2]$, so it is a back edge; $(1,3)$ satisfies $d[1] < d[3] < f[3] < f[1]$ with $(1,3) \notin T$, making it a forward edge.

    Key Theorem. A directed graph $G$ is a directed acyclic graph (DAG) if and only if DFS produces no back edges. Equivalently, $G$ contains a cycle if and only if some back edge $(u,v)$ exists, since such an edge closes a path from $v$ to $u$ through the DFS tree.

    Proof sketch. If a back edge $(u,v)$ exists, the tree path $v \to \cdots \to u$ together with $(u,v)$ forms a cycle. Conversely, if a cycle $v_1 \to v_2 \to \cdots \to v_k \to v_1$ exists, the first vertex discovered in the cycle is an ancestor of all others in $T$, so the returning edge to it is a back edge. $\square$

    Lab Cell (SymPy/NetworkX).

    import networkx as nx

G = nx.DiGraph([(1,2),(1,3),(2,4),(4,3),(3,2)])
dfs_edges = list(nx.dfs_labeled_edges(G, source=1))

for u, v, label in dfs_edges:
    if label in ("tree", "back", "forward", "cross"):
        print(f"({u},{v}) → {label} edge")

print("Is DAG?", nx.is_directed_acyclic_graph(G))
