Dependency Graph

Definition. Let $V = \{v_1, v_2, \ldots, v_n\}$ be a finite set of nodes, each representing a variable, task, or computation. A dependency graph is a directed acyclic graph (DAG) $G = (V, E)$ where a directed edge $(v_i, v_j) \in E$ means that $v_j$ depends on $v_i$, i.e., $v_i$ must be evaluated before $v_j$. Formally, $G$ is acyclic: there is no sequence $v_{i_1}, v_{i_2}, \ldots, v_{i_k}$ with $(v_{i_t}, v_{i_{t+1}}) \in E$ for all $t$ and $v_{i_1} = v_{i_k}$.

Nodes with in-degree zero are called sources (they have no prerequisites); nodes with out-degree zero are called sinks (nothing depends on them further).

Worked Example. Consider the system of assignments:

$$ a = 3, \quad b = a + 1, \quad c = a^2, \quad d = b \cdot c. $$

The dependency graph has nodes $\{a, b, c, d\}$ and edges $a \to b$, $a \to c$, $b \to d$, $c \to d$. Here $a$ is the unique source and $d$ the unique sink. A valid evaluation order—called a topological sort—is $a, b, c, d$ or $a, c, b, d$. Both orderings respect all edges, so every variable is defined before it is used.

Key Theorem (Topological Sort Existence). A directed graph $G$ admits a topological ordering if and only if $G$ is a DAG. Moreover, Kahn's algorithm produces such an ordering in $O(|V| + |E|)$ time by iteratively removing source nodes and updating in-degrees.

Proof sketch. If $G$ contains a directed cycle $v_{i_1} \to v_{i_2} \to \cdots \to v_{i_1}$, no node in the cycle can be placed first, so no topological order exists. Conversely, every finite DAG has at least one source; removing it yields a smaller DAG, and induction completes the argument. $\blacksquare$

Lab Cell.

import sympy as sp
from sympy.utilities.iterables import topological_sort

nodes = ['a', 'b', 'c', 'd']
edges = [('a','b'), ('a','c'), ('b','d'), ('c','d')]

order = topological_sort((nodes, edges))
print("Topological order:", order)

# Verify: evaluate the expressions symbolically
a = sp.Integer(3)
b = a + 1
c = a**2
d = b * c
print(f"a={a}, b={b}, c={c}, d={d}")

Running this cell prints Topological order: ['a', 'b', 'c', 'd'] and confirms $d = 4 \cdot 9 = 36$, demonstrating that symbolic evaluation respects the dependency structure automatically.
