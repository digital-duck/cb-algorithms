Concept Book: Tarjan Algorithm

Algorithms Ch07 · Generated by SPL

Payoff

Tarjan's algorithm is the culminating result of this text because it transforms a deceptively simple question — which vertices in a directed graph can reach one another? — into an answer delivered in a single linear-time traversal. Every concept encountered in preceding chapters converges here: depth-first search trees, the recursion stack, back edges, and the algebraic structure of reachability. The algorithm does not merely find strongly connected components (SCCs); it produces them in reverse topological order, collapsing a potentially cyclic graph into a directed acyclic graph (DAG) in one unified pass.

Definition. Let $G = (V, E)$ be a directed graph. A strongly connected component is a maximal subset $S \subseteq V$ such that for every pair $u, v \in S$ there exist directed paths $u \rightsquigarrow v$ and $v \rightsquigarrow u$. Tarjan's algorithm maintains two integer arrays: $\mathrm{disc}[v]$, the discovery time of vertex $v$ in the DFS, and $\mathrm{low}[v]$, the smallest discovery time reachable from the subtree rooted at $v$ via at most one back edge. A vertex $v$ is an SCC root if and only if $\mathrm{low}[v] = \mathrm{disc}[v]$.

Worked Example. Consider $G$ with edges $\{(1,2),(2,3),(3,1),(3,4),(4,5),(5,4)\}$. Beginning DFS at vertex $1$, discovery times are assigned sequentially. When the recursion returns to vertex $1$, we find $\mathrm{low}[1] = \mathrm{disc}[1] = 0$, identifying $\{1,2,3\}$ as one SCC. Continuing, vertex $4$ satisfies $\mathrm{low}[4] = \mathrm{disc}[4]$, yielding the second SCC $\{4,5\}$. The condensed DAG has two nodes and a single edge $\{1,2,3\} \to \{4,5\}$.

Key Theorem (Tarjan, 1972). Tarjan's algorithm correctly identifies all SCCs of a directed graph $G = (V, E)$ and runs in time $\Theta(|V| + |E|)$.

The proof follows by induction on DFS finish order: every subtree rooted at an SCC root contains exactly the vertices of that component still on the stack at the moment the root is popped.

# Lab cell — verify the worked example with SymPy/NetworkX
import networkx as nx

G = nx.DiGraph([(1,2),(2,3),(3,1),(3,4),(4,5),(5,4)])
sccs = list(nx.strongly_connected_components(G))
condensed = nx.condensation(G, scc=sccs)
print("SCCs:", sccs)
print("Condensed DAG edges:", list(condensed.edges()))

The algorithm's reach extends far beyond graph theory as an abstract pursuit. In compiler design, identifying SCCs in a call graph exposes mutually recursive function clusters that must be optimized together. In dependency resolution — package managers, build systems, Makefiles — detecting cycles via SCCs distinguishes legal dependency graphs from circular ones that would cause deadlock. In social-network analysis, SCCs delineate communities of mutual influence, a structural backbone underlying PageRank and information-diffusion models. Each domain inherits the same $\Theta(|V|+|E|)$ guarantee, making Tarjan's algorithm industrially practical at web scale.
