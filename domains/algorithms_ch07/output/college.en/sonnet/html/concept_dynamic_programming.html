Dynamic Programming

Definition. Dynamic programming (DP) is an algorithm design paradigm that solves an optimization or counting problem by decomposing it into overlapping subproblems, solving each subproblem exactly once, and storing the result for reuse. Formally, a problem admits a DP solution when it satisfies two properties: (1) optimal substructure — an optimal solution to the whole can be constructed from optimal solutions to its parts; and (2) overlapping subproblems — the same subproblem recurs multiple times during a naive recursive computation. The stored table of solutions is called a memoization table (top-down) or DP table (bottom-up).

Worked Example: Fibonacci Numbers. Define $F_n$ by $F_0 = 0$, $F_1 = 1$, and $F_n = F_{n-1} + F_{n-2}$ for $n \geq 2$. A direct recursive computation of $F_{10}$ recomputes $F_5$ dozens of times. In the bottom-up DP approach, we allocate an array $dp[0 \ldots n]$ and fill it left-to-right:

$$dp[0] = 0, \quad dp[1] = 1, \quad dp[k] = dp[k-1] + dp[k-2], \quad 2 \leq k \leq n.$$

For $n = 6$: $dp = [0, 1, 1, 2, 3, 5, 8]$, so $F_6 = 8$. Each value is computed exactly once, reducing time complexity from exponential $O(\phi^n)$ to linear $O(n)$, where $\phi = \tfrac{1+\sqrt{5}}{2}$ is the golden ratio.

Key Theorem (Bellman's Principle of Optimality, 1957). An optimal policy has the property that, whatever the initial state and decision, the remaining decisions must constitute an optimal policy with respect to the state resulting from the first decision. This principle justifies the recurrence relation at the heart of every DP formulation: once an optimal subproblem solution is recorded, no future computation needs to re-examine it.

More concretely, for the 0/1 knapsack problem with items of weights $w_i$ and values $v_i$ and capacity $W$, the recurrence is

$$dp[i][c] = \max\!\bigl(dp[i-1][c],\; v_i + dp[i-1][c - w_i]\bigr), \quad c \geq w_i,$$

with $dp[i][c] = dp[i-1][c]$ otherwise, achieving $O(nW)$ time.

Lab Cell.

from sympy import symbols, Function, rsolve

n = symbols('n', integer=True, positive=True)
F = Function('F')
# Solve the Fibonacci recurrence symbolically
sol = rsolve(F(n) - F(n-1) - F(n-2), F(n), {F(0): 0, F(1): 1})
print(sol)  # closed form involving the golden ratio
