Dfs Wrapper

Definition. A DFS wrapper is a higher-order function that encapsulates the bookkeeping infrastructure of depth-first search — visited-node tracking, recursion stack management, and result accumulation — behind a clean interface. Formally, given a graph $G = (V, E)$ and a user-supplied callback $f : V \to \text{Action}$, the wrapper $\texttt{dfs\_wrapper}(G, s, f)$ initiates a depth-first traversal from source vertex $s \in V$, invoking $f$ at each discovered vertex while guaranteeing that every reachable vertex is visited exactly once. The wrapper pattern separates traversal policy (DFS order, cycle avoidance) from traversal purpose (what to compute), yielding reusable infrastructure across problems such as topological sorting, connected-component labeling, and cycle detection.

Worked Example. Consider the directed graph $G$ with $V = \{1, 2, 3, 4\}$ and edges $E = \{(1,2),(1,3),(2,4),(3,4)\}$. A DFS wrapper initialized at $s = 1$ maintains a set $\text{visited} = \emptyset$ and a stack. On entry to vertex $v$ it executes $f(v)$ — say, appending $v$ to an output list — then recurses on each unvisited neighbor. The traversal visits vertices in the order $1 \to 2 \to 4 \to 3$, producing the pre-order sequence $[1, 2, 4, 3]$. Crucially, vertex $4$, reachable from both $2$ and $3$, is processed only once because the wrapper tests membership in $\text{visited}$ before each recursive call.

Theorem (Correctness and Complexity). Let $G = (V, E)$ be a finite directed or undirected graph. A DFS wrapper with an $O(1)$ membership-test data structure (e.g., a hash set) visits every vertex reachable from $s$ exactly once and traverses every incident edge at most twice. The total time complexity is $\Theta(|V| + |E|)$ and the space complexity is $O(|V|)$ for the visited set plus $O(|V|)$ for the implicit recursion stack in the worst case (a path graph).

Proof sketch. Each vertex enters $\text{visited}$ upon first discovery and is never re-enqueued, so visits are unique. Every edge $(u, v)$ is inspected when $u$ is processed; if $v$ is already visited the call returns immediately, bounding edge work by $2|E|$. $\square$

Lab Cell.

import sympy
from sympy.combinatorics.named_groups import SymmetricGroup

# Build adjacency list for a small graph
graph = {1: [2, 3], 2: [4], 3: [4], 4: []}

def dfs_wrapper(graph, start, callback):
    visited = set()
    def _dfs(v):
        if v in visited:
            return
        visited.add(v)
        callback(v)
        for neighbor in graph[v]:
            _dfs(neighbor)
    _dfs(start)

order = []
dfs_wrapper(graph, 1, order.append)
print("DFS pre-order:", order)  # [1, 2, 4, 3]
