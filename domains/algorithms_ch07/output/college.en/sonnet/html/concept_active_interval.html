Active Interval

Definition

Let $f : \mathbb{R} \to \mathbb{R}$ be a real-valued function. The active interval of $f$, denoted $\mathcal{A}(f)$, is the smallest closed interval $[a, b] \subset \mathbb{R}$ such that $f(x) = 0$ for all $x \notin [a, b]$. Equivalently,

$$\mathcal{A}(f) = [\inf\{\,x \in \mathbb{R} : f(x) \neq 0\},\; \sup\{\,x \in \mathbb{R} : f(x) \neq 0\}].$$

When $f$ is identically zero, we adopt the convention $\mathcal{A}(f) = \emptyset$. The length of the active interval, $|\mathcal{A}(f)| = b - a$, measures the temporal support of $f$ and is central to the analysis of piecewise-defined signals, probability density functions with bounded support, and finite-duration control inputs.

Worked Example

Consider the piecewise function

$$f(x) = \begin{cases} x - 1 & 1 \le x < 3, \\ 5 - x & 3 \le x \le 5, \\ 0 & \text{otherwise.} \end{cases}$$

To locate $\mathcal{A}(f)$, identify the leftmost point where $f$ is non-zero: $f(1) = 0$, but $f(1+\varepsilon) = \varepsilon > 0$ for any $\varepsilon > 0$, so $a = 1$. At the right end, $f(5) = 0$ and $f(5 - \varepsilon) = \varepsilon > 0$, giving $b = 5$. Hence $\mathcal{A}(f) = [1, 5]$ with $|\mathcal{A}(f)| = 4$. Note that $f(1) = f(5) = 0$; the boundary points belong to the active interval because they are limit points of the non-zero region.

Key Theorem: Active Interval of a Convolution

Theorem. If $f$ and $g$ are compactly supported with $\mathcal{A}(f) = [a_1, b_1]$ and $\mathcal{A}(g) = [a_2, b_2]$, then

$$\mathcal{A}(f * g) \subseteq [a_1 + a_2,\; b_1 + b_2],$$

where $(f * g)(t) = \int_{-\infty}^{\infty} f(\tau)\,g(t - \tau)\,d\tau$.

Proof sketch. For $(f * g)(t)$ to be non-zero, there must exist $\tau \in [a_1, b_1]$ such that $t - \tau \in [a_2, b_2]$. This requires $t \in [a_1 + a_2, b_1 + b_2]$; outside this range the integrand vanishes identically. $\square$

This result is indispensable in filter design: convolving two finite-duration signals produces an output whose active interval is determined by the sum of the endpoint coordinates of the inputs.

Lab Cell (SymPy)

from sympy import symbols, Piecewise, integrate, plot

x = symbols('x', real=True)

f = Piecewise((x - 1, (x >= 1) & (x < 3)),
              (5 - x, (x >= 3) & (x <= 5)),
              (0, True))

# Confirm active interval by evaluating boundary behaviour
print(f.subs(x, 1), f.subs(x, 5))   # both 0
print(f.subs(x, 2), f.subs(x, 4))   # interior values

area = integrate(f, (x, 1, 5))
print("Area under f on active interval:", area)  # 4

plot(f, (x, 0, 6), ylabel='f(x)', title='Active Interval [1, 5]')
