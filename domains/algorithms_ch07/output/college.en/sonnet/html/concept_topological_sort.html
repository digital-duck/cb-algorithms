Topological Sort

Definition. Let $G = (V, E)$ be a directed acyclic graph (DAG). A topological sort of $G$ is a linear ordering $v_1, v_2, \ldots, v_n$ of all vertices such that for every directed edge $(v_i, v_j) \in E$, the index $i < j$. Equivalently, no vertex appears before a vertex on which it depends. A topological sort exists if and only if $G$ contains no directed cycle.

Worked Example. Consider a simplified course prerequisite graph with vertices $\{A, B, C, D, E\}$ and directed edges representing "must be taken before":

$$E = \{(A, C),\; (B, C),\; (C, D),\; (C, E)\}$$

We apply Kahn's algorithm: compute the in-degree of each vertex.

| Vertex | In-degree | |--------|-----------| | $A$ | 0 | | $B$ | 0 | | $C$ | 2 | | $D$ | 1 | | $E$ | 1 |

Initialize a queue $Q = \{A, B\}$ (in-degree zero). Repeatedly dequeue a vertex $u$, append it to the result, and decrement the in-degree of each neighbor; enqueue any neighbor whose in-degree reaches zero.

$$\text{Step 1: dequeue } A \Rightarrow \text{result} = [A],\quad \deg^-(C) = 1$$ $$\text{Step 2: dequeue } B \Rightarrow \text{result} = [A, B],\quad \deg^-(C) = 0 \Rightarrow Q = \{C\}$$ $$\text{Step 3: dequeue } C \Rightarrow \text{result} = [A, B, C],\quad Q = \{D, E\}$$ $$\text{Steps 4–5:} \quad \text{result} = [A, B, C, D, E]$$

This is one valid topological ordering; $[B, A, C, E, D]$ is another.

Key Theorem. Kahn's algorithm runs in $O(|V| + |E|)$ time. If the queue empties before all vertices are processed—that is, the final result contains fewer than $|V|$ vertices—then $G$ contains a directed cycle and no topological sort exists.

Proof sketch. Each vertex is enqueued exactly once (when its in-degree reaches zero) and each edge is examined exactly once when its source is dequeued, giving the linear bound. A cycle prevents every vertex in the cycle from ever reaching in-degree zero, so they are never enqueued. $\square$
