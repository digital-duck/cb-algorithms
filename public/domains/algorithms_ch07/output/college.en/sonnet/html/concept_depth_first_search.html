Depth First Search

Definition. Let $G = (V, E)$ be a finite graph with vertex set $V$ and edge set $E$. Depth-first search (DFS) is a graph traversal algorithm that begins at a designated source vertex $s \in V$ and explores as far as possible along each branch before backtracking. Formally, DFS maintains a set $\text{visited} \subseteq V$ and, upon visiting vertex $u$, recursively visits every neighbour $v \in N(u)$ for which $v \notin \text{visited}$. Each vertex receives two timestamps: a discovery time $d[u]$ when it is first entered, and a finish time $f[u]$ when all descendants of $u$ have been fully explored.

Worked Example. Consider the directed graph $G$ with $V = \{1, 2, 3, 4, 5\}$ and edges $E = \{(1,2),(1,3),(2,4),(3,4),(4,5)\}$. Starting DFS from vertex $1$ with neighbours visited in numerical order:

  • Visit $1$: $d[1] = 1$. Recurse to $2$.
  • Visit $2$: $d[2] = 2$. Recurse to $4$.
  • Visit $4$: $d[4] = 3$. Recurse to $5$.
  • Visit $5$: $d[5] = 4$, $f[5] = 5$. Backtrack to $4$: $f[4] = 6$.
  • Backtrack to $2$: $f[2] = 7$. Recurse from $1$ to $3$.
  • Visit $3$: $d[3] = 8$; neighbour $4$ already visited, so $f[3] = 9$.
  • Finish $1$: $f[1] = 10$.

    • The DFS produces the finish-time ordering $f[5] < f[4] < f[2] < f[3] < f[1]$.

    Key Theorem (Parenthesis Theorem). For any two vertices $u, v$ in a DFS of $G$, exactly one of the following holds: the intervals $[d[u], f[u]]$ and $[d[v], f[v]]$ are disjoint, or one is entirely contained within the other. Formally,

    $$[d[v], f[v]] \subseteq [d[u], f[u]] \iff v \text{ is a descendant of } u \text{ in the DFS forest.}$$

    This nesting structure is the foundation for cycle detection, topological sorting, and strongly connected component algorithms, all of which run in $\Theta(|V| + |E|)$ time.

    Lab Cell.

    import sympy
from sympy.combinatorics.named_groups import SymmetricGroup

# Build adjacency list and run DFS with timestamps
graph = {1: [2, 3], 2: [4], 3: [4], 4: [5], 5: []}
visited, d, f, timer = set(), {}, {}, [0]

def dfs(u):
    visited.add(u)
    timer[0] += 1; d[u] = timer[0]
    for v in graph[u]:
        if v not in visited:
            dfs(v)
    timer[0] += 1; f[u] = timer[0]

dfs(1)
print("Discovery:", d)   # {1:1, 2:2, 4:3, 5:4, 3:8}
print("Finish:   ", f)   # {5:5, 4:6, 2:7, 3:9, 1:10}

    Running this cell reproduces the timestamps computed by hand, confirming the parenthesis theorem: the interval $[2,7]$ for vertex $2$ properly contains $[3,6]$ for vertex $4$, which in turn contains $[4,5]$ for vertex $5$.
