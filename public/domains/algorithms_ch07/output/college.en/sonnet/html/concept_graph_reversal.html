Graph Reversal

Definition. Let $G = (V, E)$ be a directed graph (digraph), where $V$ is a finite set of vertices and $E \subseteq V \times V$ is a set of directed edges. The reversal (or transpose) of $G$, denoted $G^R = (V, E^R)$, is the digraph obtained by reversing the direction of every edge in $E$. Formally,

$$E^R = \{(v, u) \mid (u, v) \in E\}.$$

Note that $G^R$ shares the same vertex set $V$ and the same number of edges as $G$; only orientation changes. If $G$ is represented as an adjacency list, constructing $G^R$ requires iterating over each edge $(u, v)$ and inserting $(v, u)$ into the new structure, an operation that runs in $\Theta(|V| + |E|)$ time.

Worked Example. Consider the digraph $G$ with $V = \{1, 2, 3, 4\}$ and edges

$$E = \{(1,2),\,(1,3),\,(2,4),\,(3,4)\}.$$

This represents a diamond-shaped dependency graph: vertex $1$ is the unique source and vertex $4$ the unique sink. Applying reversal yields

$$E^R = \{(2,1),\,(3,1),\,(4,2),\,(4,3)\}.$$

In $G^R$, vertex $4$ becomes the unique source and vertex $1$ the unique sink. Every path from $1$ to $4$ in $G$ corresponds to a path from $4$ to $1$ in $G^R$, and vice versa. This correspondence is exact: if $\pi = v_0 \to v_1 \to \cdots \to v_k$ is a directed path in $G$, then $v_k \to v_{k-1} \to \cdots \to v_0$ is a directed path in $G^R$.

Theorem (Involution). For any digraph $G$, $(G^R)^R = G$.

Proof sketch. Reversing every edge in $E$ produces $E^R$; reversing every edge in $E^R$ produces $\{(u,v) \mid (v,u) \in E^R\} = \{(u,v) \mid (u,v) \in E\} = E$. Hence the operation is its own inverse. $\blacksquare$

Graph reversal is central to Kosaraju's algorithm for computing strongly connected components: a vertex $u$ can reach $v$ in $G$ and $v$ can reach $u$ in $G^R$ precisely when $u$ and $v$ belong to the same strongly connected component.
