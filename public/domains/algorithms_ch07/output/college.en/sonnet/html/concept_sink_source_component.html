Sink Source Component

Definition. Let $G = (V, E)$ be a finite directed graph. A vertex $v \in V$ is called a source if $\deg^-(v) = 0$ (no incoming edges) and a sink if $\deg^+(v) = 0$ (no outgoing edges). More generally, after computing the strongly connected components (SCCs) of $G$ and forming the condensation $\hat{G}$—a directed acyclic graph (DAG) whose vertices are the SCCs of $G$—we call an SCC $C$ a source component if $\hat{C}$ has in-degree zero in $\hat{G}$, and a sink component if it has out-degree zero. A component that is simultaneously a source and a sink (i.e., $\hat{G}$ has a single vertex) is called a trivial sink-source component.

Worked Example. Consider $G$ with vertex set $\{1, 2, 3, 4, 5\}$ and directed edges

$$E = \{(1,2),(2,1),(2,3),(3,4),(4,5),(5,3)\}.$$

Running Tarjan's algorithm yields three SCCs: $C_1 = \{1,2\}$, $C_2 = \{3,4,5\}$, and the isolated vertex would not arise here. The condensation $\hat{G}$ has two vertices $\hat{C}_1, \hat{C}_2$ and a single edge $\hat{C}_1 \to \hat{C}_2$. Hence $C_1$ is a source component (in-degree 0 in $\hat{G}$) and $C_2$ is a sink component (out-degree 0). No vertex in $C_2$ can reach $C_1$, which reflects the irreversibility of information flow between the two groups.

Key Theorem. Every finite directed graph $G$ with at least one vertex possesses at least one source component and at least one sink component in its condensation.

Proof sketch. Because $\hat{G}$ is a DAG on a finite vertex set, it contains at least one topological ordering. The first element of any such ordering has in-degree 0 (a source component) and the last has out-degree 0 (a sink component). $\square$

This theorem has immediate algorithmic consequences: to find all vertices from which every other vertex is reachable, it suffices to examine source components; to identify vertices that absorb all paths, examine sink components.

Lab Cell (SymPy / NetworkX).

import networkx as nx

G = nx.DiGraph([(1,2),(2,1),(2,3),(3,4),(4,5),(5,3)])

sccs = list(nx.strongly_connected_components(G))
cond = nx.condensation(G, scc=sccs)

sources = [v for v, d in cond.in_degree()  if d == 0]
sinks   = [v for v, d in cond.out_degree() if d == 0]

for label, nodes in [("Source components", sources),
                     ("Sink components",   sinks)]:
    print(label, [cond.nodes[n]["members"] for n in nodes])

Running this prints each component's member set, confirming $\{1,2\}$ as the unique source component and $\{3,4,5\}$ as the unique sink component.
