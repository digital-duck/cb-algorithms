Concept Book: Traveling Salesman

Algorithms Ch13 · Generated by SPL

Payoff

The Traveling Salesman Problem (TSP) asks: given a complete weighted graph $G = (V, E, w)$ with $|V| = n$ cities and edge weights $w : E \to \mathbb{R}_{>0}$ representing distances, find a Hamiltonian cycle $\mathcal{C}^*$ such that

$$\mathcal{C}^* = \arg\min_{\mathcal{C} \in \mathcal{H}(G)} \sum_{(u,v) \in \mathcal{C}} w(u, v),$$

where $\mathcal{H}(G)$ denotes the set of all Hamiltonian cycles over $G$. This deceptively simple statement encodes one of the deepest tensions in all of combinatorial mathematics: the search space has $(n-1)!/2$ candidates, yet the answer must be extracted with computational resources that do not grow factorially with $n$.

The TSP is the natural culmination of this concept-book because it forces every prior idea to work in concert. Graphs provide the substrate; spanning trees and greedy heuristics (Prim, Christofides) supply the first approximations; dynamic programming over subsets (Held–Karp) compresses exponential search into $O(n^2 2^n)$ time; and complexity theory names the residual hardness precisely — TSP is NP-hard in general and APX-hard in the metric case unless $\text{P} = \text{NP}$.

Key Theorem (Christofides–Serdyuk, 1976). For any instance satisfying the triangle inequality, the Christofides algorithm returns a tour of length at most $\tfrac{3}{2}\,\text{OPT}$, where $\text{OPT}$ is the optimal tour length. The bound is achieved by combining a minimum spanning tree with a minimum-weight perfect matching on the odd-degree vertices, then shortcutting the resulting Eulerian circuit.

The theorem is significant not merely as a ratio guarantee but as a template: it shows that two tractable sub-problems — minimum spanning tree ($O(m \log n)$) and minimum-weight matching ($O(n^3)$) — can be composed to approximate an intractable one. That compositional strategy recurs across modern algorithm design.

import itertools, sympy as sp

def tsp_exact(dist):
    n = len(dist)
    cities = list(range(1, n))
    best = (sp.oo, None)
    for perm in itertools.permutations(cities):
        route = (0,) + perm + (0,)
        cost = sum(dist[route[i]][route[i+1]] for i in range(n))
        if cost < best[0]:
            best = (cost, route)
    return best

D = [[0,2,9,10],[1,0,6,4],[15,7,0,8],[6,3,12,0]]
cost, route = tsp_exact(D)
print(f"Optimal cost: {cost}, Route: {route}")
