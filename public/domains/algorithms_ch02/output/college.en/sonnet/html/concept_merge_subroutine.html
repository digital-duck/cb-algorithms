Merge Subroutine

Definition. The merge subroutine is an algorithm that accepts two sorted sequences $A = (a_1, a_2, \ldots, a_p)$ and $B = (b_1, b_2, \ldots, b_q)$ and produces a single sorted sequence $C$ of length $p + q$ containing exactly the elements of $A \cup B$ (with multiplicity). Formally, given $A[1..p]$ and $B[1..q]$ satisfying $a_1 \le a_2 \le \cdots \le a_p$ and $b_1 \le b_2 \le \cdots \le b_q$, the merge subroutine outputs $C[1..p+q]$ such that $C$ is non-decreasing and is a permutation of the concatenation $A \| B$.

The subroutine maintains two pointers $i$ and $j$, initialized to $1$. At each step it compares $A[i]$ and $B[j]$, appends the smaller element to $C$, and advances the corresponding pointer. When one input is exhausted, the remaining elements of the other are appended directly.

Worked Example. Let $A = (2, 5, 8)$ and $B = (1, 4, 9)$.

| Step | $i$ | $j$ | Compare | Append | |------|-----|-----|---------|--------| | 1 | 1 | 1 | $2 > 1$ | $1$ | | 2 | 1 | 2 | $2 < 4$ | $2$ | | 3 | 2 | 2 | $5 > 4$ | $4$ | | 4 | 2 | 3 | $5 < 9$ | $5$ | | 5 | 3 | 3 | $8 < 9$ | $8$ | | 6 | — | 3 | exhausted $A$ | $9$ |

Result: $C = (1, 2, 4, 5, 8, 9)$. Each element is visited exactly once, giving a total of $p + q - 1 \le p + q$ comparisons.

Key Theorem (Merge Complexity). The merge subroutine runs in $\Theta(p + q)$ time and requires $\Theta(p + q)$ auxiliary space.

Proof sketch. Each comparison advances at least one pointer; pointers advance at most $p$ and $q$ times respectively before exhaustion. Hence the comparison count is bounded above by $p + q - 1$ and below by $\max(p, q)$, both $\Theta(p + q)$. The output array $C$ must hold all $p + q$ elements, establishing the space bound. $\square$

This linear cost is what makes Merge Sort achieve its $\Theta(n \log n)$ worst-case guarantee: the recursion tree has $\log_2 n$ levels, each performing $\Theta(n)$ total merge work.

Lab Cell.

from sympy import symbols, Function, Rational

# Demonstrate merge on symbolic-length lists
A = [2, 5, 8]
B = [1, 4, 9]

def merge(A, B):
    C, i, j = [], 0, 0
    while i < len(A) and j < len(B):
        if A[i] <= B[j]:
            C.append(A[i]); i += 1
        else:
            C.append(B[j]); j += 1
    return C + A[i:] + B[j:]

result = merge(A, B)
print("Merged:", result)
# Verify sort invariant
assert result == sorted(A + B)
print("Comparisons upper bound:", len(A) + len(B) - 1)
