Payoff

Every tool developed in the preceding chapters — spanning constraint satisfaction, objective aggregation, and symbolic computation — has been in service of a single decision-theoretic question: given a finite collection of candidate initiatives and a set of competing resource constraints, which subset should be pursued? Project selection is the formal answer to that question.

Definition. Let $\mathcal{P} = \{p_1, p_2, \ldots, p_n\}$ denote a set of candidate projects. Each project $p_i$ carries a value $v_i > 0$ and consumes a vector of resources $\mathbf{c}_i \in \mathbb{R}^m_{\geq 0}$. A portfolio is a binary vector $\mathbf{x} \in \{0,1\}^n$, where $x_i = 1$ indicates that $p_i$ is selected. Given a resource budget $\mathbf{b} \in \mathbb{R}^m_{>0}$, the project-selection problem is

$$\max_{\mathbf{x} \in \{0,1\}^n} \sum_{i=1}^n v_i x_i \quad \text{subject to} \quad \sum_{i=1}^n \mathbf{c}_i x_i \leq \mathbf{b}.$$

This is the multidimensional 0-1 knapsack problem, a member of the NP-hard family, yet one admitting elegant exact solutions for moderate $n$ and powerful approximation schemes at scale.

Worked example. Suppose a research department has a weekly budget of $B = 40$ person-hours and considers four projects with values $(10, 7, 5, 3)$ and costs $(20, 15, 10, 5)$. Building the dynamic-programming table $\mathrm{dp}[j]$ — the maximum value achievable within $j$ hours — and iterating over projects in order yields the optimal portfolio $\{p_1, p_3\}$ with total value $15$ and total cost $30 \leq 40$.

Theorem (FPTAS for 0-1 knapsack). For any $\varepsilon > 0$, there exists an algorithm running in $O(n^2 / \varepsilon)$ time that returns a feasible portfolio whose value is at least $(1 - \varepsilon)$ times the optimum.

The proof scales the values $v_i \mapsto \lfloor v_i \cdot n / (\varepsilon \cdot v_{\max}) \rfloor$, reducing the state-space of the DP table to $O(n^2/\varepsilon)$ without losing more than an $\varepsilon$ fraction of the true optimum.

from sympy import symbols, Rational, floor

n, eps, v_max = 4, Rational(1, 10), 10
v = [10, 7, 5, 3]
scaled = [int(floor(vi * n / (eps * v_max))) for vi in v]
print("Scaled values:", scaled)   # [40, 28, 20, 12]

Project selection is the natural capstone because it unifies every prior concept: feasibility constraints from linear algebra, value aggregation from calculus-based optimization, and symbolic verification from computer-algebra tools. The invitation now is to choose one domain — portfolio management, curriculum design, or infrastructure planning — and watch this single formulation illuminate decisions that once seemed irreducibly complex.
