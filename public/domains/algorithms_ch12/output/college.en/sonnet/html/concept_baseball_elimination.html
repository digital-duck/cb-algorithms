Baseball Elimination

Definition. Let $n$ teams compete in a season. For each team $i$, let $w_i$ denote its current win total and $r_i$ its remaining games. Let $g_{jk}$ denote the number of remaining games between teams $j$ and $k$. Team $i$ is trivially eliminated if there exists a team $j$ with $w_j > w_i + r_i$. More subtly, team $i$ is non-trivially eliminated when no assignment of future game outcomes allows it to finish with the most wins, even if it wins all remaining games. Formally, team $i$ is eliminated if and only if it cannot tie for first place in any possible completion of the season.

The power of the baseball elimination problem lies in its reduction to a maximum network flow computation. Construct a directed network $G_i$ as follows. Create a source $s$, a sink $t$, one game node $(j,k)$ for every pair $j < k$ with $j, k \neq i$, and one team node for each team $j \neq i$. Add edges:

$$s \to (j,k) \text{ with capacity } g_{jk}, \quad (j,k) \to j \text{ and } (j,k) \to k \text{ with capacity } \infty,$$ $$j \to t \text{ with capacity } (w_i + r_i) - w_j \quad (\text{set to } 0 \text{ if negative}).$$

The capacity on edge $j \to t$ encodes how many more wins team $j$ can accumulate before it surpasses the ceiling $w_i + r_i$.

Worked Example. Suppose four teams remain with standings $w = (83, 80, 78, 77)$, remaining games $r = (0, 3, 6, 6)$, and inter-team game counts $g_{23}=1, g_{24}=3, g_{34}=2$ (all other pairs complete). Is team 1 eliminated? Team 1's ceiling is $83 + 0 = 83$. The total games among teams 2, 3, 4 is $G = 1+3+2=6$. The capacities to $t$ are $83-80=3$, $83-78=5$, $83-77=6$. Running max-flow on $G_1$ yields a value of $6$, equal to $G$, so team 1 is not eliminated.

Theorem (Schwartz 1966; Hoffman–Rivlin 1967). Team $i$ is eliminated if and only if the maximum $s$-$t$ flow in $G_i$ is strictly less than

$$G_i^{\text{total}} = \sum_{\substack{j < k \\ j,k \neq i}} g_{jk}.$$

By the max-flow min-cut theorem, this is equivalent to the existence of a subset $T \subseteq \{1,\dots,n\}\setminus\{i\}$ such that

$$w_i + r_i < \frac{1}{|T|}\!\left(\sum_{j \in T} w_j + \sum_{\substack{j < k \\ j,k \in T}} g_{jk}\right).$$

The right-hand side is the average wins that teams in $T$ must collectively achieve among themselves, demonstrating that the group $T$ collectively forces team $i$ out.

import networkx as nx

def is_eliminated(i, w, r, g):
    ceiling = w[i] + r[i]
    teams = [j for j in range(len(w)) if j != i]
    G = nx.DiGraph()
    G.add_node('s'); G.add_node('t')
    total_games = 0
    for idx, j in enumerate(teams):
        for k in teams[idx+1:]:
            cap = g.get((j, k), g.get((k, j), 0))
            total_games += cap
            node = f"game_{j}_{k}"
            G.add_edge('s', node, capacity=cap)
            G.add_edge(node, j, capacity=float('inf'))
            G.add_edge(node, k, capacity=float('inf'))
        G.add_edge(j, 't', capacity=max(0, ceiling - w[j]))
    flow_value, _ = nx.maximum_flow(G, 's', 't')
    return flow_value < total_games

w = [83, 80, 78, 77]; r = [0, 3, 6, 6]
g = {(1,2):1, (1,3):3, (2,3):2}
print(is_eliminated(0, w, r, g))  # False
