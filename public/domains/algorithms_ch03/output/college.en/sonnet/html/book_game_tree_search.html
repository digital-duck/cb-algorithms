What game tree search achieves. Every concept developed in this book — recursion, branching processes, minimax optimization, alpha-beta pruning, and heuristic evaluation — converges in the algorithm of game tree search. Given a two-player, zero-sum game with perfect information, game tree search constructs a complete or partial enumeration of future states and selects the move that maximizes the agent's guaranteed outcome under the assumption that the opponent plays optimally. Formally, let $S$ denote the set of game states, $A(s)$ the legal actions from state $s$, and $u : S \to \mathbb{R}$ a utility function defined on terminal states. The minimax value of a state is

$$ v(s) = \begin{cases} u(s) & \text{if } s \text{ is terminal,} \\ \max_{a \in A(s)} v(T(s,a)) & \text{if the maximizing player moves,} \\ \min_{a \in A(s)} v(T(s,a)) & \text{if the minimizing player moves,} \end{cases} $$

where $T : S \times A \to S$ is the transition function. The optimal action from state $s$ is then $a^* = \arg\max_{a \in A(s)} v(T(s,a))$.

Worked example. Consider a three-round binary game in which the maximizing player chooses Left ($\mathrm{L}$) or Right ($\mathrm{R}$) at each internal node and the minimizing player responds. Assigning terminal utilities $\{3, 5, 2, 9, 1, 6, 4, 8\}$ (left to right), a depth-first traversal propagates minimax values upward: the minimizing nodes yield $\min(3,5)=3$, $\min(2,9)=2$, $\min(1,6)=1$, $\min(4,8)=4$; the maximizing nodes then yield $\max(3,2)=3$ and $\max(1,4)=4$; and the root resolves to $\max(3,4)=4$, directing the agent to play $\mathrm{R}$.

Key theorem (Zermelo, 1913). Every finite, two-player, zero-sum game with perfect information has a deterministic optimal strategy for at least one player; equivalently, the minimax value at the root is well-defined and equals the maximin value.

Lab cell.

from sympy import symbols, Piecewise, Min, Max

# Represent a depth-2 minimax tree symbolically
a, b, c, d = symbols('a b c d', real=True)
left_min  = Min(a, b)
right_min = Min(c, d)
root_max  = Max(left_min, right_min)
print(root_max)                        # Max(Min(a, b), Min(c, d))
print(root_max.subs({a:3,b:5,c:2,d:9}))  # 3
