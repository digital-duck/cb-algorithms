Edmonds Karp Polynomial Bounds

Definition. The Edmonds–Karp algorithm is a specialization of the Ford–Fulkerson method for computing maximum flow in a network $G = (V, E)$ with capacities $c: E \to \mathbb{R}_{\geq 0}$. It selects augmenting paths by breadth-first search (BFS), ensuring that each chosen path is a shortest path (in terms of number of edges) from source $s$ to sink $t$. The algorithm terminates when no augmenting path exists, at which point the flow is maximum by the max-flow min-cut theorem.

The key polynomial guarantee is:

$$\text{Total augmentations} \leq O(VE),$$

yielding an overall time complexity of $O(VE^2)$, since each BFS costs $O(E)$.

Worked Example. Consider a network with $V = \{s, a, b, t\}$ and edges:

$$s \xrightarrow{10} a, \quad s \xrightarrow{10} b, \quad a \xrightarrow{1} b, \quad a \xrightarrow{10} t, \quad b \xrightarrow{10} t.$$

BFS from $s$ finds shortest paths first. The path $s \to a \to t$ (length 2) is chosen before $s \to a \to b \to t$ (length 3). After saturating two paths of capacity 10 each, the algorithm discovers the max flow is 20. Because BFS enforces shortest-path selection, it never wastes iterations cycling on long detours.

Key Theorem (Edmonds–Karp, 1972). In any network with $|V|$ vertices and $|E|$ edges, the Edmonds–Karp algorithm performs at most $\frac{|V||E|}{2}$ augmentations, and thus terminates in $O(|V||E|^2)$ time.

Proof sketch. Define the distance label $d(v)$ as the BFS shortest-path distance from $s$ to $v$ in the residual graph. One shows that $d(v)$ is monotonically non-decreasing across iterations. An edge $(u,v)$ becomes critical (saturated) only when $d(v) = d(u)+1$; before it can become critical again, $d(u)$ must increase by at least 2. Since $d(u) \leq |V|-1$, each edge is critical at most $O(|V|)$ times, giving at most $O(|V||E|)$ total augmentations. $\blacksquare$

Lab Cell (SymPy).

import sympy as sp

V, E = sp.symbols('V E', positive=True, integer=True)
augmentations = V * E / 2
total_complexity = V * E**2
print("Max augmentations:", augmentations)
print("Time complexity:  O(", sp.simplify(total_complexity), ")")

This confirms that Edmonds–Karp is strongly polynomial: its running time depends only on the graph structure, not on capacity magnitudes, distinguishing it from naive Ford–Fulkerson on irrational capacities.
