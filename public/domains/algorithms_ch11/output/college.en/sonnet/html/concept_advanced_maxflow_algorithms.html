Advanced Maxflow Algorithms

Definition. Let $G = (V, E)$ be a directed graph with a capacity function $c : E \to \mathbb{R}_{\geq 0}$, a source $s \in V$, and a sink $t \in V$. A flow is a function $f : E \to \mathbb{R}_{\geq 0}$ satisfying capacity constraints $f(u,v) \leq c(u,v)$ and conservation $\sum_{u} f(u,v) = \sum_{w} f(v,w)$ for all $v \notin \{s,t\}$. The maximum flow problem asks for a flow that maximises $|f| = \sum_{v} f(s,v)$. Advanced algorithms improve upon the basic Ford–Fulkerson scheme—which can run in $O(|f^*| \cdot |E|)$ time—by exploiting structural properties of the residual graph $G_f$, where $c_f(u,v) = c(u,v) - f(u,v)$.

Worked Example. Consider the graph with $V = \{s, a, b, t\}$ and edges $s \to a$ (cap 10), $s \to b$ (cap 10), $a \to t$ (cap 10), $b \to t$ (cap 10), $a \to b$ (cap 1). The maximum flow is 20. The Edmonds–Karp algorithm (BFS-based augmenting paths) finds this in two saturating pushes along $s \to a \to t$ and $s \to b \to t$, each augmenting by 10. The redundant edge $a \to b$ is never used, illustrating that shortest augmenting paths avoid wasteful detours. Edmonds–Karp runs in $O(VE^2)$, independent of capacity values.

Key Theorem (Dinic's Algorithm). Dinic's algorithm constructs a layered graph $L_f$ via BFS on $G_f$, then finds a blocking flow—a flow saturating every $s$-$t$ path in $L_f$—using DFS with link-cut pruning. Each blocking-flow phase increases the shortest augmenting-path length by at least one, so there are at most $O(V)$ phases. Each phase costs $O(VE)$, giving an overall bound of $O(V^2 E)$. On unit-capacity graphs the bound improves to $O(E \sqrt{V})$, making Dinic's algorithm optimal for many practical instances including bipartite matching.

from sympy import symbols, Rational

# Represent residual capacities as a dict and run one BFS augmentation
cap = {('s','a'): 10, ('s','b'): 10, ('a','t'): 10,
       ('b','t'): 10, ('a','b'): 1}

def bfs_path(cap, s, t):
    from collections import deque
    parent = {s: None}
    queue = deque([s])
    while queue:
        u = queue.popleft()
        for (x, y), c in cap.items():
            if x == u and y not in parent and c > 0:
                parent[y] = x
                if y == t:
                    path, node = [], t
                    while node != s:
                        path.append((parent[node], node))
                        node = parent[node]
                    return path[::-1]
                queue.append(y)
    return None

flow = 0
while (path := bfs_path(cap, 's', 't')):
    bottleneck = min(cap[e] for e in path)
    for (u, v) in path:
        cap[(u, v)] -= bottleneck
        cap.setdefault((v, u), 0)
        cap[(v, u)] += bottleneck
    flow += bottleneck

print(f"Maximum flow: {flow}")  # 20
