Fattest Augmenting Path

Definition. Let $G = (V, E)$ be a directed graph with a non-negative capacity function $c : E \to \mathbb{R}_{\geq 0}$, a source $s \in V$, and a sink $t \in V$. Given a feasible flow $f$, the residual graph $G_f$ assigns each edge a residual capacity $c_f(u,v) = c(u,v) - f(u,v)$. An augmenting path $P$ from $s$ to $t$ in $G_f$ carries flow limited by its bottleneck capacity:

$$\text{bn}(P) = \min_{(u,v) \in P} c_f(u,v).$$

The fattest augmenting path is the augmenting path $P^*$ that maximises this bottleneck:

$$P^* = \operatorname*{arg\,max}_{P \in \mathcal{P}} \text{bn}(P),$$

where $\mathcal{P}$ denotes all $s$-$t$ paths in $G_f$. Intuitively, the fattest path pushes the largest possible unit of flow in a single augmentation, reducing the number of iterations required to reach the maximum flow.

Worked Example. Consider the graph with edges and residual capacities:

$$s \xrightarrow{10} a \xrightarrow{3} t, \quad s \xrightarrow{5} b \xrightarrow{8} t, \quad s \xrightarrow{7} c \xrightarrow{7} t.$$

The three candidate paths and their bottlenecks are:

| Path | Bottleneck | |---|---| | $s \to a \to t$ | $\min(10,3) = 3$ | | $s \to b \to t$ | $\min(5,8) = 5$ | | $s \to c \to t$ | $\min(7,7) = 7$ |

The fattest path is $s \to c \to t$ with bottleneck $7$. Augmenting along it sends $7$ units, saturating both edges simultaneously.

Key Theorem. (Capacity-Scaling Bound) The fattest-path algorithm terminates in at most $O(E \log U)$ augmentation phases, where $U = \max_{e} c(e)$, and each phase requires $O(E \log V)$ time using a maximum bottleneck spanning tree (found via a modified Dijkstra or Prim sweep). Therefore the total runtime is $O(E^2 \log V \log U)$. In networks where $U$ is large but $E$ is small, this substantially outperforms naïve shortest-path augmentation, which may require $O(EU)$ augmentations.

Lab Cell (SymPy / NetworkX).

import networkx as nx

G = nx.DiGraph()
G.add_weighted_edges_from([
    ('s','a',10), ('a','t',3),
    ('s','b', 5), ('b','t',8),
    ('s','c', 7), ('c','t',7),
], weight='capacity')

# NetworkX uses Edmonds-Karp internally; to demonstrate fattest-path selection:
paths = list(nx.all_simple_paths(G, 's', 't'))
fattest = max(paths,
              key=lambda p: min(G['u']['v']['capacity']
                                for u, v in zip(p, p[1:])))
bottleneck = min(G[u][v]['capacity'] for u, v in zip(fattest, fattest[1:]))
print(f"Fattest path: {fattest}, bottleneck = {bottleneck}")
# Output: Fattest path: ['s', 'c', 't'], bottleneck = 7
