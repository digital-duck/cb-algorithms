Concept Book: Unit Capacity Network Algorithms

Algorithms Ch11 · Generated by SPL

Payoff

A unit-capacity network is a directed graph $G = (V, E)$ equipped with a capacity function $c : E \to \{0, 1\}$. Because every arc carries at most one unit of flow, the combinatorial structure tightens dramatically: feasible flows are essentially sets of arc-disjoint paths, and the integrality theorem guarantees that every maximum flow is integer-valued without additional rounding. Algorithms designed for this special structure exploit the bounded capacity to achieve running times that are strictly better than their general-capacity counterparts.

Worked example. Let $G$ have $n = 6$ vertices and $m = 8$ unit-capacity arcs. Apply Ford–Fulkerson augmentation. Because each augmenting path carries exactly one unit and the maximum flow $f^$ is bounded by $\min(\deg^+(s), \deg^-(t))$, the algorithm terminates in at most $f^$ iterations, each costing $O(m)$ time. For unit-capacity graphs one can do better: the Hopcroft–Karp strategy layers the residual graph and pushes a blocking flow in each phase, yielding $O(\sqrt{n})$ phases and total complexity $O(m\sqrt{n})$.

Key theorem (Even–Tarjan, 1975). In a unit-capacity network with $n$ vertices and $m$ arcs, a maximum $s$-$t$ flow can be computed in $O(m \sqrt{n})$ time.

Proof sketch. After $\sqrt{n}$ blocking-flow phases, the shortest augmenting path in the residual graph has length at least $\sqrt{n}$. The remaining flow value is then bounded by $n / \sqrt{n} = \sqrt{n}$, so at most $\sqrt{n}$ additional single-path augmentations suffice. Each blocking-flow phase runs in $O(m)$ via DFS, giving the stated bound. $\square$

Lab cell (SymPy).

import sympy as sp

# Symbolic verification: augmenting-path count bound
n, m = sp.symbols('n m', positive=True, integer=True)
phases      = sp.sqrt(n)          # blocking-flow phases
work_phase  = m                   # O(m) per phase
residual    = sp.sqrt(n)          # remaining augmentations
total       = sp.simplify(phases * work_phase + residual * m)
print("Total complexity:", total)  # m*sqrt(n) + m*sqrt(n)  →  O(m sqrt(n))

Unit-capacity network algorithms stand as the natural culmination of this text because they unify every theme encountered along the way—graph representation, augmenting-path logic, blocking flows, and complexity analysis—while delivering a provably tight bound that general networks cannot match. The $O(m\sqrt{n})$ barrier is not a coincidence; it reflects a deep structural constraint that only unit capacities expose.
