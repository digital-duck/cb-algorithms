Residual Capacity

Definition. Let $G = (V, E)$ be a directed graph representing a flow network, where each edge $(u, v) \in E$ carries a non-negative capacity $c(u, v) \geq 0$. A flow on $G$ is a function $f : V \times V \to \mathbb{R}$ satisfying capacity constraints $0 \leq f(u,v) \leq c(u,v)$ and conservation at every interior vertex. Given such a flow $f$, the residual capacity of an ordered pair $(u, v)$ is defined as

$$c_f(u, v) \;=\; c(u, v) - f(u, v).$$

Intuitively, $c_f(u,v)$ measures how much additional flow can still be pushed from $u$ to $v$ without violating the capacity constraint. The residual network $G_f = (V, E_f)$ retains every pair $(u,v)$ for which $c_f(u,v) > 0$, and crucially includes the reverse arc $(v, u)$ with $c_f(v, u) = f(u, v)$, representing the option to cancel previously committed flow.

Worked example. Consider a single edge $(s, t)$ with $c(s,t) = 10$ and current flow $f(s,t) = 7$. Then

$$c_f(s,t) = 10 - 7 = 3, \qquad c_f(t,s) = 7 - 0 = 7.$$

The forward residual arc says we may push up to $3$ additional units from $s$ to $t$; the backward arc says we may redirect up to $7$ units by canceling existing flow. Both arcs appear in $G_f$, even though $(t,s)$ was absent from the original network.

Key theorem (Augmenting Path Theorem). A flow $f$ in network $G$ is a maximum flow if and only if the residual network $G_f$ contains no directed path from the source $s$ to the sink $t$ (no augmenting path). Each such path can increase the total flow by $\delta = \min_{(u,v) \in P} c_f(u,v)$, the bottleneck residual capacity along path $P$.

Proof sketch. By the Max-Flow Min-Cut Theorem, any $s$-$t$ cut $\{S, T\}$ satisfies $|f| \leq c(S,T)$. If no augmenting path exists, the reachable set from $s$ in $G_f$ defines a cut whose capacity equals $|f|$, certifying optimality.

Lab cell.

import sympy as sp

# Represent one edge: capacity and current flow
c, f_val = 10, 7

c_f_forward  = c - f_val          # residual capacity s→t
c_f_backward = f_val              # residual capacity t→s (cancellation)

bottleneck = sp.Rational(c_f_forward)  # symbolic form
print(f"c_f(s,t) = {c_f_forward}")     # 3
print(f"c_f(t,s) = {c_f_backward}")    # 7
print(f"Bottleneck along path: {bottleneck}")
