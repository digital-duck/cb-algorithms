Ford Fulkerson Algorithm

Definition. Let $G = (V, E)$ be a directed graph with a source vertex $s$, a sink vertex $t$, and a capacity function $c : E \to \mathbb{R}_{\geq 0}$. A flow is a function $f : E \to \mathbb{R}_{\geq 0}$ satisfying two conditions: (1) capacity constraint: $0 \leq f(u,v) \leq c(u,v)$ for all $(u,v) \in E$, and (2) conservation: $\sum_{u} f(u,v) = \sum_{w} f(v,w)$ for all $v \in V \setminus \{s, t\}$. The value of the flow is $|f| = \sum_{v} f(s,v)$. The Ford–Fulkerson algorithm finds a maximum $s$-$t$ flow by repeatedly locating an augmenting path — a path from $s$ to $t$ in the residual graph $G_f$ — and pushing as much flow along it as possible.

The residual graph $G_f$ contains a forward edge $(u,v)$ with residual capacity $c_f(u,v) = c(u,v) - f(u,v)$ whenever $f(u,v) < c(u,v)$, and a backward edge $(v,u)$ with capacity $c_f(v,u) = f(u,v)$ whenever $f(u,v) > 0$. Each iteration selects any augmenting path $P$ in $G_f$, computes the bottleneck $\delta = \min_{(u,v)\in P} c_f(u,v)$, and updates $f$ by increasing forward edges and decreasing backward edges along $P$ by $\delta$.

Worked Example. Consider the graph $s \xrightarrow{10} a \xrightarrow{10} t$ and $s \xrightarrow{10} b \xrightarrow{10} t$ with cross-edge $a \xrightarrow{1} b$. Augmenting along $s \to a \to t$ sends 10 units; augmenting along $s \to b \to t$ sends 10 units. The algorithm terminates with $|f| = 20$, which equals the minimum cut capacity $c(\{s\}, \{a,b,t\}) = 20$.

Theorem (Max-Flow Min-Cut). The maximum value of any $s$-$t$ flow equals the minimum capacity of any $s$-$t$ cut. Ford–Fulkerson terminates with this maximum when capacities are integers, and each augmentation increases $|f|$ by at least one unit, yielding $O(|f| \cdot |E|)$ time complexity. For rational capacities, Edmonds–Karp (BFS augmentation) guarantees $O(VE^2)$ termination regardless of capacity magnitudes.

from sympy import symbols, Rational

# Represent capacities and initial flow as dicts
cap = {('s','a'): 10, ('a','t'): 10,
       ('s','b'): 10, ('b','t'): 10, ('a','b'): 1}
flow = {e: Rational(0) for e in cap}

def residual(cap, flow, u, v):
    return cap.get((u,v), 0) - flow.get((u,v), 0) + flow.get((v,u), 0)

# Verify residual capacity on the backward edge after saturating (s,a,t)
flow[('s','a')] = Rational(10); flow[('a','t')] = Rational(10)
print(residual(cap, flow, 'a', 's'))  # expects 10
