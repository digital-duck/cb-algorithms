记忆化(Memoization)

定义。 记忆化是对递归算法的一种优化:第一次算出某个子问题的结果后,把它存入表(如字典)中;以后再遇到相同的子问题,直接查表,而不再重新计算。它适用于满足两个条件的问题:(1) 存在重叠子问题,即同一子问题被反复求解;(2) 子问题的结果只取决于其参数(无副作用)。

为什么需要它。 以斐波那契数列 $F(n)=F(n-1)+F(n-2)$,$F(0)=0,\ F(1)=1$ 为例。朴素递归的调用次数 $T(n)$ 满足

$$T(n)=T(n-1)+T(n-2)+1,$$

因此 $T(n)=\Theta(\varphi^{n})$,其中 $\varphi=\frac{1+\sqrt5}{2}\approx1.618$,增长是指数级的。原因是大量重复计算:计算 $F(5)$ 时,$F(3)$ 被算了 2 次,$F(2)$ 被算了 3 次。

worked example(例题)。 加入缓存后的实现:

def fib(n, memo={}):
    if n in memo:            # 命中缓存,直接返回
        return memo[n]
    if n < 2:
        return n
    memo[n] = fib(n-1, memo) + fib(n-2, memo)
    return memo[n]

计算 $F(5)$ 时,递归先一路向下到 $F(1)$ 与 $F(0)$,然后自底向上依次填表:$F(2)=1,\ F(3)=2,\ F(4)=3,\ F(5)=5$。每个 $F(k)$ 只真正计算一次,之后的调用都是 $O(1)$ 的查表。于是不同的子问题只有 $n+1$ 个,每个的额外工作量为常数,总时间降为 $O(n)$,空间为 $O(n)$(缓存加递归栈)。

一般结论:记忆化后的时间复杂度 $=$ (不同子问题的个数)$\times$(每个子问题自身的计算代价,不含递归调用)。

解题应用。 问题:一个机器人在 $m\times n$ 网格中从左上角出发,每次只能向右或向下走一步,求到达右下角的路径数。

  • 写递归关系:$P(i,j)=P(i-1,j)+P(i,j-1)$,边界 $P(0,j)=P(i,0)=1$。
  • 识别重叠:$P(i-1,j)$ 与 $P(i,j-1)$ 都会用到 $P(i-1,j-1)$,所以子问题重叠。
  • 加缓存,以 $(i,j)$ 作为键:
    • from functools import lru_cache

@lru_cache(maxsize=None)
def paths(i, j):
    if i == 0 or j == 0:
        return 1
    return paths(i-1, j) + paths(i, j-1)
  • 分析复杂度:不同状态共 $mn$ 个,每个只需一次加法,故时间为 $O(mn)$。不用缓存的话,调用次数约为 $\binom{m+n}{m}$ 量级,是指数增长的。

    • 注意事项。 缓存的键必须完整刻画子问题的所有参数;函数必须是纯函数;递归过深可能导致栈溢出,这时可改用自底向上的动态规划填表,它与记忆化的子问题结构相同,只是计算顺序不同。
