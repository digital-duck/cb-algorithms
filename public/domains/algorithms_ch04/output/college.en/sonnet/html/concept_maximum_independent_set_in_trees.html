Maximum Independent Set In Trees

Definition. Let $G = (V, E)$ be an undirected graph. A set $S \subseteq V$ is called independent if no two vertices in $S$ are adjacent, i.e., for all $u, v \in S$, the edge $\{u, v\} \notin E$. The maximum independent set (MIS) is an independent set of largest possible cardinality, denoted $\alpha(G)$. Finding $\alpha(G)$ is NP-hard for general graphs; however, when $G$ is a tree, an exact solution is computable in $O(n)$ time via dynamic programming on the tree's structure.

Worked Example. Consider the path graph $P_5$ with vertices $\{1, 2, 3, 4, 5\}$ and edges $\{1\text{–}2, 2\text{–}3, 3\text{–}4, 4\text{–}5\}$. Root the tree at vertex $1$. Define two quantities for each vertex $v$:

$$ dp[v][0] = \text{MIS size in subtree of } v, \text{ excluding } v, $$ $$ dp[v][1] = \text{MIS size in subtree of } v, \text{ including } v. $$

The recurrences are:

$$ dp[v][0] = \sum_{c \in \text{children}(v)} \max\bigl(dp[c][0],\, dp[c][1]\bigr), $$ $$ dp[v][1] = 1 + \sum_{c \in \text{children}(v)} dp[c][0]. $$

Applying these bottom-up on $P_5$ (leaves first):

| vertex | $dp[\cdot][0]$ | $dp[\cdot][1]$ | |--------|----------------|----------------| | 5 | 0 | 1 | | 4 | $\max(0,1)=1$ | $1+0=1$ | | 3 | $\max(1,1)=1$ | $1+1=2$ | | 2 | $\max(1,2)=2$ | $1+1=2$ | | 1 | $\max(2,2)=2$ | $1+2=3$ |

Thus $\alpha(P_5) = \max(2, 3) = 3$, achieved by $S = \{1, 3, 5\}$.

Key Theorem. For any tree $T$ on $n$ vertices, the dynamic programming recurrence above produces $\alpha(T)$ in $\Theta(n)$ time and $\Theta(n)$ space. The correctness follows from the optimal substructure property of trees: removing a root partitions the graph into independent subtrees, so globally optimal decisions decompose into locally optimal ones without overlapping constraints across subtrees.
