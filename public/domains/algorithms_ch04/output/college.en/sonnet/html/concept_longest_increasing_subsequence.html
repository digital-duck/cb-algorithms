Longest Increasing Subsequence

Definition. Given a sequence $A = (a_1, a_2, \ldots, a_n)$ of real numbers, an increasing subsequence is a subsequence $a_{i_1}, a_{i_2}, \ldots, a_{i_k}$ with $i_1 < i_2 < \cdots < i_k$ and $a_{i_1} < a_{i_2} < \cdots < a_{i_k}$. The Longest Increasing Subsequence (LIS) of $A$ is any such subsequence of maximum length $L(A)$.

Note that the elements need not be contiguous in $A$; only their relative order is preserved. The LIS is generally not unique, but $L(A)$ is well-defined.

Worked Example. Consider $A = (3, 1, 4, 1, 5, 9, 2, 6)$. The subsequence $(1, 4, 5, 9)$, obtained by selecting indices $2, 3, 5, 6$, is strictly increasing and has length $4$. Checking all other candidates confirms no increasing subsequence of length $5$ exists, so $L(A) = 4$.

Key Theorem (Dynamic Programming Recurrence). Define $\text{dp}[i]$ as the length of the longest increasing subsequence ending at index $i$. Then

$$\text{dp}[i] = 1 + \max\bigl\{\text{dp}[j] : j < i,\; a_j < a_i\bigr\},$$

with $\text{dp}[i] = 1$ when no such $j$ exists. The answer is $L(A) = \max_{1 \le i \le n} \text{dp}[i]$.

Proof sketch. Any LIS ending at position $i$ consists of an LIS ending at some earlier position $j$ (with $a_j < a_i$) followed by $a_i$. Taking the maximum over all valid predecessors $j$ and adding $1$ for the element $a_i$ itself yields the recurrence. Induction on $i$ establishes correctness.

This recurrence runs in $O(n^2)$ time. A patience-sorting argument reduces this to $O(n \log n)$ by maintaining a set of active subsequence tails and applying binary search at each step.

Lab Cell.

from sympy import oo

A = [3, 1, 4, 1, 5, 9, 2, 6]
n = len(A)
dp = [1] * n

for i in range(1, n):
    for j in range(i):
        if A[j] < A[i]:
            dp[i] = max(dp[i], dp[j] + 1)

lis_length = max(dp)
print("dp array :", dp)
print("L(A)     :", lis_length)   # Expected: 4

Running this cell prints dp array : [1, 1, 2, 1, 3, 4, 2, 4] and L(A) : 4, confirming the example. Modify A to experiment with sequences of your choice.
