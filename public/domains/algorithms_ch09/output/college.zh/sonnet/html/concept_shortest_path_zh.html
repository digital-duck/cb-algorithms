最短路径

定义。 设带权图 $G=(V,E,w)$,其中 $w:E\to\mathbb{R}$ 为边权。从顶点 $s$ 到顶点 $t$ 的一条路径 $P=(s=v_0,v_1,\dots,v_k=t)$ 的长度(权重)为

$$w(P)=\sum_{i=1}^{k} w(v_{i-1},v_i).$$

最短路径是所有 $s\to t$ 路径中 $w(P)$ 最小的那条,其权重记为最短距离 $\delta(s,t)=\min_P w(P)$。若 $t$ 不可达,则 $\delta(s,t)=\infty$。注意:"最短"指总权重最小,而不是经过的边数最少(后者是无权图的特例)。

关键性质(最优子结构)。 若 $s\to\dots\to u\to\dots\to t$ 是最短路径,则其中任一子路径也是相应两端点间的最短路径。由此得到三角不等式:对任意边 $(u,v)$,

$$\delta(s,v)\le \delta(s,u)+w(u,v).$$

例题。 求上图中从 $A$ 到 $D$ 的最短路径。

枚举所有路径:

  • $A\to B\to D$:$2+8=10$
  • $A\to C\to D$:$7+1=8$
  • $A\to B\to C\to D$:$2+3+1=6$

    • 故最短路径为 $A\to B\to C\to D$,$\delta(A,D)=6$。注意:直接边数最少的路径并非最优。

    用 Dijkstra 算法(要求 $w\ge0$)验证:初始 $d[A]=0$,其余为 $\infty$。

  • 取出 $A$:$d[B]=2,\ d[C]=7$。
  • 取出 $B$($d=2$):$d[C]=\min(7,2+3)=5$,$d[D]=10$。
  • 取出 $C$($d=5$):$d[D]=\min(10,5+1)=6$。
  • 取出 $D$:结束,$d[D]=6$。

    • 问题求解应用。 选择算法时先看图的性质:

    情形 算法 时间复杂度
    无权图 BFS $O(V+E)$
    非负权重 Dijkstra(二叉堆) $O((V+E)\log V)$
    含负权边 Bellman–Ford $O(VE)$
    所有点对 Floyd–Warshall $O(V^3)$ 
    import heapq
def dijkstra(G, s):
    d = {v: float("inf") for v in G}; d[s] = 0
    pq = [(0, s)]
    while pq:
        du, u = heapq.heappop(pq)
        if du > d[u]: continue
        for v, w in G[u]:
            if du + w < d[v]:
                d[v] = du + w
                heapq.heappush(pq, (d[v], v))
    return d

    为何 Dijkstra 要求非负权重? 当 $w\ge0$ 时,一个顶点一旦以最小的 $d$ 被取出,后续路径只会增加长度,不可能再改进它,因此其距离已最终确定。若存在负边,这一论证失效。若图中存在总权重为负的环,则 $\delta$ 无下界,最短路径无定义,Bellman–Ford 可检测这种情形。

    典型应用包括地图导航(边权为时间或距离)、网络路由(边权为延迟)以及状态空间搜索。将实际问题建模为带权图,是应用该概念的第一步。
