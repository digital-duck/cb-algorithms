Fast Matrix Multiplication

Definition. Given two matrices $A \in \mathbb{R}^{m \times n}$ and $B \in \mathbb{R}^{n \times p}$, the standard matrix product $C = AB$ is defined by

$$c_{ij} = \sum_{k=1}^{n} a_{ik}\, b_{kj}, \quad 1 \le i \le m,\; 1 \le j \le p.$$

This requires $O(mnp)$ scalar multiplications — for square $n \times n$ matrices, that is $O(n^3)$ operations. Fast matrix multiplication refers to any algorithm that computes $AB$ in asymptotically fewer arithmetic operations, the canonical example being Strassen's algorithm, which reduces the exponent from $3$ to $\log_2 7 \approx 2.807$.

Strassen's Key Idea. To multiply two $2 \times 2$ block matrices using only $7$ (instead of the naive $8$) scalar multiplications, define the auxiliary products

$$M_1 = (A_{11}+A_{22})(B_{11}+B_{22}), \quad M_2 = (A_{21}+A_{22})B_{11}, \quad \ldots, \quad M_7 = (A_{11}+A_{12})B_{22}.$$

The blocks of $C$ are then recovered by additions and subtractions of the $M_i$. Applying this decomposition recursively to $n \times n$ matrices (where $n$ is a power of two) yields a recurrence $T(n) = 7\,T(n/2) + O(n^2)$, which by the Master Theorem resolves to $T(n) = O(n^{\log_2 7})$.

Worked Example. Let $A = B = \begin{pmatrix} 1 & 2 \\ 3 & 4 \end{pmatrix}$. The standard product requires $8$ multiplications and yields $C = \begin{pmatrix} 7 & 10 \\ 15 & 22 \end{pmatrix}$. Strassen computes the same $C$ with $7$ multiplications: for instance, $M_1 = (1+4)(1+4) = 25$ and $c_{11} = M_1 + M_4 - M_5 + M_7 = 7$, recovering the correct entry while saving one scalar multiply.

Key Theorem (Strassen, 1969). Two $n \times n$ matrices can be multiplied in $O(n^{\log_2 7})$ arithmetic operations. More generally, if a divide-and-conquer scheme computes the product of $n \times n$ matrices by reducing to $q$ multiplications of $(n/2) \times (n/2)$ submatrices, then the overall complexity is $O(n^{\log_2 q})$; Strassen achieves $q = 7$.

Lab Cell.

import sympy as sp

A = sp.Matrix([[1, 2], [3, 4]])
B = sp.Matrix([[1, 2], [3, 4]])

# Standard product
C_standard = A * B
print("Standard product:", C_standard)

# Strassen's 7-multiplication scheme for 2x2
a, b, c, d = A[0,0], A[0,1], A[1,0], A[1,1]
e, f, g, h = B[0,0], B[0,1], B[1,0], B[1,1]

M1 = (a + d)*(e + h)
M2 = (c + d)*e
M3 = a*(f - h)
M4 = d*(g - e)
M5 = (a + b)*h
M6 = (c - a)*(e + f)
M7 = (b - d)*(g + h)

C_strassen = sp.Matrix([
    [M1 + M4 - M5 + M7, M3 + M5],
    [M2 + M4,           M1 - M2 + M3 + M6]
])
print("Strassen product:", sp.simplify(C_strassen))
print("Match:", C_standard == C_strassen)
